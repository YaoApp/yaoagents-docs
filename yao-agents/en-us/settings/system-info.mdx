# System Info

The **System Info** panel shows the current version numbers and runtime environment of your Yao Agents installation. Open it from the Settings page.

![Settings — System Info](https://assets.yaoagents.com/en/settings/01-config-system-info-en-$__THEME.png)

## What you'll see

| Field | Description |
|-------|-------------|
| Yao Agents | Version of the Yao Agents desktop application. |
| Yao Engine | Version of the underlying Yao Engine runtime. |
| CUI | Version of the CUI (Chat UI) component. |
| Environment | Current runtime mode — `Development` or `Production`. |

## When to check

- **Before reporting a bug** — include the version numbers in your issue.
- **After updating** — verify that all components updated successfully.
- **Troubleshooting** — support may ask for your version details.
