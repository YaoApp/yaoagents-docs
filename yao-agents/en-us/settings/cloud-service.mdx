# Cloud Service

The **Cloud Service** panel configures the connection between Yao Agents and the Yao Agents model service. This is the fastest way to get started — sign up, paste your API key, and every built-in AI Expert will work out of the box.

![Settings — Cloud Service](https://assets.yaoagents.com/en/settings/02-config-cloud-service-en-$__THEME.png)

## Configuration

| Field | Description |
|-------|-------------|
| Region | Select the closest region to reduce latency: US, China, Asia, or Europe. |
| API URL | The endpoint for the Yao Agents model service. Pre-filled based on your region selection. |
| API Key | Your personal API key. Get one at [yaoagents.com/dashboard](https://yaoagents.com/dashboard/auth/entry?redirect=/console). |

## Steps

1. Choose a **Region** closest to you.
2. The **API URL** updates automatically.
3. Paste your **API Key**.
4. Click **Save**. Yao Agents will verify the connection.

## Using your own model providers

If you prefer to use your own model services (OpenAI, Anthropic, DeepSeek, local Ollama, etc.), configure them in [Model Configuration](/docs/en-us/settings/ai-models) instead. The cloud service and custom providers can work side by side.
