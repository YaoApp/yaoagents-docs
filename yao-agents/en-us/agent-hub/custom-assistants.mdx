# Custom AI Experts

Yao Agents comes with a set of built-in AI Experts, and you can create your own as needed.

## 1. Build with Agent Smith

Open Agent Smith and describe the expert you want — it searches the skill library, builds, tests, and deploys automatically. No code required.

Agent Smith searches a global skill library (100,000+) and third-party ecosystems for ready-made solutions, runs a security audit, then adapts them to your requirements.

→ [Agent Smith details](/docs/en-us/built-in-agents/agent-smith)

## 2. Build with Code

Write your own AI Expert using the Yao DSL. This gives you full control over prompts, tools, sandbox, and behavior.

→ [Getting Started with Yao Agent](https://yaoapps.com/docs/tutorials/en-us/agent/getting-started/index) — step-by-step tutorial on YaoApps.com
