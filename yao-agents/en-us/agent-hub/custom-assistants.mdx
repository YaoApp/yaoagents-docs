# Custom AI Experts

Yao Agents comes with a set of built-in AI Experts, and you can extend it with your own. Here are the ways to add new experts.

## 1. Install from Yao Agents Hub

Browse Yao Agents Hub to find ready-made experts built by the community, then install with one click.

> **Early Access.** Yao Agents Hub is currently in early access.

## 2. Ask the AI Dev Expert

Open the built-in AI development expert and describe the expert you want to create. It will generate the configuration and install it for you — no code required.

> **Early Access.** This feature is currently in early access.

## 3. Build with Code

Write your own AI Expert using the Yao DSL. This gives you full control over prompts, tools, sandbox, and behavior.

→ [Your First Agent](https://yaoapps.com/docs/tutorials/en-us/agent/basics/first-agent) — step-by-step tutorial on YaoApps.com

## 4. Explore Third-Party Ecosystems

Yao Agents is compatible with agents from open community ecosystems. You can browse these platforms and adapt compatible agents for use in Yao Agents.

- [ClawHub](https://clawhub.ai/) — community-built skills and plugins
- [Hermes Agent Skills Hub](https://hermes-agent.nousresearch.com/docs/skills) — open registry of agent skills by Nous Research

> **Early Access.** Third-party ecosystem integration is currently in early access. These are independent communities; compatibility may vary.
