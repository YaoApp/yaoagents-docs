# Yao Agents Hub

Yao Agents Hub is your marketplace for discovering, installing, and sharing AI experts — purpose-built for every workflow.

> **Early Access.** Yao Agents Hub is currently in early access. Public launch coming soon.

## Built-in Experts

Yao Agents ships with a curated set of experts ready to use out of the box.

| Expert | What it does |
|--------|-------------|
| [General](/docs/en-us/built-in-agents/general) | General-purpose assistant — Q&A, coding, research, writing |
| [PM](/docs/en-us/built-in-agents/pm) | Project manager — task breakdown, tracking, team coordination |
| [Postman](/docs/en-us/built-in-agents/postman) | Email assistant — draft, send, and manage emails via SMTP/IMAP |
| [Insights](/docs/en-us/built-in-agents/insights) | Data analyst — databases, spreadsheets, ECharts dashboards |
| [Market Scout](/docs/en-us/built-in-agents/scout) | Market intelligence — monitor feeds, classify articles |
| [Slides](/docs/en-us/built-in-agents/slides) | Slide builder — outlines to HTML presentations, PDF export |
| [Transformer](/docs/en-us/built-in-agents/transformer) | Data structuring — images, PDFs, JSON, CSV via Vision LLM |
| [Web Builder](/docs/en-us/built-in-agents/website) | Website builder — Next.js + Tailwind, VNC preview, SSH deploy |
| [Applet Workshop](/docs/en-us/built-in-agents/applet) | Mini-app builder — Node.js visual tools, live VNC preview |
| [Report Writer](/docs/en-us/built-in-agents/report-writer) | Report robot — auto-generates structured Markdown reports in Mission Control |
