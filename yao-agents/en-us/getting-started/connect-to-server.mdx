# Connect to a Cloud Server

By default, Yao Agents connects to a local Yao Engine (Local Server). If you'd rather skip the local setup, you can connect directly to a cloud server — sign in and you're good to go, with all AI Experts ready to use.

## Local vs Cloud

| | Local Server | Cloud Server |
|---|---|---|
| Yao Engine required | Yes | No |
| Data storage | Everything stays on your device | Stored on the server |
| AI models | Bring your own key or use cloud service | Pre-configured by server |
| Tai Link nodes | Connect your own | Shared nodes provided |
| Best for | Privacy-first, long-term use | Quick trial, team sharing |

## How to connect

### 1. Pick a server

Open Yao Agents. On first launch, you'll see the server selection screen. **Local Server** is there by default. Hit **Add server** to add a cloud server.

![Server selection](https://assets.yaoagents.com/en/servers/01-servers-select-en-$__THEME.png)

### 2. Enter the server address

Fill in the server URL and a display name. Check the [/servers](/servers) page for available servers and their addresses.

![Add server](https://assets.yaoagents.com/en/servers/02-servers-add-en-$__THEME.png)

### 3. Select and connect

Once added, the cloud server appears in your server list. Click it to start connecting.

![Server list](https://assets.yaoagents.com/en/servers/03-servers-added-en-$__THEME.png)

### 4. Sign in

Enter your email, grab the verification code, and sign in. Some servers require an invite code — check the [/servers](/servers) page for details.

![Sign in](https://assets.yaoagents.com/en/servers/04-servers-login-en-$__THEME.png)

### 5. You're in

After signing in, you land on the main screen with all AI Experts ready. Everything works the same as with a local server — pick an expert, start a chat, create tasks.

![Cloud server main screen](https://assets.yaoagents.com/en/servers/05-servers-main-en-$__THEME.png)

## Switch between servers

You can switch servers anytime. Click the server name in the top-left corner to go back to the selection screen and hop between local and cloud.

## Available servers

Head to the [/servers](/servers) page to see which cloud servers are online, their regions, registration requirements, and specs.
