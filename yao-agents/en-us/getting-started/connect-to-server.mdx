# Connect to a Server

This guide walks you through connecting your Yao Agents client to a server.

## Step 1: Get Your Server Address

Visit the [Servers](/servers) page to find a server near you. Copy the server URL.

## Step 2: Open Yao Agents

Launch the Yao Agents desktop application on your device.

## Step 3: Configure Server

Navigate to **Settings → Server** and paste the server address you copied.

## Step 4: Sign In or Register

If the server requires an invite code, apply for one on the [Servers](/servers) page. Otherwise, create an account directly.
