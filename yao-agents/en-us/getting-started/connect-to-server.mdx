# Connect to a Cloud Server

By default, Yao Agents connects to a local Yao Engine (Local Server). If you'd rather skip the local setup, you can connect straight to a cloud server — sign in and you're good to go, with every AI Expert ready to use.

## Local vs Cloud

| | Local Server | Cloud Server |
|---|---|---|
| Yao Engine required | Yes | No |
| Data storage | Everything stays on your device | Stored on the server |
| AI models | Bring your own key or use a cloud service | Pre-configured by the server |
| Tai Link nodes | Connect your own | Shared nodes provided |
| Best for | Privacy-first, long-term use | Quick trial, team sharing |

## How to connect

### 1. Pick a cloud server

Open the client. In the server window, choose a cloud server under the **Cloud Servers** tab — for example, Polaris (Trial Server) at `https://bj.yaoagents.cn`.

![Pick a cloud server](https://assets.yaoagents.com/en/login/login-cloud-servers-en-$__THEME.png)

You can also switch to the **Custom Server** tab and enter a server address yourself.

![Custom Server](https://assets.yaoagents.com/en/login/login-custom-server-url-en-$__THEME.png)

### 2. Connect

Click **Connect**. Some servers are invite-only and need a code — you can apply for one on the site.

### 3. Sign in / register

Enter your own email, verify the code, and click **Continue**.

![Enter email](https://assets.yaoagents.com/en/servers/04-servers-login-en-$__THEME.png)

- **Already registered** — you're signed in right away.
- **New here** — set a password and click **Sign Up**.

![Set a password](https://assets.yaoagents.com/en/login/login-reg-en-$__THEME.png)

### 4. You're in

You'll land on the main screen with every AI Expert ready to go — the same as with a local server.

![Main screen](https://assets.yaoagents.com/en/login/login-inbox-en-$__THEME.png)

## Switch between servers

You can switch servers anytime. Right-click the tray icon, or click the server name in the top-left corner, to return to the server window.
