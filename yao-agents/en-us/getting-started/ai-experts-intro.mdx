# AI Experts

Yao Agents comes with a roster of AI Experts — each one built for a specific type of work. Pick the right expert, describe what you need, and let it handle the rest.

![AI Experts — browse by category, pick a specialist](https://assets.yaoagents.com/en/experts/03-experts-full-en-$__THEME.png)

### DeepSeek Harness

General-purpose agent powered by DeepSeek Harness. Coding, research, data analysis, writing, and automation — all in a persistent sandbox with terminal, browser, and VNC desktop.

![DeepSeek Harness](https://assets.yaoagents.com/en/experts/04-expert-deepseek-harness-en-$__THEME.png)

[View details →](/docs/en-us/built-in-agents/deepseek-harness)

### Claude Code

General-purpose agent powered by Claude Code. Coding, research, data analysis, writing, and automation — with the same persistent sandbox and live preview.

![Claude Code](https://assets.yaoagents.com/en/experts/05-expert-claude-code-en-$__THEME.png)

[View details →](/docs/en-us/built-in-agents/claude-code)

### Agent Smith

Build your own AI experts. Describe what you need — Agent Smith finds skills, assembles the expert, tests it in a sandbox, and deploys it to your expert list.

![Agent Smith](https://assets.yaoagents.com/en/experts/06-expert-agent-smith-en-$__THEME.png)

[View details →](/docs/en-us/built-in-agents/agent-smith)

Build and deploy websites from a conversation. Next.js + Tailwind, live VNC preview, and one-step SSH deployment with HTTPS.

![Web Builder](https://assets.yaoagents.com/en/experts/07-expert-web-builder-en-$__THEME.png)

## Picking the right expert

Open the **AI Experts** panel from the home screen. Browse by category using the filter tabs, or search by name.

## Switching models

Each expert uses your primary model by default. Switch mid-conversation using the model picker at the bottom of the chat.

![Model picker](https://assets.yaoagents.com/en/chat/08-chat-model-picker-en-$__THEME.png)
