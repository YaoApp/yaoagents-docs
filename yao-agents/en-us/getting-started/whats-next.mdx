# What's Next

You've got Yao Agents running and understand the basics. Here's where to go depending on what you want to do next.

## Connect your other devices — Tai Link

Tai Link turns any machine into a node your AI team can work on. Install it on a second computer, a VM, or a server — your Robots and experts can then open apps, move files, and run commands there, without touching your main machine.

[What Is Tai Link →](/docs/en-us/tai-link/what-is-tai-link)

[Connect Your First Device →](/docs/en-us/tai-link/connect-first-device)

## Connect to messaging platforms

Bind a Robot or an expert to your team's chat app. Results land wherever your team already works.

## Add your own AI models

Yao Agents works with any OpenAI-compatible API — including local models via Ollama. Add a new connector in Settings if you want to use a model not configured during setup.

[AI Models →](/docs/en-us/settings/ai-models)

## Extend with MCP tools

MCP (Model Context Protocol) tools let experts and Robots interact with external services — your calendar, databases, internal APIs. Connect any MCP server in a few clicks.

[MCP Tools →](/docs/en-us/settings/mcp-tools)

## Build or install custom experts

Browse the Yao Agents Hub for community-built experts, or create your own using the built-in AI development assistant. Yao Agents is also compatible with the OpenClaw agent ecosystem.

[Yao Agents Hub →](/docs/en-us/agent-hub/hub-overview)

[Custom AI Experts →](/docs/en-us/agent-hub/custom-assistants)
