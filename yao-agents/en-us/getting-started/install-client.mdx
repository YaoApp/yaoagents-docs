# Install the Desktop Client

The desktop client is the best way to use Yao Agents day to day. It connects to the Yao Engine running on your own machine. Here's the full flow.

## 1. Download and install

Available for macOS, Windows, and Linux. Grab it from the [client download page](/download/yaoagents) and install it like any other app.

## 2. Connect to your local Engine

Open the client and switch to the **Custom Server** tab in the server window.

![Custom Server](https://assets.yaoagents.com/en/login/login-custom-server-en-$__THEME.png)

Enter your local Engine address — `http://127.0.0.1:5099`, the same one your browser uses — and click **Connect**.

![Enter the address](https://assets.yaoagents.com/en/login/login-custom-server-url-en-$__THEME.png)

> Can't connect? Make sure Yao Engine is running and the address and port are right.

## 3. Sign in / register

Enter your email, verify the code, and click **Continue**.

![Enter email](https://assets.yaoagents.com/en/servers/04-servers-login-en-$__THEME.png)

- **Already registered** — you're signed in right away.
- **New here** — set a password and click **Sign Up**.

![Set a password](https://assets.yaoagents.com/en/login/login-reg-en-$__THEME.png)

## 4. Set up a model service

Choose where your models come from:

- **Use Tao Service (recommended)** — one key for models, search, fetch, storage, and more.
- **Bring Your Own Key** — connect your own OpenAI, Anthropic, local Ollama, and so on.

![Choose a model service](https://assets.yaoagents.com/en/login/login-bind-key-en-$__THEME.png)

For Tao Service, open the console, click **Create New Key**, and copy the key.

![Get the key](https://assets.yaoagents.com/en/login/login-get-key-en-$__THEME.png)

Paste it into the app and click **Verify and Configure**.

![Configure Tao Service](https://assets.yaoagents.com/en/login/login-bind-key-step-2-en-$__THEME.png)

## 5. Start using it

You'll land on the main screen — pick an expert, send a message, or create a task.

![Main screen](https://assets.yaoagents.com/en/login/login-inbox-en-$__THEME.png)

> **Tip:** Right-click the tray icon to switch servers or open settings.
