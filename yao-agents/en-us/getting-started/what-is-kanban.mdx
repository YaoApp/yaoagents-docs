# What Is Kanban Board

Put your tasks on a board, tell AI what to do, and watch them get done — all in one view.

![Kanban board overview](https://assets.yaoagents.com/en/kanban/07-kanban-board2-en-$__THEME.png)

## What it can do

- **See everything at once** — Boards, columns, cards. Your whole workload in one place
- **Say it, start it** — Describe what you need in plain language. AI picks it up instantly
- **Always know where things stand** — Every task shows its status: queued, running, waiting for you, done, or failed
- **Automate the recurring stuff** — Set a schedule and AI runs on its own — daily, weekly, whatever you need
- **Drag to rearrange** — Move cards between columns to match how you actually work

## Core concepts

Kanban Board has three layers:

**Board** — One board per work area. "Content Ops," "Competitor Research," "Client Work" — whatever makes sense for you.

**Column** — Columns inside a board. Use them to group tasks: "This Week," "Recurring," "Done."

**Task** — Each card in a column is a task. Under the hood, every task is an AI conversation — you tell AI what to do, and it does it.

## Create boards and tasks

You can create multiple boards, each for a different work context. Create a new board from the dropdown menu at the board title area.

Add columns via the right-click menu to categorize your tasks within a board.

### Create a task

Click the "+" button at the bottom of a column.

![Add task](https://assets.yaoagents.com/en/kanban/02-kanban-addtask-en-$__THEME.png)

A chat panel opens. Type what you need — same as talking to an AI Expert. Hit send, and the task is live. AI starts working right away.

![Enter task request](https://assets.yaoagents.com/en/kanban/03-kanban-newtask-en-$__THEME.png)

You can follow along in real time while AI works. If it needs your input, it pauses and waits.

![Task in progress](https://assets.yaoagents.com/en/kanban/04-kanban-running-en-$__THEME.png)

When a task wraps up, you get the full output and any files it generated.

![Task completed](https://assets.yaoagents.com/en/kanban/05-kanban-result-en-$__THEME.png)

## Task status

Every task shows exactly where it's at:

| Status | What it means |
|--------|---------------|
| Queued | In line, waiting to run |
| Running | AI is working on it |
| Waiting for input | AI needs your call before it can continue |
| Completed | Done |
| Failed | Something broke — check the details and retry |

> 💡 Status changes trigger Inbox notifications automatically. No need to babysit the board.

## Scheduling

Some work needs to happen on repeat — a weekly report every Monday, daily brand monitoring.

Set up a schedule in the task settings:

| Mode | How it works |
|------|--------------|
| Timed | Runs at specific times — e.g. every Monday at 9 AM |
| Interval | Repeats on a fixed cycle — e.g. every 24 hours |

Scheduled tasks keep their conversation history. AI remembers last time's output and builds on it.
