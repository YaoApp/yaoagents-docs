# Agent Smith (Build Your Own Expert)

![Agent Smith](https://assets.yaoagents.com/en/experts/02-agent-smith-en-$__THEME.png)

Describe what you need, and it creates, refines, and deploys your custom AI expert. No coding, no technical background required — you describe, it delivers.

## What it's good at

- **Create experts from scratch** — Tell it what kind of expert you want (e.g. "stock analyst"), and it builds the whole thing
- **Reuse existing skills** — Searches a global skill library (100,000+) for ready-made solutions
- **Security audit** — Automatically checks safety and compatibility before installing external skills
- **Automated testing** — Verifies functionality and iterates until all tests pass
- **Live sandbox testing** — Runs the expert in a sandbox desktop with real inputs
- **One-click deploy** — Deploy when ready, immediately available in your expert list

## What kinds of experts can it make

- **Data analysis** — Stock quotes, financial reports, data dashboards
- **Content creation** — Industry reports, slide decks, marketing copy
- **Information processing** — File format conversion, OCR, batch data organization
- **Research** — Competitive analysis, market research, technical evaluations
- **Productivity** — Email management, progress tracking, work summaries

Not limited to the above — if you can describe it clearly, it can build it.

## How it works

Agent Smith runs in a sandbox environment with a full desktop, terminal, file system, and browser. Its workflow:

1. Analyze your requirements
2. Search the global skill library for reusable solutions
3. Build the expert's core capabilities
4. Run automated tests to ensure everything works
5. Launch in sandbox for live testing — you confirm the results
6. Deploy

You just say one sentence to start, then wait for the result. It asks if anything needs clarification.

## How to write good prompts

**Create a new expert:**

> Build me a stock analyst that can read K-line charts and fundamentals

> Make a meeting notes expert — input transcript text, output structured minutes

**Improve an existing expert:**

> My stock analyst is too verbose, help me tune it

> Add PPT generation to my competitive analysis expert

**Find existing skills:**

> Any ready-made PDF parsing skill? Search and install it

> Find a web scraping skill and add it to my research expert

**Test and preview:**

> Test this expert to see if it works properly

> I want to see how it looks in the browser, open a preview

**Deploy:**

> All good, deploy it

> Push this expert live, my team needs to use it
