# Yao Agents とは

Yao Agents は、AI エキスパートチームを手元に持てるデスクトップアプリです。すべて自分のデバイス上で動作し、データが外部に出ることはありません。

> あなたの AI チーム。あなたのデバイスで。あなたのコントロール下に。

## なぜ Yao Agents なのか

インストールするだけで、AI スタッフのチームが揃います。質問に答えるもの、スケジュールに従って自動でタスクを実行するもの、投げ込んだ情報をひっそり整理し続けるもの。すべてあなたのマシン上で動き、データはあなたのものです。

AI があなたのパソコンを占有することもありません。別のデバイス——予備のノートPC、VM、コンテナ、ラックのサーバー——をつなげば、AI チームはそちらで働きます。あなたの画面はいつでも自由です。

## チームでできること

- **いつでも適切な専門家に聞ける** — プログラミング・ライティング・リサーチ・データ分析・プロジェクト管理など、30以上の内蔵 AI Expert がそれぞれの領域に特化して待機しています。
- **監視不要で自動実行** — Robot はスケジュール通りまたは自動でタスクを実行します。朝のニュースまとめ、受信トレイの処理、データレポート——寝ている間に完成しています。
- **知識を読み取り整理する** — Keeper はウェブページ・PDF・動画・音声を消化し、要約・タグ付け・アーカイブを自動で行います。リンクを渡すだけで、あとはすべて任せられます。
- **すべてのマシンをまたいで連携** — Tai Link でノートPC・VM・コンテナ・サーバーを接続。AI チームはリモートデバイス上で作業し、自分の画面はまったく邪魔されません。

![Yao Agents — 30以上の内蔵エキスパートが並ぶ AI Expert パネル](https://assets.yaoagents.com/en/experts/01-experts-grid-en-$__THEME.png)

## 仕組み

Yao Agents はローカルサーバー（Yao Engine）としてあなたのマシン上で動作します。デスクトップクライアントはそこに接続します——Engine を頭脳、クライアントをその頭脳を覗く窓と考えてください。

別のデバイスで AI を動かしたい場合は、そのマシンに Tai Link をインストールするだけ。Yao Engine への安全なトンネルが確立され、AI チームがそのデバイス上で操作できるようになります。あなたの画面は完全に空いたままです。

すべての会話履歴・ナレッジ・ファイル・タスク結果はあなたのデバイスに保存されます。外部に出るのは、接続した LLM に送るプロンプトのみ——そのプロバイダーはあなたが選びます。

## Yao Agents でないもの

製品の性格を正しく理解するために、いくつか明確にしておきます。

- **ノーコード Bot 構築プラットフォームではない** — フローを組んだり Pipeline を設定しなくても使えます。アプリを開いて、専門家を選んで、作業を始めるだけ。
- **開発者専用ツールではない** — 非技術者でもすぐに使えます。開発者は Hooks・MCP・Processes で深くカスタマイズできます。
- **ただのチャット画面ではない** — AI Expert はあなたが依頼したときにタスクを実行します。Robot は同じタスクをスケジュールに従って自律的に行います。Keeper はバックグラウンドでナレッジを管理し、あなたが声をかけなくても動いています。

## 用語集

| 用語 | 意味 |
|------|------|
| **AI Expert** | 特定領域（プログラミング・ライティング・リサーチなど）に特化した AI 専門家——30以上を内蔵し、自分で追加することも可能 |
| **AI Task Agent** | Mission Control の実行パイプライン内で動くエージェント |
| **Robot** | Mission Control の自律タスク実行者——スケジュールに従って動作し、手動トリガーは不要 |
| **Keeper** | ナレッジ管理エージェント——送り込んだコンテンツを読み取り、要約し、アーカイブする |
| **Mission Control** | タスクダッシュボード——Robot の作成・スケジュール設定・監視を行う場所 |
| **Tai Link** | リモートデバイスを Yao Engine に接続するブリッジ |
| **Yao Engine** | すべてを動かすローカルサーバー——あなたのマシン上で動作する |
| **BYOK** | Bring Your Own Key——使いたい LLM の API キーを自分で用意する方式 |
| **Pipeline** | Robot がタスクを完了するまでに経る一連の実行ステージ |
