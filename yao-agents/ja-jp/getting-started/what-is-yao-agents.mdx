# Yao Agents とは

すべてのエージェントとワークスペースを一元管理。あなた自身のデバイスで動作します。タスクはボードで追跡でき、デスクトップ・モバイル・ブラウザ・API からいつでもアクセス可能。セルフホスト対応。

![仕組み](https://assets.yaoagents.com/en/architecture/01-how-it-works-en-$__THEME.png)

エージェントは専用マシン上で並列に動きます。接続したデバイスの数だけ同時に稼働し、すべてを一つのアプリで管理できます。マシンを追加すれば、そのまま生産力が増えます。

[ダウンロード](/download) · [インストールガイド](/docs/ja-jp/getting-started/installation)

## なぜ Yao Agents か

デスクトップ、スマホ、ブラウザからエージェントに指示を出すだけ。あなたのマシン上で作業が進む間、あなたは別のことに集中できます。

### ワークスペース

各ワークスペースは完全に独立した環境です。異なる仕事は別々の空間で管理され、複数台のマシンを横断して統合管理できます。作業はドキュメントとして蓄積され、ナレッジベースになります。

エージェントは作業中、どのノードからでも必要な情報を参照できます。

![ワークスペース](https://assets.yaoagents.com/en/workspace/01-workspace-index-en-$__THEME.png)

### タスクボード

会話でやりたいことを伝えれば、エージェントがタスクとしてボードに登録します。繰り返し実行するほど精度が上がり、その仕事に特化したエージェントへと成長します。

タスクエージェントを自分のアプリに接続したり、他のユーザーと共有することもできます。

![タスクボード](https://assets.yaoagents.com/en/kanban/09-kanban-daily-en-$__THEME.png)

### オープン API

エキスパートエージェントもタスクエージェントも、あなたのアプリやワークフローに組み込めます。標準 API 準拠で、SSE と WebSocket の両方に対応。

エージェントをビジネスの一部に。必要な場所で、いつでも稼働します。

![オープン API](https://assets.yaoagents.com/en/openapi/01-openapi-task-en-$__THEME.png)
