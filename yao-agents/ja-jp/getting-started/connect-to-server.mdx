# サーバーへの接続

このガイドでは、Yao Agents クライアントをサーバーに接続する方法を説明します。

## ステップ 1: サーバーアドレスを取得

[サーバー](/servers)ページにアクセスし、最寄りのサーバーを見つけてURLをコピーします。

## ステップ 2: Yao Agents を起動

デバイスで Yao Agents デスクトップアプリケーションを起動します。

## ステップ 3: サーバーを設定

**設定 → サーバー**に移動し、コピーしたサーバーアドレスを貼り付けます。

## ステップ 4: サインインまたは登録

サーバーに招待コードが必要な場合は、[サーバー](/servers)ページから申請してください。それ以外はアカウントを作成します。
