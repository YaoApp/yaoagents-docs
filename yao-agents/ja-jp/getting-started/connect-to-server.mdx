# クラウドサーバーに接続

Yao Agents はデフォルトでローカルの Yao Engine（Local Server）に接続します。ローカルに Engine をインストールしたくない場合は、クラウドサーバーに直接接続できます。サインインするだけで、すべての AI エキスパートがすぐに使えます。

## ローカル vs クラウド

| | Local Server | Cloud Server |
|---|---|---|
| Yao Engine のインストール | 必要 | 不要 |
| データ保存先 | すべて自分のデバイス | サーバー側に保存 |
| AI モデル | 自分のキーまたはクラウドサービス | サーバー側で事前設定済み |
| Tai Link ノード | 自分で接続 | サーバー提供の共有ノード |
| 向いている用途 | プライバシー重視・長期利用 | 手軽に試す・チーム共有 |

## 接続手順

### 1. サーバーを選択

Yao Agents クライアントを起動します。初回起動時にサーバー選択画面が表示されます。デフォルトで **Local Server** があります。**Add server** をクリックしてクラウドサーバーを追加します。

![サーバー選択](https://assets.yaoagents.com/en/servers/01-servers-select-en-$__THEME.png)

### 2. サーバーアドレスを入力

表示されたフォームにサーバーの URL と表示名を入力します。利用可能なサーバーは [/servers](/servers) ページで確認できます。

![サーバー追加](https://assets.yaoagents.com/en/servers/02-servers-add-en-$__THEME.png)

### 3. 選択して接続

追加が完了すると、サーバーリストにクラウドサーバーが表示されます。クリックして接続を開始します。

![サーバーリスト](https://assets.yaoagents.com/en/servers/03-servers-added-en-$__THEME.png)

### 4. サインイン

**ご自身のメールアドレスを入力**してください。確認コードが届くので、認証後にパスワードを設定します。デフォルトアカウントは使用しないでください。招待コードが必要なサーバーもあります。詳細は [/servers](/servers) ページをご確認ください。

![サインイン](https://assets.yaoagents.com/en/servers/04-servers-login-en-$__THEME.png)

### 5. 利用開始

サインイン後、メイン画面が表示され、すべての AI エキスパートが使えます。ローカルサーバーと操作方法は同じです。エキスパートを選び、会話を始め、タスクを作成しましょう。

![クラウドサーバーのメイン画面](https://assets.yaoagents.com/en/servers/05-servers-main-en-$__THEME.png)

## サーバーの切り替え

いつでもサーバーを切り替えられます。クライアント左上のサーバー名をクリックすると選択画面に戻り、ローカルとクラウドを自由に行き来できます。

## 利用可能なサーバー

[/servers](/servers) ページで、現在利用可能なクラウドサーバー、リージョン、登録方法、スペックを確認できます。
