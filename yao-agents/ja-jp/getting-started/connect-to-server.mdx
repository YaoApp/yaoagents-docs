# クラウドサーバーに接続

Yao Agents はデフォルトでローカルの Yao Engine（Local Server）に接続します。ローカルに Engine をインストールしたくない場合は、クラウドサーバーに直接接続できます。サインインするだけで、すべての AI エキスパートがすぐに使えます。

## ローカル vs クラウド

| | Local Server | Cloud Server |
|---|---|---|
| Yao Engine のインストール | 必要 | 不要 |
| データ保存先 | すべて自分のデバイス | サーバー側に保存 |
| AI モデル | 自分のキーまたはクラウドサービス | サーバー側で事前設定済み |
| Tai Link ノード | 自分で接続 | サーバー提供の共有ノード |
| 向いている用途 | プライバシー重視・長期利用 | 手軽に試す・チーム共有 |

## 接続手順

### 1. クラウドサーバーを選択

クライアントを開き、サーバー選択ウィンドウの **Cloud Servers** タブでクラウドサーバーを選びます（例：Polaris (Trial Server) `https://bj.yaoagents.cn`）。

![クラウドサーバーを選択](https://assets.yaoagents.com/en/login/login-cloud-servers-en-$__THEME.png)

**Custom Server** タブに切り替えて、自分でサーバーアドレスを入力することもできます。

![カスタムサーバー](https://assets.yaoagents.com/en/login/login-custom-server-url-en-$__THEME.png)

### 2. 接続

**Connect** をクリックします。招待コードが必要なサーバーもあります（サイトで申請できます）。

### 3. サインイン / 登録

ご自身のメールアドレスを入力し、確認コードで認証して **Continue** をクリックします。

![メールアドレスを入力](https://assets.yaoagents.com/en/servers/04-servers-login-en-$__THEME.png)

- **登録済み**：そのままサインインします。
- **未登録**：パスワードを設定し、**Sign Up** で登録します。

![パスワードを設定](https://assets.yaoagents.com/en/login/login-reg-en-$__THEME.png)

### 4. 利用開始

メイン画面が表示され、すべての AI エキスパートがすぐに使えます。ローカルサーバーと同じ操作です。

![メイン画面](https://assets.yaoagents.com/en/login/login-inbox-en-$__THEME.png)

## サーバーの切り替え

いつでもサーバーを切り替えられます。トレイアイコンを右クリックするか、左上のサーバー名をクリックすると、サーバー選択ウィンドウに戻ります。

## 利用可能なサーバー

[/servers](/servers) ページで、現在利用可能なクラウドサーバー、リージョン、登録方法を確認できます。
