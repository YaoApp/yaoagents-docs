# AI エキスパート

Yao Agents には複数の AI エキスパートが内蔵されており、それぞれ特定の業務に特化しています。適切なエキスパートを選び、やりたいことを伝えるだけで、あとはお任せください。

![AI エキスパート一覧](https://assets.yaoagents.com/en/experts/03-experts-full-en-$__THEME.png)

### DeepSeek Harness

DeepSeek Harness 搭載の汎用エージェント。コーディング、リサーチ、データ分析、ライティング、自動化——永続サンドボックスでターミナル、ブラウザ、VNC デスクトップを完備。

![DeepSeek Harness](https://assets.yaoagents.com/en/experts/04-expert-deepseek-harness-en-$__THEME.png)

[詳細を見る →](/docs/ja-jp/built-in-agents/deepseek-harness)

### Claude Code

Claude Code 搭載の汎用エージェント。コーディング、リサーチ、データ分析、ライティング、自動化——同様の永続サンドボックスとライブプレビューを備えています。

![Claude Code](https://assets.yaoagents.com/en/experts/05-expert-claude-code-en-$__THEME.png)

[詳細を見る →](/docs/ja-jp/built-in-agents/claude-code)

### Agent Smith

あなた専用の AI エキスパートを構築。要件を伝えると、Agent Smith がスキルを検索し、エキスパートを組み立て、サンドボックスでテストし、エキスパートリストにデプロイします。

![Agent Smith](https://assets.yaoagents.com/en/experts/06-expert-agent-smith-en-$__THEME.png)

[詳細を見る →](/docs/ja-jp/built-in-agents/agent-smith)

### Web Builder

会話からウェブサイトを構築・デプロイ。Next.js + Tailwind、VNC ライブプレビュー、ワンステップ SSH デプロイと HTTPS 自動設定。

![Web Builder](https://assets.yaoagents.com/en/experts/07-expert-web-builder-en-$__THEME.png)

[詳細を見る →](/docs/ja-jp/built-in-agents/website)

### Applet Workshop

ツールを説明するだけで、動作するアプリを取得。計算機、ダッシュボード、コンバーター、AI ツールをデスクトップ上でリアルタイムに構築・プレビュー。

![Applet Workshop](https://assets.yaoagents.com/en/experts/08-expert-applet-workshop-en-$__THEME.png)

[詳細を見る →](/docs/ja-jp/built-in-agents/applet)

### Slides

トピック、アウトライン、ドキュメントから洗練されたスライドデッキを生成。9 種類の内蔵テーマ、1920×1080 PDF エクスポート。

![Slides](https://assets.yaoagents.com/en/experts/09-expert-slides-en-$__THEME.png)

[詳細を見る →](/docs/ja-jp/built-in-agents/slides)

### Insights

データベースに接続するか、スプレッドシートを投入。Insights が指標を設計し、インタラクティブな ECharts ダッシュボードを構築してライブプレビュー。

![Insights](https://assets.yaoagents.com/en/experts/10-expert-insights-en-$__THEME.png)

[詳細を見る →](/docs/ja-jp/built-in-agents/insights)

## エキスパートの選び方

ホーム画面から **AI エキスパート** パネルを開き、カテゴリタブで絞り込むか、名前で検索します。

## モデルの切り替え

デフォルトではプライマリモデルを使用。会話中にチャット下部のモデルピッカーでいつでも切り替えられます。

![モデルピッカー](https://assets.yaoagents.com/en/chat/08-chat-model-picker-en-$__THEME.png)
