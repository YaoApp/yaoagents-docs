# インストール

[ダウンロードページ](/download)から Yao Engine を入手してください。プラットフォームとアーキテクチャを選択します。

Yao Engine はローカルサーバーです。1 台の PC にインストールすれば、そのままブラウザーから使い始められます。

日常使いには、**Yao Agents デスクトップクライアント**をインストールしてこの Engine に接続するのがおすすめです。Engine は 1 台で十分で、**同じネットワーク内の他の PC からも接続できます**。複数のデバイスで 1 台のサーバーを共有できます。

- まず動かしたい：インストール後すぐにブラウザーで使えます。
- 日常使い：[デスクトップクライアント](/docs/ja-jp/getting-started/install-client) をインストールすると快適です。

## ステップ 1：Yao Engine を起動

インストール後、Yao Engine を開きます。メインウィンドウに Yao と Tai の 2 つのサービスが表示されます。

![Yao Engine](https://assets.yaoagents.com/en/engine/01-engine-app-en-$__THEME.png)

> **注意：** 初回起動時、App Root に空のディレクトリを指定してください。Yao Agents v1.6.1 以降が必要です。

**Start** をクリックします。起動すると各サービスの PID とアドレスが表示されます。

![Yao Engine 実行中](https://assets.yaoagents.com/en/engine/02-engine-start-en-$__THEME.png)

## ステップ 2：ウェルカムページを開く

**Visit** をクリックしてブラウザでウェルカムページを開き、**Get Started** をクリックします。

![ウェルカムページ](https://assets.yaoagents.com/en/engine/03-engine-visit-en-$__THEME.png)

## ステップ 3：サインイン

**初回ログイン**は、組み込みの管理者アカウントを使用します：

- **メール：** `root@yaoagents.com`
- **パスワード：** `Yao123++`

![サインイン](https://assets.yaoagents.com/en/engine/05-engine-login-code-en-$__THEME.png)

> **注意：** アカウントはローカルデバイスに保存されます。ユーザーを追加するには、先に SMTP を設定してください。設定しないと認証コードを受信できません。

## ステップ 4：モデルを設定

サイドバー左下のアバターをクリックし、**Settings → Model Configuration** を開きます。

![モデル設定](https://assets.yaoagents.com/en/engine/06-engine-models-en-$__THEME.png)

| スロット | 用途 |
|----------|------|
| Default | 汎用タスク |
| Heavy | 高度な推論、長文コンテキスト |
| Light | 高速で軽量なクエリ |
| Vision | 画像認識 |
| Audio | 音声テキスト変換 |
| Embedding | ベクトル検索、ナレッジベース |

> **注意：** DeepSeek モデルは画像・音声に非対応です。DeepSeek 使用時は Vision スロットに別のモデル（Claude、GPT-4o 等）、Audio スロットに Whisper 音声文字起こしモデルを割り当ててください。

**Add Provider** をクリックし、認証情報を入力します。

![プロバイダー追加](https://assets.yaoagents.com/en/engine/07-engine-provider-add-en-$__THEME.png)

> **ヒント：** image2（OpenAI 互換インターフェース）のテキスト→画像/画像編集モデルを追加すると、エージェントが必要に応じて自動的に画像生成・編集を実行します。

デフォルトモデルを選択します。

![設定完了](https://assets.yaoagents.com/en/engine/08-engine-provider-default-en-$__THEME.png)

## ステップ 5：デスクトップクライアントを接続

デスクトップクライアントは日常利用に最適です。[クライアントダウンロードページ](/download/yaoagents)からダウンロードして開き、サーバーアドレス（ローカル Engine は `http://127.0.0.1:5099`）を入力して **Connect** をクリックします。

![サーバーに接続](https://assets.yaoagents.com/en/login/login-custom-server-url-en-$__THEME.png)

> **ヒント：** タスクトレイのアイコンを右クリックすると、サーバーの切り替えや設定にアクセスできます。

詳しい手順は[デスクトップクライアントをインストール](/docs/ja-jp/getting-started/install-client)をご覧ください。
