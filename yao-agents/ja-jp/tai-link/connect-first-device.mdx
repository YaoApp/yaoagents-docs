# 最初のデバイスを接続

Tai Link を設定し、Server Key を使ってリモートマシンを Yao Agents に接続します。

## 事前準備

- 対象マシンに [Tai Link がインストール済み](/docs/ja-jp/tai-link/installation)であること。
- ネットワーク経由でアクセス可能な Yao Engine サーバー（Yao v1.0.0-rc10+）が稼働中であること。

## ステップ 1 — Server Key を作成

既存の Server Key がある場合はそのまま使えます——1 つの Key で複数ノードの同時接続が可能です。なければ新しく作成します：

Yao Engine 画面下部の **Open Terminal** をクリックします。

![Yao Engine — Open Terminal をクリック](https://assets.yaoagents.com/en/engine/02-engine-start-en-$__THEME.png)

実行：

```bash
yao server-key create --name "my-node"
```

出力：

```
  Server key created successfully

  Key ID:  sk-a1b2c3d4e5f6
  Name:    my-node
  Key:     yao-sk:64-char-hex-string...

  ⚠ Save this key now. It will not be shown again.
```

Key 全体（`yao-sk:...`）をコピーしてください。ステップ 2 で使います。

## ステップ 2 — 設定ファイルを作成

対象マシンに `config.yml` を作成します：

**macOS / Linux:**

```yaml
yao:
  server: "<YOUR_YAO_SERVER>"
  node_id: "my-node"
  display_name: "Office Server"
  server_key: "yao-sk:your-key-here"

data: /path/to/your/data

host_exec:
  only: true
  full_access: true

log:
  level: info
```

**Windows:**

```yaml
yao:
  server: "<YOUR_YAO_SERVER>"
  node_id: "my-node"
  display_name: "Office Server"
  server_key: "yao-sk:your-key-here"

data: "C:\\TaiData"

host_exec:
  only: true
  full_access: true

log:
  level: info
  file: logs/tai.log
```

| フィールド | 説明 |
|-----------|------|
| `yao.server` | Yao Agents サーバーアドレス。Yao Engine のウェルカムページで確認できます（クライアントのログインアドレスと同じ）。 |
| `yao.node_id` | ノードの一意識別子。接続する各マシンで重複不可。 |
| `yao.display_name` | Yao Agents UI に表示される名前。 |
| `yao.server_key` | ステップ 1 で作成した Server Key。 |
| `data` | ワークスペースのデータディレクトリ。Agent がファイルを読み書きします。Windows ではパスにダブルバックスラッシュ（`\\`）を使用。 |
| `host_exec.only` | ホスト実行モード——Agent が Docker コンテナではなく、このマシン上で直接コマンドを実行します。 |
| `host_exec.full_access` | コマンドやパスの制限なし、フルアクセスを許可。 |

## ステップ 3 — Tai Link を起動

```bash
tai server --config config.yml
```

正常に起動すると以下のような出力が表示されます：

```
level=INFO msg="logger initialized" level=info format=text file=logs/tai.log
level=INFO msg="tai server" module=server version=1.8.6 ...
level=INFO msg="tai server starting" module=server grpc=[127.0.0.1:0] ...
```

Tai Link は Server Key で自動認証されるため、ブラウザでのログインは不要です。数秒以内にデバイスが Yao Agents UI に表示されます。

## ステップ 4 — 接続を確認

上部ナビゲーションバーの **Computers** をクリックしてパネルを開きます。新しいデバイスが **Running** と表示されていれば成功です。

![Tai Link — デバイスパネル](https://assets.yaoagents.com/en/tai/01-tai-devices-en-$__THEME.png)

ワークスペース作成時に、このノードを実行環境として選択できるようになります。

## Server Key の管理

すべての Key を一覧表示：

```bash
yao server-key list
```

Key を無効化：

```bash
yao server-key revoke sk-a1b2c3d4e5f6
```

## トラブルシューティング

**デバイスが Tai Link パネルに表示されない。**
対象マシンから Yao サーバーにアクセスできるか確認してください。ファイアウォールが送信接続をブロックしていないか確認し、Tai Link ターミナルのエラーメッセージを確認してください。

**デバイスが「Offline」と表示されるが Tai Link は稼働中。**
トンネルが切断された可能性があります。Tai Link は指数バックオフで自動再接続します。ネットワークを確認し、しばらくお待ちください。
