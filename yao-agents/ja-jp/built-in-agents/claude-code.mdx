# Claude Code

![Claude Code](https://assets.yaoagents.com/en/experts/05-expert-claude-code-en-$__THEME.png)

Claude Code 搭載の汎用エージェント。コーディング、リサーチ、データ分析、ライティング、自動化——複雑な推論、長いコンテキストの理解、精密な実行に特に優れています。

## 得意なこと

- **コーディング** — 完全なアプリケーションの構築、コードベースのリファクタリング、デバッグ、複雑なマルチファイルプロジェクトの保守
- **リサーチ** — Web スクレイピング、複数ソースからの情報統合、構造化レポートの作成
- **データ分析** — CSV、JSON、Excel ファイルの処理；分析の実行；チャートやダッシュボードの生成
- **ライティング** — レポート、提案書、ドキュメント、API 仕様を精密かつ繊細に作成
- **自動化** — スクリプト、CLI ツール、パイプラインを構築し、繰り返し作業を自動化
- **ライブプレビュー** — サンドボックスですべてを実行・テスト、フル VNC デスクトップ完備

## 仕組み

Claude Code は DeepSeek Harness と同じ永続 Docker サンドボックスで動作——フルデスクトップ、ターミナル、ファイルシステム、ブラウザ、VNC。違いはモデルです：Claude を推理に使用し、複雑な判断、長いコンテキストの理解、精密な実行に優れています。

タスクを説明すると、Claude Code がアプローチを計画し、作業を実行して結果を検証します。大きなタスクでは作業をステップに分割し、各ステップを確認してから次に進みます。

サンドボックスのライフサイクルは `longrunning`——アイドル時に一時停止し、戻ると自動再開。構築したものはすべて会話をまたいで永続的に保存されます。

Docker サンドボックスが有効でない場合、タスクは Yao Engine がインストールされたマシン上で直接実行されます。

## 使い方のコツ

**結果と制約を伝える。** ステップを細かく指示するのではなく、完了後にどうなっていてほしいかと境界条件を説明します。「この50ページのPDFを2ページの経営層向けサマリーにまとめて、財務リスクに焦点を当てて」の方が「まず1ページ目を読んで...」より効果的です。

**複雑なタスクでは先に質問させる。** 簡単でないタスクの場合、概要を伝えてから質問してもらいます。あなたが考えていなかったエッジケースやトレードオフを発見してくれます。

**まずリサーチ、次にプラン、それから実行。** 大きなタスクではリサーチとアクションを分離します。状況を理解させ、計画を提案させ、承認してから実行。無駄な作業を防ぎます。

**検証可能な成功基準を示す。**「正解」がどんな状態か——具体的な数値、フォーマット要件、リファレンスとの比較——を含めてください。納品前に自己検証します。

**会話を続けて、どんどん進める。** 各メッセージはそれまでの完全なコンテキストの上に積み重なります。ワークスペース内のドキュメントを参照したり、フォローアップしたり、結果を調整したり。「さっきの分析をスライドにして」——フルコンテキストが残っているので、そのまま進めます。

**例：**

> 添付の契約書PDFを読んで。すべての義務条項、期限、違約金条項を構造化テーブルに抽出。30日以内に期限が来るものをフラグ付け。

> [企業名]を調査——財務状況、最近のニュース、競争ポジション。1ページの投資メモを作成し、推奨を付けて。

> 過去1ヶ月の議事録（添付）があります。繰り返し出てくるテーマ、未解決のアクションアイテムを特定し、経営層向けステータスレポートのドラフトを作成。

> カスタマーサポートチケット（添付CSV）を分析。クレームカテゴリのトップ5を特定し、プロセス改善を提案、影響を見積もって。

## 機能一覧

| 機能 | 詳細 |
|------|------|
| モデル | Claude（設定可能） |
| 言語 | Python、TypeScript、Go、Rust、およびインストール可能な任意の言語 |
| Web アクセス | ブラウジング、スクレイピング、API 呼び出し |
| ファイル I/O | あらゆるファイル形式に対応 |
| プレビュー | VNC ライブデスクトップ——アプリの実行をリアルタイムで確認 |
| サンドボックス | 永続 Docker デスクトップ、フルターミナルとブラウザ |
| ライフサイクル | 長期実行——アイドル時に一時停止、復帰時に再開 |
| ワークスペース | 永久保存——コードとファイルは会話をまたいで保持 |
