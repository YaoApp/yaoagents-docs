# Claude Code

![Claude Code](https://assets.yaoagents.com/en/experts/05-expert-claude-code-en-$__THEME.png)

Claude Code 搭載の汎用エージェント。コーディング、リサーチ、データ分析、ライティング、自動化——複雑な推論、長いコンテキストの理解、精密な実行に特に優れています。

## 得意なこと

- **コーディング** — 完全なアプリケーションの構築、コードベースのリファクタリング、デバッグ、複雑なマルチファイルプロジェクトの保守
- **リサーチ** — Web スクレイピング、複数ソースからの情報統合、構造化レポートの作成
- **データ分析** — CSV、JSON、Excel ファイルの処理；分析の実行；チャートやダッシュボードの生成
- **ライティング** — レポート、提案書、ドキュメント、API 仕様を精密かつ繊細に作成
- **自動化** — スクリプト、CLI ツール、パイプラインを構築し、繰り返し作業を自動化
- **ライブプレビュー** — サンドボックスですべてを実行・テスト、フル VNC デスクトップ完備

## 仕組み

Claude Code は DeepSeek Harness と同じ永続 Linux サンドボックスで動作——フルデスクトップ、ターミナル、ファイルシステム、ブラウザ、VNC。違いはモデルです：Claude を推理に使用し、複雑な判断、長いコンテキストの理解、精密な実行に優れています。

タスクを説明すると、Claude Code がアプローチを計画し、作業を実行して結果を検証します。大きなタスクでは作業をステップに分割し、各ステップを確認してから次に進みます。

サンドボックスのライフサイクルは `longrunning`——アイドル時に一時停止し、戻ると自動再開。構築したものはすべて会話をまたいで永続的に保存されます。

## プロンプトのコツ

**スコープと制約を明確に。**「認証モジュールを Session から JWT に変更——既存の API 契約は維持」は「認証を改善して」よりはるかに良いです。

**必要に応じてアーキテクチャを説明。** monorepo、マイクロサービス、特定のパターンが欲しい場合は事前に伝えてください。指定がなければ Claude Code が妥当なデフォルトを選びます。

**マルチステップエンジニアリングに使う。** Claude Code の強みは、計画が必要で、ファイル間に依存関係があり、検証が必要なタスクです。単一ファイルスクリプトも問題ありませんが、より難しい仕事のために作られています。

**例：**

> TypeScript monorepo を構築：共有ライブラリ、REST API（Express）、React フロントエンド。workspace 参照と統一ビルドコマンドを設定。

> この Python プロジェクトをフラットスクリプトから適切なパッケージにリファクタリング：CLI、設定管理、ユニットテスト。外部動作は変更しない。

> このコードベースをレビューして、パフォーマンスのボトルネック上位 5 つを特定。最も深刻なものを修正し、前後のベンチマークを提示。

> この Next.js アプリに Stripe 決済を統合。チェックアウトページ、Webhook ハンドラー、サブスクリプション管理を追加。

| 機能 | 詳細 |
|------|------|
