# Robot Host Agent

ユーザーと Robot の間の会話レイヤーです。**タスクを割り当て**をクリックすると、Robot Host が応答します——説明を聞き、必要に応じて確認の質問をし、目標をまとめて返答し、パイプラインが開始する前に確認を待ちます。

Robot Host はパイプライン Agent です。Robot の詳細設定の**実行パイプライン**ドロップダウンで見つかります——Host ステージとして選択することで、その Robot の手動タスクトリガーを有効にします。

## できること

- **タスクを割り当て**クリック時のタスク説明を受け取る
- 意図が曖昧な場合は確認の質問をする
- 確認した目標をわかりやすい言葉でまとめる
- 明示的な確認（"ok"、"start"、"yes"、"go" など）を待つ
- `confirm_task` を呼び出して確認済み目標をパイプラインに引き渡す

Robot Host はタスクをどのように実行するかについては意図的に**話しません**——それはパイプラインの仕事です。何かが実行される前に目標が正しいことを確認することに集中します。

## 動作の仕方

会話は固定のパターンに従います：

1. あなたが何をしたいか説明する
2. Robot Host が必要に応じて確認の質問をする
3. Robot Host が目標のサマリーを提示する
4. あなたが確認する
5. Robot Host が `confirm_task` を呼び出し、パイプラインが開始する

パイプラインに渡される目標は、あなたが確認したサマリーの忠実なコピーです——Robot Host は同意後に言い換えたり、詳細を追加・省略したりしません。

## 機能一覧

| 機能 | 詳細 |
|------|------|
| Agent タイプ | `robot-host`——パイプライン Agent、実行パイプラインのドロップダウンで選択可能 |
| ステージ | Host Agent——手動タスクトリガーを有効にする |
| トリガー | ユーザーが**タスクを割り当て**をクリックすると起動 |
| 出力 | 確認済み目標の説明、`confirm_task` 経由でパイプラインに引き渡す |
| サンドボックス | コンテナなし |
