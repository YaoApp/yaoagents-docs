# DeepSeek Harness

![DeepSeek Harness](https://assets.yaoagents.com/en/experts/04-expert-deepseek-harness-en-$__THEME.png)

DeepSeek Harness 搭載の汎用エージェント。コーディング、リサーチ、データ分析、ライティング、自動化——永続サンドボックスですべてを処理。ターミナル、ファイルシステム、ブラウザ、VNC デスクトップを完備。

## 得意なこと

- **コーディング** — あらゆる言語でプログラムの作成・実行・デバッグ・リファクタリング；複雑なプロジェクトの構築と保守
- **リサーチ** — Web スクレイピング、複数ソースからの情報統合、構造化レポートの作成
- **データ分析** — CSV、JSON、Excel ファイルの処理；分析の実行；チャートやダッシュボードの生成
- **ライティング** — レポート、提案書、メール、Markdown/HTML ドキュメントの作成
- **自動化** — スクリプト、CLI ツール、パイプラインを構築し、繰り返し作業を自動化
- **ライブプレビュー** — サンドボックスでアプリやツールを実行し、VNC でリアルタイムに結果を確認

## 仕組み

DeepSeek Harness は永続的な Docker サンドボックスで動作し、フルデスクトップ環境を備えています。ターミナル、ブラウザ、ファイルシステム、ネットワークアクセスがあり、実質的に完全な作業マシンです。

推理エンジンとして DeepSeek V4 Pro または V4 Flash を使用。要件を伝えると、アプローチを計画し、作業を実行し、結果を観察して、満足いくまで繰り返します。

サンドボックスのライフサイクルは `longrunning`——アイドル時に一時停止し、戻ると自動的に再開。コード、ファイル、プロジェクトの状態は会話をまたいで永続的に保存されます。

Docker サンドボックスが有効でない場合、タスクは Yao Engine がインストールされたマシン上で直接実行されます。

## 使い方のコツ

**期待する結果と制約を伝える。** 完了時にどうなっていてほしいかと境界条件を伝えます。やり方は任せてください。「どの製品が売上成長を牽引しているか、地域別に分解して見せて」で十分です。

**コンテキストを先に与える。** ファイルを添付し、スクリーンショットを貼り付け、ワークスペース内の既存ドキュメントを参照するか、状況を詳しく説明します。コンテキストが豊富なほど、やり取りの回数が減ります。

**複雑なタスクはフェーズ分け。** まずリサーチ、次にプラン、それから実行を依頼します。間違った方向に進むのを防げます。例：「まずこのスプレッドシートを見て何のデータがあるか教えて。それからどんな分析が有用か提案して。」

**検証可能な完了基準を示す。** 「完了」がどんな状態かを説明できるなら——特定フォーマットのファイル、トレンドを示すチャート、特定セクションを含むレポート——それを伝えてください。納品前に自分でチェックします。

**会話を続けて、どんどん進める。** 各メッセージはそれまでの完全なコンテキストの上に積み重なります。「前年比の比較を追加して」や「もっと簡潔にして」と言えば、フルコンテキストを保持したまま前回の続きから進めます。

**例：**

> [業界]のトップ5競合を調査し、価格モデルを整理して比較表を作成。

> 添付の sales-report.xlsx を分析。成長が最も速い製品は？主要指標のダッシュボードを構築。

> [テーマ]のプロジェクト提案書を作成。読者：経営陣。3ページ以内でタイムラインと予算見積もりを含めて。

> この RSS フィードを毎日監視し、[トピック]に関連する内容をまとめてログファイルに保存。

## 機能一覧

| 機能 | 詳細 |
|------|------|
| モデル | DeepSeek V4 Pro / V4 Flash（設定可能） |
| 言語 | Python、Node.js、Bash、およびインストール可能な任意の言語 |
| Web アクセス | ブラウジング、スクレイピング、API 呼び出し |
| ファイル I/O | あらゆるファイル形式に対応 |
| プレビュー | VNC ライブデスクトップ——アプリの実行をリアルタイムで確認 |
| サンドボックス | 永続 Docker デスクトップ、フルターミナルとブラウザ |
| ライフサイクル | 長期実行——アイドル時に一時停止、復帰時に再開 |
| ワークスペース | 永久保存——コードとファイルは会話をまたいで保持 |
