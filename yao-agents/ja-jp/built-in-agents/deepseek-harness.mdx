# DeepSeek Harness

![DeepSeek Harness](https://assets.yaoagents.com/en/experts/04-expert-deepseek-harness-en-$__THEME.png)

DeepSeek Harness 搭載の汎用エージェント。コーディング、リサーチ、データ分析、ライティング、自動化——永続サンドボックスですべてを処理。ターミナル、ファイルシステム、ブラウザ、VNC デスクトップを完備。

## 得意なこと

- **コーディング** — あらゆる言語でプログラムの作成・実行・デバッグ・リファクタリング；複雑なプロジェクトの構築と保守
- **リサーチ** — Web スクレイピング、複数ソースからの情報統合、構造化レポートの作成
- **データ分析** — CSV、JSON、Excel ファイルの処理；分析の実行；チャートやダッシュボードの生成
- **ライティング** — レポート、提案書、メール、Markdown/HTML ドキュメントの作成
- **自動化** — スクリプト、CLI ツール、パイプラインを構築し、繰り返し作業を自動化
- **ライブプレビュー** — サンドボックスでアプリやツールを実行し、VNC でリアルタイムに結果を確認

## 仕組み

DeepSeek Harness は永続的な Linux サンドボックスで動作し、フルデスクトップ環境を備えています。ターミナル、ブラウザ、ファイルシステム、ネットワークアクセスがあり、実質的に完全な作業マシンです。

推理エンジンとして DeepSeek V4 Pro または V4 Flash を使用。要件を伝えると、アプローチを計画し、作業を実行し、結果を観察して、満足いくまで繰り返します。

サンドボックスのライフサイクルは `longrunning`——アイドル時に一時停止し、戻ると自動的に再開。コード、ファイル、プロジェクトの状態は会話をまたいで永続的に保存されます。

## プロンプトのコツ

**目標を説明し、手順は説明しない。**「SQLite で Todo を管理する REST API を書いて」で十分です。フレームワークやファイル構造を指定する必要はありません。

**デバッグ時はコンテキストを提供。** エラーメッセージ、関連コード、または両方を貼り付けてください。コンテキストが多いほど修正が速くなります。

**自然に反復。** 最初の結果が出たら、続けてリクエスト：「認証を追加」「パフォーマンスを改善」「テストを書いて」。サンドボックスは状態を保持するので、各リクエストは前回の続きです。

**例：**

> 顧客注文の CSV ファイルを読み込み、地域別の集計レポートを生成する Python スクリプトを書いて。

> この Node.js サーバーをデバッグして——POST リクエストでクラッシュする。エラーメッセージ：[貼り付け]

> この 3 つの URL から商品価格をスクレイピングして JSON ファイルに保存する Web スクレイパーを作って。

> JWT 認証付き Flask API を構築して、SQLite に接続し、ブログの CRUD エンドポイントを追加。

## 機能一覧

| 機能 | 詳細 |
|------|------|
| モデル | DeepSeek V4 Pro / V4 Flash（設定可能） |
| 言語 | Python、Node.js、Bash、およびインストール可能な任意の言語 |
| Web アクセス | ブラウジング、スクレイピング、API 呼び出し |
| ファイル I/O | あらゆるファイル形式に対応 |
| プレビュー | VNC ライブデスクトップ——アプリの実行をリアルタイムで確認 |
| サンドボックス | 永続 Linux デスクトップ、フルターミナルとブラウザ |
| ライフサイクル | 長期実行——アイドル時に一時停止、復帰時に再開 |
| ワークスペース | 永久保存——コードとファイルは会話をまたいで保持 |
