# Slides

アイデア、アウトライン、ドキュメントをプロフェッショナルなプレゼンテーションに変換して PDF として書き出します。トピックを伝えるかコンテンツを貼り付けるだけで、構成、デザイン、出力をすべて担当します。

## 得意なこと

- **デッキ作成** — どんな入力（トピック、箇条書き、ドキュメント、議事録）からも、構造的でデザインされたスライドデッキを構築
- **プロフェッショナルなテーマ** — 9 つの組み込みテーマ：Tech、Business、Science、Nature、Education、Art、Culture、Lifestyle、Health
- **PDF 書き出し** — 16:9 高品質 PDF（1920×1080、2× レティナ）、そのまま共有・プレゼン可能
- **コンテンツ生成** — 組み込み LLM でスライドの内容を執筆・改善（要約・翻訳を含む）
- **リサーチ** — ウェブからコンテンツを取得して最新データでスライドを補足
- **カスタムビジュアル** — 必要に応じてスライド用の画像を生成

## 仕組み

Slides は4段階のワークフローに従います：**アウトライン → コンテンツ → デザイン → 書き出し**。

まず入力に基づいてスライド構成を提案します。承認（または調整）後、各スライドのコンテンツを作成し、選択したテーマを適用、HTML をレンダリングして、レイアウトをスクリーンショットで確認します。最後に PDF に書き出して Workspace にファイルを納品します。

サンドボックスはフル VNC 表示なしの desktop-lite イメージを使用し、ヘッドレスでレンダリングします。ライフサイクルは `oneshot` で会話ごとに新しく開始されます。ファイルは Workspace に保存されてセッションをまたいで永続します。

## 良いプロンプトの書き方

**トピックから始めるかコンテンツを貼り付ける。** Slides が推測する量が少ないほど、構成が良くなります。一行のトピックでも動きますが、議事録を貼り付けるとさらに良い結果が出ます。

**枚数と対象者を指定する。** 「営業チーム向けの製品ローンチ用 10 枚」でSlides は深さとトーンを調整できます。

**好みがあればテーマを指定する。** 指定しなければ Slides がトピックに基づいて選択します——ほとんどのビジネスシーンでは Tech か Business がデフォルトです。

**コンテンツ前にアウトラインを繰り返す。** Slides がすべてのコピーを書く前に構成を変える方が速いです。

**例：**

> 新製品紹介の10枚スライドを作って：AI を活用した分析プラットフォーム。対象：エンタープライズ営業。Business テーマを使用。

> 2026年の AI トレンドについてのプレゼンを作って——8枚、Tech テーマ、一般向け。

> この議事録を6枚のサマリースライドに変換して：[テキスト貼り付け]

> この既存のプレゼンを英語に翻訳して Business テーマで再フォーマットして。

## 機能一覧

| 機能 | 詳細 |
|------|------|
| 入力 | トピック、アウトライン、ドキュメントテキスト、議事録 |
| テーマ | Tech、Business、Science、Nature、Education、Art、Culture、Lifestyle、Health |
| 出力 | HTML デッキ + PDF（16:9、1920×1080、2× レティナ） |
| AI 機能 | コンテンツ執筆、要約、翻訳、ウェブリサーチ、画像生成 |
| サンドボックス | `claude-desktop-lite` イメージ、4 GB RAM、`oneshot` ライフサイクル |
| Workspace | 永続保存——スライドファイルは無期限に保持 |
