# General Assistant

コーディング、リサーチ、データ分析、ライティング、自動化など、あらゆるタスクを処理する万能エージェントです。固定のワークフローはありません。どのエキスパートを使えばいいか分からない時は、ここから始めてください。

## 得意なこと

- **コーディング** — Python、Node.js、Bash、その場でインストールできる任意の言語でコードを書き、実行、デバッグ、リファクタリング
- **リサーチ** — ウェブページのスクレイピング、複数ソースからの情報統合、構造化レポートの生成
- **データ分析** — CSV、JSON、Excel ファイルの処理、統計分析の実行、グラフ生成（matplotlib、plotly）
- **ライティング** — Markdown または HTML でレポート、提案書、メール、ドキュメントを作成
- **ファイル処理** — ファイルの変換、変換、バッチ処理、アーカイブ、整理
- **自動化** — スクリプト、CLI ツール、パイプラインを構築して繰り返しのワークフローを自動化
- **LLM サブタスク** — 組み込み LLM API を呼び出して、より大きなタスクの一部として要約、翻訳、分類、コンテンツ生成を実行

## 仕組み

General Assistant はフルデスクトップと VNC を備えた永続的な Linux サンドボックスで動作します。各セッションでファイルが保持されるため、ゼロから始めることなく複数の会話にわたってプロジェクトを続けることができます。

完全なターミナル、ファイルシステム、ネットワークアクセスを持っています。パッケージをインストールし、サーバーを起動し、VNC デスクトップでブラウザを開き、出力を Workspace に書き戻すことができます。

**Workspace は永続保存されます**——生成したファイル、構築したスクリプト、処理したデータは、どれだけ時間が経っても次に会話を開いたときにそこにあります。基盤となるコンテナはアイドル時に一時停止し、戻ると再起動しますが、ファイルが失われることはありません。

## 良いプロンプトの書き方

General Assistant には定義済みのワークフローがないため、結果の品質はほぼすべてタスクの説明の明確さに依存します。

**出力を具体的に指定する。** 「この記事を要約して」は素早い回答には適しています。「ビジネスへの影響に焦点を当てた3つの箇条書きでこの記事を要約して」はより使いやすい結果を得られます。

**一つのメッセージで仕事全体を説明する。** トピックをリサーチして、レポートを書いて、メールで送ってほしい場合——3つとも同時に言ってください。各ステップをプロンプトする必要なく、シーケンス全体を計画・実行します。

**関連ファイルを添付する。** チャットに直接 PDF、スプレッドシート、画像をドロップしてください。ファイルを読み取ってそのまま作業します——内容をコピペする必要はありません。

**イテレーションする。** 最初の結果はドラフトです。修正、深掘り、フォーマット変更、別のアプローチを依頼してください。会話がワークスペースです。

**効果的なプロンプトの例：**

> 「AI agent frameworks 2025」の上位5件の検索結果をスクレイピングして、主要な機能を抽出し、Markdown 形式の比較表を作成して。

> 添付の sales-report.xlsx を分析して。収益成長率でトップ3の製品を特定して棒グラフを生成し、PNG として保存して。

> 新しい社内ナレッジ共有システムの2ページの提案書を作成して。対象：エンジニアリングマネージャー。トーン：簡潔で直接的。

> フォルダ内の新しい CSV ファイルを監視し、それらを一つのファイルにまとめてサマリーレポートを出力する Python スクリプトを書いて。

## 機能一覧

| 機能 | 詳細 |
|------|------|
| プログラミング言語 | Python、Node.js、Bash、インストール可能な任意の言語 |
| ウェブアクセス | ページのスクレイピング、コンテンツ取得、リンクの追跡 |
| ファイル I/O | CSV、JSON、Excel、PDF、画像、テキストの読み書き |
| 可視化 | matplotlib、plotly、ECharts |
| LLM サブ呼び出し | 組み込み API 経由で要約、分類、翻訳 |
| サンドボックス | 永続的な Linux デスクトップ、VNC、フルターミナル |
| Workspace | 永続保存——ファイルは会話をまたいで無期限に保持 |
