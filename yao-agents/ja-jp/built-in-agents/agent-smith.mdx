# Agent Smith（専属エキスパート作成）

![Agent Smith](https://assets.yaoagents.com/en/experts/02-agent-smith-en-$__THEME.png)

要件を伝えるだけで、カスタムAIエキスパートを作成・調整・デプロイ。コーディング不要、技術知識不要——あなたが説明し、Agent Smith が実現します。

## 得意なこと

- **ゼロからエキスパートを作成** — 欲しいエキスパートを説明すれば（例：「株式アナリスト」）、自動で構築
- **既存スキルの再利用** — グローバルスキルライブラリ（10万以上）から適切なソリューションを自動検索
- **セキュリティ審査** — 外部スキルのインストール前に安全性と互換性を自動チェック
- **テスト検証** — 機能が正常か自動テスト、不合格なら修正して再テスト
- **サンドボックス実テスト** — サンドボックスのデスクトップで実際に動かしてテスト
- **ワンクリックデプロイ** — テスト完了後すぐにデプロイ、即利用可能

## どんなエキスパートが作れるか

- **データ分析** — 株価チェック、決算解読、データレポート生成
- **コンテンツ作成** — 業界レポート、プレゼン資料、マーケティングコピー
- **情報処理** — ファイル形式変換、画像文字認識、バッチデータ整理
- **リサーチ** — 競合分析、市場調査、技術評価
- **業務効率化** — メール整理、進捗追跡、業務報告書作成

上記に限らず、明確に説明できれば何でも作れます。

## 仕組み

Agent Smith はフルデスクトップ付きのサンドボックス環境で動作し、ターミナル・ファイルシステム・ブラウザを備えています。ワークフロー：

1. 要件を分析
2. グローバルスキルライブラリで再利用可能なソリューションを検索
3. エキスパートのコア機能を構築
4. 自動テストを実行し、機能を確認
5. サンドボックスで実際に動かして確認
6. デプロイ

一言で開始し、あとは結果を待つだけ。不明点があればAgent Smithが確認してきます。

Docker サンドボックスが有効でない場合、タスクは Yao Engine がインストールされたマシン上で直接実行されます。

## プロンプトの書き方

**新規作成：**

> 株式アナリストを作って。Kラインとファンダメンタルズが見れるやつ

> 議事録エキスパートを作って。文字起こしテキストを入れたら構造化された議事録を出力するやつ

**改善：**

> 株式アナリストの回答が冗長すぎる、調整して

> 競合分析エキスパートにPPT生成機能を追加して

**既存スキルを探す：**

> PDF解析の既存スキルある？探してインストールして

> Webスクレイピングのスキルを探して、リサーチエキスパートに入れて

**テストとプレビュー：**

> このエキスパートが正常に動くかテストして

> ブラウザで結果を確認したい、プレビューを開いて

**デプロイ：**

> テスト完了、デプロイして

> このエキスパートを公開して、チームで使いたい
