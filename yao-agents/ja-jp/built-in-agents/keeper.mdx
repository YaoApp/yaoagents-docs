# Keeper

あなたのナレッジハブ。ウェブページ、メモ、調査資料、ファイルなど何でも保存して、後からすぐ見つけられます。Keeper が自動で読み取り、タグ付け、整理するので、手動での管理は不要です。

## 得意なこと

- **ウェブページの保存** — URL を貼り付けるだけで、Keeper が全文を抽出して保存し、検索可能にします
- **メモ・調査資料の保存** — テキスト断片、議事録、調査結果を貼り付けると自動で分類・タグ付け
- **ファイルの取り込み** — PDF やドキュメントをアップロードすると、内容を読み取ってインデックスを作成
- **コレクションへの整理** — フラットなリストではなく、トピックや種類ごとにグループ化
- **検索・取り出し** — キーワード、タグ、または自然言語で保存済みコンテンツを横断検索

## 仕組み

Keeper は会話型のナレッジストアです。URL、テキスト、ファイルを渡すと、自動で保存・分類・タグ付けします。各エントリにはメタデータ（ソース、日付、トピック、種類）が付与され、後から見つけやすくなります。

検索は自然言語に対応しています。「先月保存した競合他社の価格に関するもの」と聞けば、Keeper がインデックスを検索して関連エントリを返します。

サンドボックスコンテナはありません。Keeper は軽量 Agent として動作し、Workspace に紐付いた構造化ナレッジストアに保存します。データは会話をまたいで永続します。

## 良いプロンプトの書き方

**要約ではなくソースを渡す。** URL を貼り付けるかファイルを添付して、読み取りは Keeper に任せましょう。自分で要約する必要はありません。

**意図的にタグを指定する。** プロジェクトやトピック別に整理したい場合は明示してください：「これを保存して Q2 研究のタグを付けて」。自動タグ付けもしますが、指定したラベルが優先されます。

**自然言語で検索する。** 探しているものを普通に説明するだけでOK：「MUJI について保存したもの」や「pricing タグが付いたエントリをすべて表示して」。

**例：**

> https://www.bcg.com/publications/2025/ai-agent-trends を研究コレクションに保存して、AI strategy タグを付けて。

> この議事録を保存して、product と Q2 のタグを付けて：[テキスト貼り付け]

> 過去2週間に保存した競合他社の価格に関するエントリを検索して。

> サプライチェーン混乱について何を保存しているか教えて。

## 機能一覧

| 機能 | 詳細 |
|------|------|
| 入力方法 | URL 貼り付け、テキスト入力、ファイルアップロード |
| ファイル形式 | PDF、ドキュメント、プレーンテキスト |
| 整理方法 | 自動タグ付け、トピック分類、コレクション管理 |
| 検索 | キーワード検索、タグフィルター、自然言語クエリ |
| サンドボックス | コンテナなし——軽量 Agent、永続ナレッジストア |
| Workspace | ナレッジストアは永続保存、会話をまたいで利用可能 |
