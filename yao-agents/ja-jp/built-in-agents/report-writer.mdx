# Report Writer

生データや要件を、構造的でプロフェッショナルにフォーマットされた Markdown レポートに変換します。Report Writer はパイプライン Agent です——AI エキスパートのチャットリストには表示されません。Robot の作成・編集時に、エキスパート割り当てリストや実行パイプラインのステージ置き換えドロップダウンで見つかります。

## できること

- 上流パイプラインステージの出力を受け取る（データ、調査結果、メモ、分析結果）
- 完全で構造的な Markdown レポートを作成
- 見出し階層、箇条書き、表、ブロック引用を自動的に整理
- 複数のレポートフォーマットに対応：競合分析、技術評価、週次サマリー、議事録など
- レポートタイプに応じてエグゼクティブサマリー、結論、推奨事項のセクションを追加

## Robot での使い方

Robot を作成または編集する際に、**設定 → 詳細 → 実行パイプライン**を開きます。各ステージには Agent ドロップダウンがあります。**Delivery** ステージを **Report Writer** に設定してください。

それ以降、Robot が実行されるたびに Report Writer がパイプラインの累積出力を受け取り、フォーマット済み Markdown レポートを作成して Robot の受信者に配信します。

> **ヒント：** レポートの品質は Robot のタスク説明に依存します。レポートの種類（「週次サマリー」「競合分析」）と必要なセクション（エグゼクティブサマリー、推奨事項）を Robot のタスク説明または Identity プロンプトに直接含めてください。

## 機能一覧

| 機能 | 詳細 |
|------|------|
| 役割 | パイプライン Agent——Robot ステージ選択に表示 |
| 典型的なステージ | Delivery |
| 入力 | 上流パイプラインステージからの出力 |
| レポートタイプ | リサーチ、競合分析、技術評価、議事録、週次/月次サマリー |
| 出力 | 構造化 Markdown レポート、Robot の受信者に転送 |
| サンドボックス | コンテナなし——軽量 Agent |
