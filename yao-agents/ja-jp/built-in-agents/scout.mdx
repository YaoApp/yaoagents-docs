# Market Scout

マーケットインテリジェンスフィード。ニュースサイト、業界ブログ、競合ページなどのソースを購読すると、Market Scout が自動的に監視し、最新コンテンツを取得・分類して、マーケットリサーチコレクションに整理します。

## 得意なこと

- **ソース監視** — 購読フィードを定期的にチェックして新しいコンテンツを取得
- **コンテンツ分類** — 業界、トピック、関連性でタグ付け、手動ソート不要
- **トレンド分析** — 複数ソースにわたるパターンを識別し、新興テーマを浮き彫りに
- **ブリーフィング** — すべての監視ソースにわたる日次または週次インテリジェンスサマリーを作成
- **オンデマンドクエリ** — トピックについて質問し、収集データから関連エントリを取得

## 仕組み

Market Scout はスケジュールまたはオンデマンドで、設定済みの購読ソースからコンテンツを読み取ります。新しいコンテンツを取得すると、各記事をトピックと関連性で分類し、**マーケットリサーチ**コレクションに保存します。

サンドボックスコンテナはなく、軽量 Agent として動作します。収集したすべてのインテリジェンスは会話をまたいでナレッジストアに永続します。

大量監視の場合は、Market Scout を Mission Control のスケジュール済み Robot と組み合わせてください——毎日実行するよう設定すれば、手動でトリガーすることなくコレクションが自動更新されます。

## 良いプロンプトの書き方

**ソースから始める。** 初回は Scout にどのウェブサイトやフィードを監視するか伝えてください：「これら3つの URL を監視リストに追加して」。その後は「更新を確認して」で十分です。

**取得時はスコープを絞る。** 「今週の AI Agent フレームワークの最新情報は？」や「先月のサプライチェーンに関する記事を探して」で検索が絞り込まれます。

**ブリーフィングを依頼する。** 「今日のマーケットサマリーをください」はすべてのソースのダイジェストを素早く得る方法です。

**例：**

> 監視リストにこれらのソースを追加して：https://techcrunch.com、https://www.theinformation.com、https://news.ycombinator.com

> すべての購読ソースから今日の更新を取得して。

> AI インフラの最新トレンドは？

> 今週収集したすべてのコンテンツの週次ブリーフィングをください。

> 過去2週間の競合他社の価格設定や資金調達に関する記事を探して。

## 機能一覧

| 機能 | 詳細 |
|------|------|
| 入力 | 購読 URL、オンデマンドトピッククエリ |
| 分類 | 業界、トピック、関連性で自動タグ付け |
| 出力 | マーケットリサーチコレクション |
| ブリーフィング形式 | 日次ダイジェスト、週次サマリー |
| サンドボックス | コンテナなし——軽量 Agent、永続ナレッジストア |
| Workspace | ナレッジストアは永続保存、会話をまたいで利用可能 |
