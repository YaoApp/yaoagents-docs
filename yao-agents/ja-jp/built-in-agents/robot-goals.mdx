# Robot Goals Agent

Goals Agent は Inspiration レポート（または手動トリガー入力）を受け取り、明確な戦略的目標のセットに変換します——各目標には明確な目的、具体的な成果物、Validation ステージが確認できる成功基準が含まれます。

これはパイプラインステージ Agent です。AI エキスパートのチャットリストには表示されません。Robot の詳細設定で Goals ステージの Agent を置き換える際に、**実行パイプライン**ドロップダウンで見つかります。

## できること

- Inspiration ステージ（時間トリガー）、ユーザートリガー（手動タスク）、または外部イベントトリガーからの入力を受け取る
- 高レベルの意図を戦略的目標に変換——タスクや指示ではない
- 各目標で指定：何を達成するか、何が生成されるか、成功をどう測定するか
- Goals を利用可能なリソースにマッピングして Tasks Agent が何を使えるかを把握させる

目標は意図的に高レベルに保たれます。次のステージの Tasks Agent が実行可能なステップに分解する役割を担います。

## 目標 vs. タスク——違い

| | 目標（このステージ） | タスク（次のステージ） |
|---|---|---|
| レベル | 戦略的——何を達成するか | 戦術的——どのように達成するか |
| 例 | 「トレンド分析付きの月次売上レポートを作成する」 | 「data-analyst を呼び出して1月の売上データをクエリする」 |
| 実行者 | 未指定 | 特定の Agent または MCP ツール |

## トリガータイプ

Goals Agent は3つの入力シナリオを処理します：

- **時間トリガー** — 前のステージから Inspiration レポートを受け取る
- **人的トリガー** — Robot Host から確認済み目標の説明を受け取る（手動タスク割り当て）
- **イベントトリガー** — 外部システムからの構造化イベントペイロードを受け取る（例：`lead.created`、`order.placed`）

## 機能一覧

| 機能 | 詳細 |
|------|------|
| Agent タイプ | `robot-goals`——パイプラインステージ Agent |
| 置き換え可能 | 可——Goals ステージのドロップダウンで選択可能 |
| 入力 | Inspiration レポート、人的タスク説明、またはイベントペイロード |
| 出力 | 成果物と成功基準を持つ優先度付き戦略的目標リスト |
| サンドボックス | コンテナなし |
