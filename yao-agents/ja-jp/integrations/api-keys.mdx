# API キー

> **エンタープライズプランのみ。** API キー管理にはエンタープライズサブスクリプションが必要です。[エンタープライズについて](/enterprise)

API キーを生成して、外部コード・スクリプト・連携システムからロボットを呼び出す際の認証に使用します。

## はじめる前に

API キーの管理には、アカウントで **二要素認証（2FA）** を有効にしている必要があります。2FA が未設定の場合、このページにアクセスすると設定を促すメッセージが表示されます。

まず **設定 → セキュリティ** から 2FA を有効にしてください。

## API キーの作成

1. **設定 → API キー** に移動します。
2. 任意の名前を入力します（例：「本番環境」「CI/CD パイプライン」）。
3. **新しいキーを作成** をクリックします。
4. キーをすぐにコピーしてください——ページを離れると値の一部がマスクされます。

![設定 — API キーページ](https://placehold.co/1200x750/1a1a2e/ffffff?text=Screenshot+needed%3A+Settings+%E2%86%92+API+Keys)

> ⚠️ 完全なキー値は一度しか表示されません。パスワードと同様に安全に保管してください。

## キーの使用方法

すべての API リクエストの `Authorization` ヘッダーにキーを含めます：

```
Authorization: Bearer <YOUR_API_KEY>
```

完全なエンドポイントリファレンスとコード例は [API ダイレクト接続](/docs/ja-jp/integrations/api-direct-connect) を参照してください。

## キーの管理

各キーには以下の情報が表示されます：

| フィールド | 説明 |
|-----------|------|
| 名前 | 作成時に付けたラベル |
| キー | マスクされた値（`sk-xxx...xxxx`）、コピーと表示ボタン付き |
| ステータス | `アクティブ` または `無効` |
| 作成日時 | 作成された日付 |
| 最終使用 | 最後にリクエストした日付、または「なし」 |

キーを**削除**するには、キーカードの削除アイコンをクリックして確認します。削除は即時に有効になり、取り消せません——そのキーを使用しているすべてのコードが直ちに動作しなくなります。
