# Larkに接続する

ロボットをLark（Feishu）に接続すると、チームメンバーがディレクトリでロボットを見つけて直接メッセージを送れます。

LarkオープンプラットフォームでBotアプリを作成し、必要な権限を付与して、App IDとApp SecretをYao Agentsの統合パネルに貼り付けます。

## 始める前に

- ロボットがMission Controlで作成済みであること。
- Lark組織の管理者アクセス権（アプリの作成と公開のため）。

## ステップ 1 — Larkアプリを作成する

1. [Lark Open Platform](https://open.larksuite.com/)（中国本土の場合は [Feishu Open Platform](https://open.feishu.cn/)）を開いてログインします。
2. **開発者コンソール → アプリを作成 → カスタムアプリ** に移動します。
3. アプリ名と説明を入力し、**作成** をクリックします。
4. アプリダッシュボードで **認証情報と基本情報** に移動し、**App ID** と **App Secret** をコピーします。

> 💡 App Secretは作成後に一度しか表示されません。すぐにコピーして安全に保管してください。

![Larkオープンプラットフォーム — アプリ認証情報ページ](https://placehold.co/1200x750/1a1a2e/ffffff?text=Screenshot+needed%3A+Lark+app+credentials+page)

## ステップ 2 — Bot機能を有効にする

アプリダッシュボードで：

1. **機能 → Bot** に移動します。
2. Bot機能を有効にします。
3. オプションで、ユーザーがLarkで見るBot名とアイコンを設定します。

## ステップ 3 — 権限を追加する

アプリダッシュボードの **権限とスコープ** で以下を追加します：

- `im:message` — Botへのメッセージを受信
- `im:message:send_as_bot` — Botとしてメッセージを送信

## ステップ 4 — Yao Agentsに認証情報を貼り付ける

1. Mission Controlでロボットの **設定 → 統合** パネルを開きます。
2. **Lark** カードを展開し、トグルを **オン** にします。
3. ステップ1で取得した **App ID** と **App Secret** を貼り付けます。
4. **接続を確認** をクリック——アプリ名が緑色で表示されれば成功です。

![ロボット統合パネル — Larkカード](https://placehold.co/1200x750/1a1a2e/ffffff?text=Screenshot+needed%3A+Robot+Integration+panel+%E2%80%94+Lark+card)

## ステップ 5 — イベントサブスクリプションエンドポイントを設定する

Larkアプリダッシュボードに戻り：

1. **イベントサブスクリプション** に移動します。
2. **リクエストURL** を以下に設定します：
   ```
   https://<Yao Agentsサーバーアドレス>/v1/agent/robots/<robot_id>/connector/feishu
   ```
   `<Yao Agentsサーバーアドレス>` をサーバーの公開アドレスに、`<robot_id>` をMission Controlに表示されているロボットIDに置き換えてください。
3. イベントを購読します：**メッセージ受信（im.message.receive_v1）**。
4. 保存して確認——LarkはURLにテストリクエストを送信して到達可能か確認します。

## ステップ 6 — アプリを公開する

**バージョン管理とリリース** でバージョンを作成してレビューを申請します（社内アプリは通常自動承認されます）。

公開後、チームメンバーはLarkディレクトリでBotを見つけて直接メッセージを送れます。

## トラブルシューティング

**確認に失敗する。**
App IDが `cli_` で始まる長い文字列であることを確認してください（App Keyではありません）。必要に応じてApp Secretを再生成してください。

**Lark URLの確認に失敗する。**
Yao AgentsサーバーはパブリックインターネットからアクセスできるURLが必要です。ローカルでテストする場合はトンネリングツール（ngrokなど）を使用してください。

**ユーザーがLarkでBotを見つけられない。**
アプリが公開されて組織で利用可能になっていないと、メンバーはディレクトリで検索できません。
