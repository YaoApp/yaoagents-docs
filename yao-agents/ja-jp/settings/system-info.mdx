# システム情報

**システム情報**パネルには、Yao Agents のバージョン番号と実行環境が表示されます。設定ページから開くことができます。

![設定 — システム情報](https://assets.yaoagents.com/en/settings/01-config-system-info-en-$__THEME.png)

## 表示内容

| 項目 | 説明 |
|------|------|
| Yao Agents | Yao Agents デスクトップアプリケーションのバージョン。 |
| Yao Engine | 基盤となる Yao Engine ランタイムのバージョン。 |
| CUI | CUI（Chat UI）コンポーネントのバージョン。 |
| Environment | 現在の実行モード — `Development` または `Production`。 |

## 確認すべきタイミング

- **バグを報告する前に** — Issue にバージョン番号を記載してください。
- **アップデート後に** — すべてのコンポーネントが正常に更新されたことを確認してください。
- **トラブルシューティング時** — サポートからバージョン情報を求められる場合があります。
