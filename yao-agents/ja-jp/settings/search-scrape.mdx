# 検索とスクレイピング

**検索 & スクレイピング**パネルでは、AI エキスパートが使用する Web 検索およびページスクレイピングのプロバイダーを設定します。エキスパートがオンラインで情報を調べたり、URL からコンテンツを抽出したりする際に、ここで設定されたプロバイダーが使用されます。

![設定 — 検索 & スクレイピング](https://assets.yaoagents.com/en/settings/07-config-search-en-$__THEME.png)

## 対応プロバイダー

| プロバイダー | 種類 | 機能 |
|------------|------|------|
| [Tavily](https://tavily.com) | 検索 | AI に最適化された Web 検索 API。LLM がすぐに利用できる構造化された結果を返します。 |
| [Serper](https://serper.dev) | 検索 | Google 検索 API。高速かつ低コストで、標準的な検索結果を返します。 |
| [Brightdata](https://brightdata.com) | スクレイピング | Web スクレイピングとデータ収集。単純なフェッチではブロックされるページからコンテンツを抽出します。 |

## セットアップ

1. 使用したいプロバイダーにサインアップします。
2. プロバイダーのダッシュボードから API キーをコピーします。
3. Yao Agents で**設定 → 検索 & スクレイピング**を開きます。
4. プロバイダーを選択し、API キーを貼り付けます。
5. **保存**をクリックします。

## エキスパートの利用方法

最新の情報が必要な質問を AI エキスパートにすると、自動的に以下の処理が行われます：

1. 設定された検索プロバイダーを呼び出して、関連するページを検索します。
2. スクレイピングプロバイダーが設定されている場合、それらのページからコンテンツ全文を抽出します。
3. 結果を統合して回答を生成します。

すべてのプロバイダーを設定する必要はありません。ほとんどのユースケースでは、検索プロバイダーだけで十分です。特定の Web サイトから詳細なコンテンツを抽出するワークフローがある場合に、スクレイピングプロバイダーを追加してください。
