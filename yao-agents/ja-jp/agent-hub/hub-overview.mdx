# Yao Agents Hub

Yao Agents Hub は、AIエキスパートを発見・インストール・共有できるオープンマーケットプレイスです。あらゆるワークフローに対応した専門エキスパートが揃っています。

> **アーリーアクセス（Early Access）。** Yao Agents Hub は現在アーリーアクセス段階です。正式公開は近日予定しています。

## 組み込みエキスパート

Yao Agentsにはすぐに使える組み込みエキスパートが揃っています。

| エキスパート | 得意なこと |
|------------|-----------|
| [General](/docs/ja-jp/built-in-agents/general) | 汎用アシスタント——Q&A、コーディング、調査、ライティング |
| [PM](/docs/ja-jp/built-in-agents/pm) | プロジェクト管理——タスク分解、進捗追跡、チーム連携 |
| [Postman](/docs/ja-jp/built-in-agents/postman) | メールアシスタント——SMTP/IMAPでの送受信・作成 |
| [Insights](/docs/ja-jp/built-in-agents/insights) | データ分析——データベース、スプレッドシート、EChartsダッシュボード |
| [Market Scout](/docs/ja-jp/built-in-agents/scout) | マーケット情報——フィード監視、記事分類・整理 |
| [Slides](/docs/ja-jp/built-in-agents/slides) | スライド作成——アウトラインからHTMLプレゼン、PDFエクスポート |
| [Transformer](/docs/ja-jp/built-in-agents/transformer) | データ構造化——画像・PDF・JSON・CSV変換 |
| [Web Builder](/docs/ja-jp/built-in-agents/website) | ウェブサイト構築——Next.js + Tailwind、VNCプレビュー + SSHデプロイ |
| [Applet Workshop](/docs/ja-jp/built-in-agents/applet) | ミニアプリ開発——Node.jsビジュアルツール、VNCライブプレビュー |
| [Report Writer](/docs/ja-jp/built-in-agents/report-writer) | レポート作成ロボット——Mission Controlで構造化Markdownレポートを自動生成 |
