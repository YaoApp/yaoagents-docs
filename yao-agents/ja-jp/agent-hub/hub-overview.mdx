# エキスパートマーケットプレイス

エキスパートマーケットプレイスは、AIエキスパートを発見・インストール・共有する場所です。ワークフローに合ったエキスパートを見つけて、ワンクリックでインストール。

> **アーリーアクセス（Early Access）。** エキスパートマーケットプレイスは現在アーリーアクセス段階です。正式公開まもなく。

## 組み込みエキスパート

Yao Agentsには、すぐに使えるエキスパートがプリインストールされています。

| エキスパート | 得意なこと |
|------------|-----------|
| [General](/docs/ja-jp/built-in-agents/general) | 汎用アシスタント——Q&A、コーディング、リサーチ、ライティング |
| [Agent Smith](/docs/ja-jp/built-in-agents/agent-smith) | 専属エキスパート作成——要件を伝えて自動構築・テスト・デプロイ |
| [PM](/docs/ja-jp/built-in-agents/pm) | プロジェクトマネージャー——タスク分解、進捗管理、チーム連携 |
| [Postman](/docs/ja-jp/built-in-agents/postman) | メールアシスタント——SMTP/IMAPでメールの作成・送受信 |
| [Insights](/docs/ja-jp/built-in-agents/insights) | データ分析——データベース、スプレッドシート、EChartsダッシュボード |
| [Slides](/docs/ja-jp/built-in-agents/slides) | スライド作成——アウトラインからHTMLプレゼン、PDF出力 |
| [Transformer](/docs/ja-jp/built-in-agents/transformer) | データ構造化——画像・PDF・JSON・CSVをVision LLMで変換 |
| [Web Builder](/docs/ja-jp/built-in-agents/website) | ウェブサイト構築——Next.js + Tailwind、VNCプレビュー + SSHデプロイ |
| [Applet Workshop](/docs/ja-jp/built-in-agents/applet) | ミニアプリ——Node.jsビジュアルツール、VNCライブプレビュー |
