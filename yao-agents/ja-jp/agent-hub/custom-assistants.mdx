# カスタムAIエキスパート

Yao Agentsには組み込みのAIエキスパートが揃っていますが、必要に応じて独自のエキスパートを作成できます。

## 1. Agent Smithで構築

Agent Smithを開いて、作りたいエキスパートを説明するだけ。スキルライブラリの検索、構築、テスト、デプロイまで自動で行います。コード不要。

Agent Smithはグローバルスキルライブラリ（10万以上）とサードパーティエコシステムから既製ソリューションを自動検索し、セキュリティ審査後にあなたの要件に合わせて適用します。

→ [Agent Smith 詳細](/docs/ja-jp/built-in-agents/agent-smith)

## 2. コードで作成

Yao DSLを使って独自のAIエキスパートを記述し、プロンプト・ツール・サンドボックス・動作を完全にコントロールできます。

→ [はじめてのAgent作成](https://yaoapps.com/docs/tutorials/en-us/agent/getting-started/index) — YaoApps.comのステップバイステップチュートリアル
