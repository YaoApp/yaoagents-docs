# カスタムAIエキスパート

Yao Agentsには組み込みのAIエキスパートが揃っていますが、独自のエキスパートを追加することもできます。以下に追加方法をご紹介します。

## 1. Yao Agents Hubからインストール

Yao Agents Hubでコミュニティが作成した既製エキスパートを探し、ワンクリックでインストールできます。

> **アーリーアクセス（Early Access）。** Yao Agents Hub は現在アーリーアクセス段階です。

## 2. AI開発エキスパートに作ってもらう

内蔵のAI開発エキスパートを開き、作りたい専門家の役割を説明するだけ。設定の生成からインストールまで自動で行います——コード不要。

> **アーリーアクセス（Early Access）。** この機能は現在アーリーアクセス段階です。

## 3. コードで作成

Yao DSLを使って独自のAIエキスパートを記述し、プロンプト・ツール・サンドボックス・動作を完全にコントロールできます。

→ [はじめてのAgent作成](https://yaoapps.com/docs/tutorials/en-us/agent/getting-started/index) — YaoApps.comのステップバイステップチュートリアル

## 4. サードパーティエコシステムを探す

Yao Agentsはオープンコミュニティエコシステムのエージェントと互換性があります。以下のプラットフォームで閲覧し、対応するエージェントをYao Agents向けに適用できます。

- [ClawHub](https://clawhub.ai/) — コミュニティ製スキルとプラグイン
- [Hermes Agent Skills Hub](https://hermes-agent.nousresearch.com/docs/skills) — Nous Researchが管理するオープンエージェントスキルレジストリ

> **アーリーアクセス（Early Access）。** サードパーティエコシステム連携は現在アーリーアクセス段階です。これらは独立したコミュニティであり、一部のエージェントは適用に調整が必要な場合があります。
