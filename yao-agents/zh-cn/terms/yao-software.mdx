1.5 **"凭据"**：指您为第三方模型、Tao 服务或设备连接所配置的 API Key、令牌、Server Key 等。

## 第五条 Tai Link 与设备连接

5.1 Tai Link 用于让您的 Yao Agents 实例连接并操作您授权连接的其他设备。

5.2 **仅限您有权控制的设备。** 您不得使用 Tai Link 连接、访问或操作您不拥有或未获合法授权的设备或数据。

5.3 连接在 Tai Link 与您的 Yao Agents 实例之间建立（通过加密的 gRPC 隧道；在生产环境中应启用 TLS 以实现端到端加密）。我们不会访问或存储您设备之间的连接内容。

5.4 **高风险能力。** Host Exec 等直接在宿主系统执行命令的能力默认关闭；开启后由您自行配置访问策略并承担相应风险。建议在共享设备上使用权限受限的专用账号运行 Tai Link。

5.5 您应妥善保管 Server Key、OAuth 令牌等凭据，并在设备丢失、转让或人员变动时及时吊销。
