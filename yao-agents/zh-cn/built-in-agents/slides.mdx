# Slides

将想法、大纲或文档转化为精美的演示文稿并导出为 PDF。给 Slides 一个主题或粘贴你的内容——它负责结构、设计和输出。

## 擅长做什么

- **制作幻灯片** — 接受任意输入（主题、要点列表、文档、会议记录）并构建结构完整、设计精良的演示文稿
- **专业主题** — 9 个内置主题：Tech、Business、Science、Nature、Education、Art、Culture、Lifestyle、Health
- **PDF 导出** — 1920×1080 高质量 16:9 PDF（2× 视网膜屏），可直接分享或演示
- **内容生成** — 使用内置 LLM 撰写和润色幻灯片内容，包括摘要和翻译
- **资料搜集** — 可抓取网络内容，用最新数据补充你的幻灯片
- **自定义视觉** — 按需为幻灯片生成图片

## 工作原理

Slides 遵循四阶段工作流：**大纲 → 内容 → 设计 → 导出**。

首先根据你的输入提出幻灯片结构。经你确认（或调整）后，为每张幻灯片撰写内容，应用所选主题，渲染 HTML，并截图验证布局。最后导出为 PDF 并将文件交付到 Workspace。

沙箱使用 desktop-lite 镜像，没有完整的 VNC 显示——渲染为无头模式。生命周期为 `oneshot`，每次对话重新开始。文件保存到 Workspace 并跨会话持久保留。

## 怎么写好 Prompt

**从主题开始或粘贴你的内容。** Slides 需要猜测的越少，结构越好。一行主题就够；粘贴会议记录效果更好。

**说明长度和受众。** "10 张幻灯片用于产品发布，受众是销售团队"给了 Slides 足够的上下文来校准深度和语气。

**如果有偏好，指定主题。** 否则 Slides 根据主题自动选择——大多数专业场合默认是 Tech 或 Business。

**在生成内容前迭代大纲。** 在 Slides 写好所有文案之前调整结构更快捷。

**示例：**

> 制作一个 10 张幻灯片的演示文稿，介绍我们的新产品：一个 AI 驱动的分析平台。受众：企业销售。使用 Business 主题。

> 制作一个关于 2026 年 AI 趋势的演示——8 张幻灯片，Tech 主题，面向普通受众。

> 将这些会议记录转化为 6 张幻灯片的摘要：[粘贴记录]

> 将这个现有演示文稿翻译成英文并重新设计为 Business 主题。

## 能力速览

| 能力 | 说明 |
|------|------|
| 输入 | 主题、大纲、文档文本、会议记录 |
| 主题 | Tech、Business、Science、Nature、Education、Art、Culture、Lifestyle、Health |
| 输出 | HTML 幻灯片 + PDF（16:9，1920×1080，2× 视网膜屏） |
| AI 功能 | 内容撰写、摘要、翻译、网络搜索、图片生成 |
| 沙箱 | `claude-desktop-lite` 镜像，4 GB 内存，`oneshot` 生命周期 |
| Workspace | 永久存储——幻灯片文件无限期保留 |
