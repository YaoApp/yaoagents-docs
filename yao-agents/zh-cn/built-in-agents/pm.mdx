# Project Manager

无需手动维护即可保持项目井然有序。扫描邮件、粘贴指令或上传文件——Project Manager 自动读取并更新对应的项目记录、日志和时间线。

## 擅长做什么

- **邮件分类** — 扫描邮件文件夹，找出与项目相关的邮件，自动路由到正确的项目
- **创建项目** — 一条指令即可生成完整的文件夹结构（README、干系人列表、时间线、日志）
- **更新项目** — 自动追加日志条目、刷新状态、更新里程碑、复制新附件，无需手动操作
- **干系人管理** — 追踪每个项目的参与者，保持联系方式和角色信息最新
- **汇总报告** — 日报摘要、周报、单项目深度分析、跨项目状态看板和干系人简报
- **查询** — 用自然语言提问任意项目，返回结构化 Markdown 报告

## 工作原理

Project Manager 使用基于 Workspace 的项目存储。每个项目位于 `projects/YYYY/project-name/`，包含 `README.md`、`people.md`、`timeline.md`、`logs/` 和 `attachments/` 目录。日志条目按日期组织在 `logs/` 内。

扫描邮件时，它读取邮件文件夹中的 `INDEX.md` 进行高效分类，深度读取相关邮件，然后自动创建或更新匹配的项目。不需要分别触发创建和更新——扫描会自动串联执行。

沙箱运行 `oneshot`——每次对话使用全新容器，没有后台状态。所有项目记录保存在 Workspace 中，跨会话持久保留。

如果未启用 Docker 沙箱，任务将直接在安装 Yao Engine 的机器上执行。

## 怎么写好 Prompt

**扫描邮件时，指定文件夹。** 告诉 Project Manager 要扫描哪个日期文件夹："扫描今天的邮件。"它负责分类处理。

**手动更新时，尽量具体。** "在 Acme 网站项目记录一通与 Alice 的电话，她确认了 5 月 31 日的截止日期。"这样的描述足以生成一条完整的日志。

**请求报告时，说清楚你要什么。** "生成本周的报告"或"总结 Acme 项目"就够了——它知道各种格式。

**示例：**

> 扫描今天的邮件并按项目分类。

> 创建新项目：Acme 网站改版。负责人：Alice。截止日期：5 月 31 日。预算：5 万美元。

> 在 Acme 改版项目记录一次与 Bob（ACME）的会议。我们审查了首页设计稿并批准了配色方案。下一步：Alice 在周五前发送最终素材。

> 生成本周的项目汇总报告。

> 当前所有活跃项目的状态是什么？

## 能力速览

| 能力 | 说明 |
|------|------|
| 邮件扫描 | 基于 INDEX.md 的 IMAP 分类，自动路由到项目 |
| 项目结构 | README、干系人、时间线、日志、附件——全部自动生成 |
| 报告类型 | 日报摘要、周报、项目概览、状态看板、干系人简报 |
| 查询 | 自然语言提问 → 结构化 Markdown 报告 |
| 沙箱 | `claude` 镜像（无 VNC），2 GB 内存，`oneshot` 生命周期 |
| Workspace | 永久存储——所有项目记录无限期保留 |
