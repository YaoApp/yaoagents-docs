# DeepSeek Harness

![DeepSeek Harness](https://assets.yaoagents.com/en/experts/04-expert-deepseek-harness-en-$__THEME.png)

基于 DeepSeek Harness 的通用智能体。编程、研究、数据分析、写作、自动化——在持久化沙箱中完成一切，终端、文件系统、浏览器和 VNC 桌面全部就绪。

## 擅长什么

- **编程** — 编写、运行、调试和重构任何语言的程序；搭建和维护复杂项目
- **研究** — 抓取网页、综合多源信息、生成结构化报告
- **数据分析** — 处理 CSV、JSON、Excel 文件；运行分析；生成图表和看板
- **写作** — 撰写报告、方案、邮件、Markdown 或 HTML 文档
- **自动化** — 构建脚本、CLI 工具和流水线，将重复工作自动化
- **实时预览** — 在沙箱中运行应用和工具，通过 VNC 实时查看结果

## 工作原理

DeepSeek Harness 运行在持久化的 Docker 沙箱中，配备完整桌面环境。拥有终端、浏览器、文件系统和网络访问——相当于一台完整的工作机器。

它使用 DeepSeek V4 Pro 或 V4 Flash 作为推理引擎。你描述需求，它规划方案、执行工作、观察结果并反复迭代，直到满意为止。

沙箱生命周期为 `longrunning`——空闲时暂停，回来时自动恢复。代码、文件和项目状态跨对话永久保存。

如果未启用 Docker 沙箱，任务将直接在安装 Yao Engine 的机器上执行。

## 使用技巧

**描述期望的结果和约束。** 告诉它完成后应该是什么样，加上边界条件。不要指挥怎么做——让它自己规划路径。"找出哪些产品在拉动营收增长，按地区拆分给我看"就够了。

**提前给足上下文。** 附上文件、粘贴截图、引用工作区内已有的文档，或详细描述当前状况。上下文越充分，来回沟通的轮次越少。

**复杂任务分阶段推进。** 先让它调研，再制定方案，最后执行。避免一上来就干错方向。例如："先看看这个表格有什么数据，然后建议可以做哪些分析。"

**给出可验证的完成标准。** 如果你能描述"做对了是什么样"——特定格式的文件、展示某个趋势的图表、包含特定章节的报告——就直接说。它会在交付前自行检查。

**持续对话，不断推进。** 每条消息都基于之前的完整上下文。直接说"加一个同比对比"或"再精简一些"——它保留完整语境，从上一步接着做。

**示例：**

> 调研 [行业] 排名前 5 的竞争对手，整理他们的定价模式，生成对比表格。

> 分析附件的 sales-report.xlsx。哪些产品增速最快？做一个包含关键指标的数据看板。

> 为 [主题] 撰写一份项目方案。受众：管理层。控制在 3 页以内，附时间表和预算估算。

> 每日监控这个 RSS 源，汇总与 [话题] 相关的内容，并保存到日志文件中。
