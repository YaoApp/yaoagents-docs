# Market Scout

你的市场情报信息流。订阅信息源——新闻网站、行业博客、竞品页面——Market Scout 自动监控、获取最新内容、分类整理，汇入你的市场研究集合。

## 擅长做什么

- **信息源监控** — 定期检查订阅的信息源，获取新内容
- **内容分类** — 按行业、主题和相关性自动打标签，无需手动整理
- **趋势分析** — 识别多个信息源中的模式，发现新兴主题
- **简报** — 生成跨所有监控信息源的日报或周报摘要
- **按需查询** — 按主题提问，从已收集的数据中获取相关条目

## 工作原理

Market Scout 按计划或按需从你配置的订阅信息源读取内容。获取新内容后，按主题和相关性分类每篇文章，然后存入你的**市场研究**集合（也可通过 Keeper 访问）。

Market Scout 没有沙箱容器，作为轻量级 Agent 运行。所有收集的情报跨对话持久保存在知识库中。

大量监控场景下，将 Market Scout 与 Mission Control 中的定时 Robot 配合使用——设置为每天运行，它会自动更新你的集合，无需手动触发。

## 怎么写好 Prompt

**从信息源开始。** 第一次使用时，告诉 Scout 要监控哪些网站或信息源："把这三个 URL 添加到我的监控列表。"之后"检查更新"就够了。

**检索时缩小范围。** "本周 AI Agent 框架有什么新动态？"或"查找过去一个月关于供应链的文章"能让搜索结果更精准。

**请求简报。** "给我今天的市场摘要"是快速获取所有信息源摘要的方法。

**示例：**

> 把这些信息源添加到我的监控列表：https://techcrunch.com，https://www.theinformation.com，https://news.ycombinator.com

> 从所有订阅信息源获取今天的更新。

> AI 基础设施领域的最新趋势是什么？

> 给我本周收集的所有内容的周报摘要。

> 查找过去两周关于竞品定价或融资的文章。

## 能力速览

| 能力 | 说明 |
|------|------|
| 输入 | 订阅 URL、按需主题查询 |
| 分类 | 按行业、主题和相关性自动打标签 |
| 输出 | 市场研究集合（与 Keeper 共享） |
| 简报格式 | 日报摘要、周报 |
| 沙箱 | 无容器——轻量级 Agent，知识库持久存储 |
| Workspace | 知识库永久保存，跨对话持续可用 |
