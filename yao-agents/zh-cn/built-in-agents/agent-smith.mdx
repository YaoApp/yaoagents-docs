# Agent Smith（打造专属专家）

![Agent Smith](https://assets.yaoagents.com/en/experts/02-agent-smith-en-$__THEME.png)

说出你的需求，它来创建、调优并上线你的专属 AI 专家。不用写代码，不用懂技术——你描述，它实现。

## 擅长做什么

- **从零创建专家** — 告诉它你要什么样的专家（比如"股票分析专家"），它自动完成搭建
- **搜索现成能力** — 自动从全球技能库（10 万+）中找到合适的方案，直接复用
- **安全审查** — 外部技能安装前自动检查安全性和兼容性
- **测试验证** — 自动测试功能是否正常，不通过就改到通过
- **浏览器预览** — 在沙箱桌面打开浏览器，实时查看效果
- **一键上线** — 测好后直接部署，你和团队马上就能用

## 能做哪些类型的专家

- **数据分析专家** — 看股票行情、解读财报、生成数据报告
- **内容创作专家** — 行业报告、演示文稿、营销文案
- **信息处理专家** — 转换文件格式、识别图片文字、整理批量数据
- **研究调研专家** — 竞品分析、市场调研、技术方案评估
- **办公效率专家** — 整理邮件、跟踪进度、生成工作汇报

不限于以上类型，只要你说得清楚，它都可以做。

## 工作原理

Agent Smith 运行在一个带完整桌面的沙箱环境中，有终端、文件系统、浏览器。它的工作流程：

1. 分析你的需求
2. 搜索全球技能库中有没有现成方案可以复用
3. 搭建专家的核心能力
4. 自动运行测试，确保功能正常
5. 打开浏览器预览，供你确认效果
6. 部署上线

整个过程你只需要说一句话启动，然后等结果。中间有问题它会问你。

如果未启用 Docker 沙箱，任务将直接在安装 Yao Engine 的机器上执行。

## 怎么写好 Prompt

**新建专家：**

> 帮我做一个股票分析专家，能看 K 线和基本面

> 做一个会议纪要专家，输入录音文字就能输出结构化纪要

**改进现有专家：**

> 我的股票分析专家回答太啰嗦了，帮我调一下

> 给竞品分析专家加上生成 PPT 的能力

**找现成技能：**

> 有没有现成的 PDF 解析技能？帮我搜一下装上

> 搜一下有没有爬网页的技能，装到我的调研专家里

**测试和预览：**

> 帮我测一下这个专家能不能正常工作

> 我想在浏览器里看看效果，打开预览

**上线发布：**

> 测好了，帮我上线

> 把这个专家部署上去，我和团队要用

## 能力速览

| 能力 | 说明 |
|------|------|
| 创建专家 | 根据描述自动搭建完整的 AI 专家 |
| 技能复用 | 从全球 10 万+ 技能库中搜索并安装现成能力 |
| 安全审查 | 安装外部技能前自动进行安全检查 |
| 自动测试 | 内置测试流程，确保专家功能可用 |
| 浏览器预览 | 沙箱内打开浏览器，实时查看专家效果 |
| 一键部署 | 测试通过后直接上线，立即可用 |
| 沙箱 | 持久化 Docker 桌面，完整开发环境 |
