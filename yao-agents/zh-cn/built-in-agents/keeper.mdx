# Keeper

你的知识中心。保存任何内容——网页、笔记、研究资料、文件——随时找回。Keeper 自动阅读、打标签、分类整理，你不需要手动操作。

## 擅长做什么

- **保存网页** — 粘贴 URL，Keeper 自动提取全文内容并存档，支持搜索
- **存储笔记和研究资料** — 粘贴文字片段、会议记录或研究发现，Keeper 自动分类打标签
- **文件摄取** — 上传 PDF、文档等文件，Keeper 读取并建立索引
- **整理到集合** — 按主题和类型分组，不是简单堆成一个列表
- **检索** — 用关键词、标签或自然语言搜索所有存档内容

## 工作原理

Keeper 是对话式知识库。你把内容交给它——URL、一段文字、一个文件——它自动保存、分类、打标签。每条记录都带有元数据（来源、日期、主题、类型），方便日后查找。

搜索支持自然语言。你可以问"上个月我保存的竞品定价内容"，Keeper 会在索引里查找并返回相关条目。

没有沙箱容器——Keeper 是轻量级 Agent，背后是绑定到你 Workspace 的结构化知识库。数据跨对话持久保存。

## 怎么写好 Prompt

**给来源，不要给摘要。** 直接粘贴 URL 或上传文件，让 Keeper 自己读。不需要你先总结内容。

**主动指定标签。** 如果你想按项目或主题整理，说出来："保存这个，打上 Q2 研究的标签。"Keeper 也会自动打标签，但你指定的优先。

**用自然语言检索。** 描述你要找什么就行："我保存过的关于 MUJI 的内容"或"所有打了 pricing 标签的条目"。

**示例：**

> 把 https://www.bcg.com/publications/2025/ai-agent-trends 保存到我的研究集合，打上 AI strategy 标签。

> 存这条会议记录，打上 product 和 Q2 标签：[粘贴内容]

> 搜索我最近两周保存的竞品定价相关内容。

> 我保存过哪些关于供应链中断的内容？

## 能力速览

| 能力 | 说明 |
|------|------|
| 输入方式 | URL 粘贴、文本输入、文件上传 |
| 文件类型 | PDF、文档、纯文本 |
| 整理方式 | 自动打标签、主题分类、集合管理 |
| 检索 | 关键词搜索、标签筛选、自然语言查询 |
| 沙箱 | 无容器——轻量级 Agent，知识库持久存储 |
| Workspace | 知识库永久保存，跨对话持续可用 |
