# Claude Code

![Claude Code](https://assets.yaoagents.com/en/experts/05-expert-claude-code-en-$__THEME.png)

基于 Claude Code 的通用智能体。编程、研究、数据分析、写作、自动化——在复杂推理、长上下文理解和精细执行方面表现尤为出色。

## 擅长什么

- **编程** — 构建完整应用、重构代码库、调试、维护复杂多文件项目
- **研究** — 抓取网页、综合多源信息、生成结构化报告
- **数据分析** — 处理 CSV、JSON、Excel 文件；运行分析；生成图表和看板
- **写作** — 撰写报告、方案、文档和 API 规范，表达精准细腻
- **自动化** — 构建脚本、CLI 工具和流水线，将重复工作自动化
- **实时预览** — 在沙箱中运行和测试一切，配备完整 VNC 桌面

## 工作原理

Claude Code 运行在与 DeepSeek Harness 相同的持久化 Docker 沙箱中——完整桌面、终端、文件系统、浏览器和 VNC。不同之处在于模型：它使用 Claude 进行推理，在复杂决策、长上下文理解和精细执行方面表现出色。

你描述任务，Claude Code 规划方案、执行工作并验证结果。对于大型任务，它会将工作拆分为步骤，逐步检验后再继续。

沙箱生命周期为 `longrunning`——空闲时暂停，回来时自动恢复。你构建的一切跨对话永久保存。

如果未启用 Docker 沙箱，任务将直接在安装 Yao Engine 的机器上执行。

## 使用技巧

**说清结果和约束。** 不要一步步指挥，描述你希望完成后是什么样，加上边界条件。"把这份 50 页 PDF 总结为 2 页管理层摘要，聚焦财务风险"比"先读第 1 页，再读第 2 页"好得多。

**复杂任务让它先问你。** 对于非简单任务，先给个简要描述，让它向你提问。它会帮你发现你没想到的边界情况和取舍。

**先调研，再方案，再执行。** 大任务时把研究和行动分开。让它先理解情况、提出计划，你确认后再动手。避免白做功。

**给出可验证的成功标准。** 如果你能描述"正确"是什么样——具体数字、格式要求、跟参照物对比——就写进去。它会在交付前自行校验。

**持续对话，不断推进。** 每条消息都基于之前的完整上下文。引用工作区内的文档、追问、调整结果。"把刚才的分析做成幻灯片"——完整语境还在，直接接着做。

**示例：**

> 阅读附件的合同 PDF。提取所有义务条款、截止日期和违约罚则，整理成结构化表格。标出 30 天内到期的事项。

> 调研 [公司名]——财务状况、近期新闻、竞争格局。生成一页纸的投资备忘录，附带建议。

> 我有过去一个月的会议纪要（附件）。找出反复出现的议题、未完成的待办，起草一份给管理层的状态报告。

> 分析我们的客服工单（附件 CSV）。找出投诉量最高的 5 个类别，建议流程改进方案，并估算影响。
