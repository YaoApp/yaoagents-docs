# 连接第一台设备

配置 Tai Link，通过 Server Key 将远程机器接入 Yao Agents。

## 准备

- 目标机器已[安装 Tai Link](/docs/zh-cn/tai-link/installation)。
- 一台正在运行的 Yao Engine 服务器（Yao v1.0.0-rc10+），目标机器能通过网络访问。

## 第 1 步 — 创建 Server Key

如果已有 Server Key 可直接复用——同一个 Key 支持多台设备同时使用。否则新建一个：

在 Yao Engine 界面底部点击 **Open Terminal**。

![Yao Engine — 点击 Open Terminal](https://assets.yaoagents.com/en/engine/02-engine-start-en-$__THEME.png)

运行：

```bash
yao server-key create --name "my-node"
```

输出：

```
  Server key created successfully

  Key ID:  sk-a1b2c3d4e5f6
  Name:    my-node
  Key:     yao-sk:64-char-hex-string...

  ⚠ Save this key now. It will not be shown again.
```

复制完整 Key（`yao-sk:...`），第 2 步会用到。

## 第 2 步 — 编写配置文件

在目标机器上创建 `config.yml`：

**macOS / Linux:**

```yaml
yao:
  server: "<YOUR_YAO_SERVER>"
  node_id: "my-node"
  display_name: "Office Server"
  server_key: "yao-sk:your-key-here"

data: /path/to/your/data

host_exec:
  only: true
  full_access: true

log:
  level: info
```

**Windows:**

```yaml
yao:
  server: "<YOUR_YAO_SERVER>"
  node_id: "my-node"
  display_name: "Office Server"
  server_key: "yao-sk:your-key-here"

data: "C:\\TaiData"

host_exec:
  only: true
  full_access: true

log:
  level: info
  file: logs/tai.log
```

| 字段 | 说明 |
|------|------|
| `yao.server` | Yao Agents 服务器地址。在 Yao Engine 欢迎页可以看到，与客户端登录地址相同。 |
| `yao.node_id` | 节点唯一标识。多台设备之间不能重复。 |
| `yao.display_name` | 在 Yao Agents 界面中显示的名称。 |
| `yao.server_key` | 第 1 步创建的 Server Key。 |
| `data` | 工作空间数据目录，Agent 在此读写文件。Windows 路径需使用双反斜杠（`\\`）。 |
| `host_exec.only` | 宿主机执行模式——Agent 直接在本机执行命令，不使用 Docker 容器。 |
| `host_exec.full_access` | 不限制命令和路径，允许完全访问。 |

## 第 3 步 — 启动 Tai Link

```bash
tai server --config config.yml
```

正常启动后会看到类似输出：

```
level=INFO msg="logger initialized" level=info format=text file=logs/tai.log
level=INFO msg="tai server" module=server version=1.8.6 ...
level=INFO msg="tai server starting" module=server grpc=[127.0.0.1:0] ...
```

Tai Link 通过 Server Key 自动认证，无需浏览器登录。设备会在几秒内出现在 Yao Agents 界面中。

## 第 4 步 — 确认连接

点击顶部导航栏的 **电脑**，打开电脑面板。新设备应显示为 **Running**。

![Tai Link — 设备面板](https://assets.yaoagents.com/en/tai/01-tai-devices-en-$__THEME.png)

创建工作区时，即可选择该节点作为执行环境。

## 管理 Server Key

列出所有 Key：

```bash
yao server-key list
```

吊销 Key：

```bash
yao server-key revoke sk-a1b2c3d4e5f6
```

## 常见问题

**设备没有出现在 Tai Link 面板。**
检查目标机器能否访问 Yao 服务器，确认防火墙未拦截出站连接。查看 Tai Link 终端的错误信息。

**设备显示"Offline"但 Tai Link 正在运行。**
隧道可能断开了。Tai Link 会自动重连（指数退避）。检查网络并稍等片刻。
