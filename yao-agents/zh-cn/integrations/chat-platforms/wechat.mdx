# 连接微信

将机器人接入微信，用户直接在微信里发消息即可对话——对方无需安装任何额外软件。

微信通过 **ClawBot 插件**接入，这是微信官方插件体系中的一个渠道插件，由腾讯提供支持。连接后，机器人以一个微信号的身份在线，用户添加好友后即可开始聊天。

## 开始之前

- 机器人已在 Mission Control 中创建。
- 准备一个专用微信号（个人账号即可，不需要公众号或小程序）。
- 微信客户端：请升级到最新版本（iOS / Android 均支持）。
- 运行 Yao Agents 的服务器在扫码期间及机器人运行时需保持联网。

## 第一步 — 打开集成面板

1. 在 Mission Control 中点击要连接的机器人。
2. 进入 **配置 → 集成** 标签页。
3. 找到 **微信** 卡片，将开关打开。

![Mission Control — 集成面板，微信卡片](https://placehold.co/1200x750/1a1a2e/ffffff?text=Screenshot+needed%3A+Robot+Integration+panel+%E2%80%94+WeChat+card)

## 第二步 — 扫码连接

点击 **扫码连接**，弹出含有连接码的对话框。

在手机微信中，按以下路径打开 ClawBot 插件：

**我 → 设置 → 插件 → 微信 ClawBot → 详情**

在 ClawBot 插件详情页，点击 **开始扫一扫**，扫描 Mission Control 页面上显示的二维码。

> 💡 二维码有效期为 3 分钟。超时后关闭对话框重新打开即可刷新。

**首次连接时**，微信会提示你授权 ClawBot 插件访问该账号，确认授权后连接即建立。

扫码成功后，对话框自动关闭，卡片显示 **已连接** 及微信账号名。

## 第三步 — 保存

点击 **保存**（配置面板顶部保存按钮）。机器人现在已在微信上线。

用任意手机向该微信号发消息，机器人即会回复。

## 重新连接

若连接中断（例如服务器重启后），打开集成面板，点击微信卡片上的 **重新连接** 重新扫码即可。

## 常见问题

**弹出"ClawBot 插件未安装"或"不支持该功能"。**
当前微信版本不满足要求，请将微信升级到最新版本后重试。

**扫码后"已连接"状态一直不出现。**
确认使用了 iOS 8.0.70+ 的微信，且已授权 ClawBot 插件。确认该账号未在其他设备上同时登录。

**机器人过一段时间后停止回复。**
微信会话可能超时，重新扫码连接即可。建议保持 Yao Agents 服务器持续运行以避免中断。

**提示"已在其他设备登录"。**
先在其他设备退出该微信账号，再重新扫码。
