# AI 专家

Yao Agents 内置多位 AI 专家，各自专精一类工作。选对专家，说出需求，剩下的交给它。

![AI 专家列表](https://assets.yaoagents.com/en/experts/03-experts-full-en-$__THEME.png)

### DeepSeek Harness

基于 DeepSeek Harness 的通用智能体。编程、研究、数据分析、写作、自动化——在持久化沙箱中完成，终端、浏览器、VNC 桌面一应俱全。

![DeepSeek Harness](https://assets.yaoagents.com/en/experts/04-expert-deepseek-harness-en-$__THEME.png)

[查看详情 →](/docs/zh-cn/built-in-agents/deepseek-harness)

### Claude Code

基于 Claude Code 的通用智能体。编程、研究、数据分析、写作、自动化——同样配备持久化沙箱和实时预览。

![Claude Code](https://assets.yaoagents.com/en/experts/05-expert-claude-code-en-$__THEME.png)

[查看详情 →](/docs/zh-cn/built-in-agents/claude-code)

### Agent Smith

打造你的专属 AI 专家。描述你的需求，Agent Smith 会自动搜索技能、组装专家、在沙箱中测试，然后上线到你的专家列表。

![Agent Smith](https://assets.yaoagents.com/en/experts/06-expert-agent-smith-en-$__THEME.png)

[查看详情 →](/docs/zh-cn/built-in-agents/agent-smith)

### Web Builder

用对话构建并部署网站。Next.js + Tailwind，VNC 实时预览，一键 SSH 部署并自动配置 HTTPS。

![Web Builder](https://assets.yaoagents.com/en/experts/07-expert-web-builder-en-$__THEME.png)

[查看详情 →](/docs/zh-cn/built-in-agents/website)

### Applet Workshop

描述一个工具，直接得到可运行的应用。计算器、看板、转换器、AI 工具——在桌面上实时构建和预览。

![Applet Workshop](https://assets.yaoagents.com/en/experts/08-expert-applet-workshop-en-$__THEME.png)

[查看详情 →](/docs/zh-cn/built-in-agents/applet)

### Slides

输入主题、大纲或文档，生成精美幻灯片。9 套内置主题，1920×1080 PDF 导出。

![Slides](https://assets.yaoagents.com/en/experts/09-expert-slides-en-$__THEME.png)

[查看详情 →](/docs/zh-cn/built-in-agents/slides)

### Insights

连接数据库或拖入表格，Insights 设计指标、构建交互式 ECharts 看板，并实时预览。

![Insights](https://assets.yaoagents.com/en/experts/10-expert-insights-en-$__THEME.png)

[查看详情 →](/docs/zh-cn/built-in-agents/insights)

## 如何选择专家

在主页打开 **AI 专家** 面板，通过分类标签筛选或搜索名称。

## 切换模型

默认使用你设置的主模型。对话过程中可通过底部的模型选择器随时切换。

![模型选择器](https://assets.yaoagents.com/en/chat/08-chat-model-picker-en-$__THEME.png)
