# Yao Agents 是什么

智能体与工作空间统一管理，跑在你自己的设备上。看板追踪任务进度，桌面、手机、浏览器、API 随时掌控。私有部署，数据不出门。

![工作原理](https://assets.yaoagents.com/en/architecture/01-how-it-works-en-$__THEME.png)

智能体在专用设备上并发运行，你连多少台，它们就同时在多少台上干活。一个应用统管全部。加电脑，就是加生产力。

[下载](/download) · [安装指南](/docs/zh-cn/getting-started/installation)

## 为什么选择 Yao Agents

在电脑、手机或浏览器上告诉智能体要做什么，它们在你的设备上同时开工，你该干嘛干嘛。

### 工作空间

每个工作区都是隔离的空间，不同工作各占一处、互不干扰，多台电脑统一管理。工作沉淀成文档，攒成你的知识库。

智能体工作时，可跨节点读取需要的资料。

![工作空间](https://assets.yaoagents.com/en/workspace/01-workspace-index-en-$__THEME.png)

### 任务看板

在对话里说出你想做的事，智能体会把它变成一个任务，放进看板。持续对话、反复执行，越用越好用，成为一个专门处理此类任务的智能体。

还可以把任务智能体接入自己的应用，分享给更多人使用。

![任务看板](https://assets.yaoagents.com/en/kanban/09-kanban-daily-en-$__THEME.png)

### 开放接口

专家智能体、任务智能体，都能接入你自己的应用和业务。接口兼容 API 标准，支持 SSE，同时支持 WebSocket。

让智能体融入你的业务，哪里需要它，它就在哪里。

![开放接口](https://assets.yaoagents.com/en/openapi/01-openapi-task-en-$__THEME.png)
