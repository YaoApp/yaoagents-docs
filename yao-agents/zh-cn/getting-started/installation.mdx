# 安装

前往[下载页面](/download)获取 Yao Engine，选择对应平台和架构。

## 第一步：启动 Yao Engine

安装完成后打开 Yao Engine，主窗口会显示 Yao 和 Tai 两个服务。

![Yao Engine](https://assets.yaoagents.com/en/engine/01-engine-app-en-$__THEME.png)

> **注意：** 首次启动时，App Root 需指向一个空目录。版本要求 Yao Agents v1.6.1+。

点击 **Start**，启动后会显示各服务的 PID 和访问地址。

![Yao Engine 运行中](https://assets.yaoagents.com/en/engine/02-engine-start-en-$__THEME.png)

## 第二步：打开欢迎页

点击 **Visit**，浏览器会打开欢迎页面，点击 **Get Started** 继续。

![欢迎页](https://assets.yaoagents.com/en/engine/03-engine-visit-en-$__THEME.png)

## 第三步：登录

**首次登录**使用内置管理员账号：

- **邮箱：** `root@yaoagents.com`
- **密码：** `Yao123++`

![登录](https://assets.yaoagents.com/en/engine/05-engine-login-code-en-$__THEME.png)

> **注意：** 账号存储在本地设备上。如需注册其他用户，请先配置 SMTP 邮箱服务，否则无法接收注册验证码。

## 第四步：配置模型

点击侧边栏左下角头像，进入 **设置 → 模型配置**。

![模型配置](https://assets.yaoagents.com/en/engine/06-engine-models-en-$__THEME.png)

| 槽位 | 用途 |
|------|------|
| Default | 日常通用任务 |
| Heavy | 复杂推理、长上下文 |
| Light | 快速简单查询 |
| Vision | 图片识别 |
| Audio | 语音转文字 |
| Embedding | 向量检索、知识库 |

> **注意：** DeepSeek 系列模型不支持图片和语音。使用 DeepSeek 时，请为 Vision 槽位配置其他模型（如 Claude、GPT-4o），Audio 槽位配置 Whisper 语音转录模型。

点击 **Add Provider** 添加模型服务商，填入凭据。

![添加服务商](https://assets.yaoagents.com/en/engine/07-engine-provider-add-en-$__THEME.png)

> **提示：** 添加 image2（OpenAI 兼容接口）的文生图/图生图模型后，Agent 在工作中如需生成或编辑图片会自动调度。

选择默认模型。

![配置完成](https://assets.yaoagents.com/en/engine/08-engine-provider-default-en-$__THEME.png)

## 第五步：安装桌面客户端

桌面客户端适合日常使用，和浏览器互不冲突。

前往[客户端下载页](/download/yaoagents)下载安装。打开后填入服务器地址（与浏览器登录地址相同），点击 **Connect**。登录方式与浏览器一致。

![添加服务器](https://assets.yaoagents.com/en/servers/02-servers-add-en-$__THEME.png)

> **提示：** 右键点击托盘图标可切换服务器、进入设置等。
