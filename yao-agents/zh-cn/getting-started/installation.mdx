# 安装

大约十分钟，让 Yao Agents 在你的机器上跑起来。

## 你要安装什么

| 组件 | 作用 | 是否必需 |
|------|------|---------|
| **Yao Engine** | 驱动一切的本地服务器 | 必需 |
| **Yao Agents** | 你每天使用的客户端应用 | 必需 |
| **Tai Link** | 连接其他设备，让 AI 在远程设备上工作 | 按需 |

安装顺序：先装 Yao Engine，再装 Yao Agents，最后按需安装 Tai Link。

---

## 第一步 — 安装 Yao Engine

Yao Engine 是整个系统的核心，其他组件都连接到它。不同平台的安装方式有所区别，选择你的平台：

### macOS

从 [yaoagents.com/download](https://yaoagents.com/download) 下载并运行 Yao Engine 安装包。

| 架构 | 适用机型 |
|------|---------|
| Apple Silicon (arm64) | M1 / M2 / M3 / M4 Mac |
| Intel (x86_64) | 较旧款 Mac |

1. **安装 Yao Engine** — 运行安装包并启动 Yao Engine，你将看到引擎状态窗口。

   ![Yao Engine 运行中 — Application 标签页显示状态和服务地址](https://assets.yaoagents.com/en/engine/01-engine-app-en-$__THEME.png)

2. **启动服务** — 点击引擎窗口中的 **Start Server**。启动后点击 **Visit**，在浏览器中打开欢迎页，确认一切正常。

   ![浏览器中的 Yao Engine 欢迎页](https://assets.yaoagents.com/en/website/02-web-welcome-en-$__THEME.png)

3. **安装 Docker Desktop** — 从 [docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/) 下载并安装。

4. **拉取沙盒镜像**：
   ```bash
   docker pull yaoapp/tai-sandbox-claude:latest
   docker pull yaoapp/tai-sandbox-claude-ssh:latest
   docker pull yaoapp/tai-sandbox-claude-desktop-lite:latest
   docker pull yaoapp/tai-sandbox-claude-desktop-lite-ssh:latest
   docker pull yaoapp/tai-sandbox-claude-desktop:latest
   docker pull yaoapp/tai-sandbox-claude-desktop-ssh:latest
   ```

### Windows

Yao Engine 在 Windows 上运行于 WSL2 环境中。请先配置好环境，再安装 Yao Engine。

1. **启用 WSL2 并安装 Ubuntu** — 以管理员身份打开 PowerShell，运行：
   ```powershell
   wsl --install
   ```
   按提示重启电脑，然后打开 Ubuntu 应用完成初始设置（用户名和密码）。

2. **安装 Docker Desktop** — 从 [docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/) 下载并安装。在 **Docker Desktop → Settings → Resources → WSL Integration** 中启用 WSL2 集成。

3. **拉取沙盒镜像**：
   ```bash
   docker pull yaoapp/tai-sandbox-claude:latest
   docker pull yaoapp/tai-sandbox-claude-ssh:latest
   docker pull yaoapp/tai-sandbox-claude-desktop-lite:latest
   docker pull yaoapp/tai-sandbox-claude-desktop-lite-ssh:latest
   docker pull yaoapp/tai-sandbox-claude-desktop:latest
   docker pull yaoapp/tai-sandbox-claude-desktop-ssh:latest
   ```

4. **安装 Yao Engine** — 从 [yaoagents.com/download](https://yaoagents.com/download) 下载 Windows 安装包并运行，启动 Yao Engine，你将看到引擎状态窗口。

   ![Yao Engine 运行中（Windows）](https://placehold.co/1200x750/1a1a2e/ffffff?text=Screenshot+needed%3A+Yao+Engine+on+Windows)

5. **启动服务** — 点击 **Start Server**，然后点击 **Visit**，在浏览器中打开欢迎页，确认一切正常。

   ![浏览器中的 Yao Engine 欢迎页](https://assets.yaoagents.com/en/website/02-web-welcome-en-$__THEME.png)

### Linux

Linux 安装面向开发者和自托管场景，请参考 Yao Engine 文档站的完整指引：

[Yao Engine 文档 → yaoapps.com/docs](https://yaoapps.com/docs)

### 沙盒镜像

每个沙盒镜像都是一个 Docker 容器，AI Task Agent 在其中运行。按需拉取即可。

| 镜像 | 桌面 | SSH | 适用 Agent |
|------|------|-----|-----------|
| `tai-sandbox-claude` | — | — | Postman、PM、Market Scout 及大多数 Agent |
| `tai-sandbox-claude-ssh` | — | ✓ | 需要连接远程服务器的 Agent |
| `tai-sandbox-claude-desktop-lite` | 轻量 | — | 不需要完整桌面的浏览器任务 |
| `tai-sandbox-claude-desktop-lite-ssh` | 轻量 | ✓ | 同上，额外支持远程服务器访问 |
| `tai-sandbox-claude-desktop` | 完整（XFCE）| — | Applet Workshop |
| `tai-sandbox-claude-desktop-ssh` | 完整（XFCE）| ✓ | Web Builder（构建、测试、部署）|

所有镜像支持 `linux/amd64` 和 `linux/arm64`。→ [沙盒镜像参考](/docs/zh-cn/resources/sandbox-images)

## 第二步 — 安装 Yao Agents

Yao Agents 是客户端应用，这是你每天使用的界面。

从 [yaoagents.com/download](https://yaoagents.com/download) 下载并运行对应平台的安装包。

> 💡 不确定选哪个 macOS 版本？Apple Silicon = M1/M2/M3/M4，Intel = 较旧款 Mac。

首次打开 Yao Agents，添加你的 Yao Engine：

1. 进入 **Settings → Engine**
2. 输入服务器地址 — 如果 Yao Engine 运行在同一台机器上，默认地址为 `http://localhost:5099`
3. 点击 **Connect** — 连接成功后状态指示灯变绿

![Yao Agents 设置 — Engine 标签页，填写服务器地址](https://placehold.co/1200x750/1a1a2e/ffffff?text=Screenshot+needed%3A+Settings+%E2%86%92+Engine)

连接成功后，系统会提示登录。使用默认账号：

- **邮箱：** `root@yaoagents.com`
- **密码：** `Yao123++`

> 💡 首次登录后，请在 **Settings → Account** 修改密码。

![Yao Agents 登录界面](https://placehold.co/1200x750/1a1a2e/ffffff?text=Screenshot+needed%3A+Login+screen)

登录后，你将进入主界面。

![Yao Agents 主界面 — 空白对话，随时可以开始](https://assets.yaoagents.com/en/chat/01-chat-empty-en-$__THEME.png)

## 第三步 — 连接 AI 模型

Yao Agents 需要接入 AI 模型才能工作。最简单的方式是使用 **Yao Agents 服务**——由团队托管的托管 API，登录即可使用，无需额外配置。

### 方案 A — Yao Agents 服务（推荐）

1. 访问 [yaoagents.com](https://yaoagents.com) 并登录
2. 在 **API Keys** 页面复制你的 API Key

   ![Yao Agents 控制台 — API Keys 页面](https://assets.yaoagents.com/en/console/02-console-keys-en-$__THEME.png)

3. 在 Yao Engine 的 **Models** 标签页中粘贴 Key

   ![Yao Engine — Models 标签页，填写 API Key](https://assets.yaoagents.com/en/engine/03-engine-models-en-$__THEME.png)

该服务支持 Claude、GPT-4o、DeepSeek 等模型——按量计费，无需订阅。

### 方案 B — 自带密钥（BYOK）

想用自己的 LLM 账号？在 Yao Engine → **Models** 中设置自定义 API 端点和 Key，支持任何兼容 OpenAI 接口的提供商：Anthropic、OpenAI、DeepSeek、Ollama（本地）等。

> 💡 **不确定选哪个？** 先用 Yao Agents 服务——这是最快能跑起来的路径。随时可以在 Yao Engine → Models 切换到 BYOK。

模型连接成功后，就可以开始工作了。

## 常见问题

**Yao Agents 提示"Engine not running"**
确保 Yao Engine 已打开并运行。点击菜单栏中的引擎图标查看状态。如果无法启动，检查端口 5099 是否被其他进程占用。

**运行 Robot 时提示"Docker not found"**
安装 [Docker Desktop](https://www.docker.com/products/docker-desktop/) 并确保它正在运行。Windows 用户请先配置好 WSL2。

**Yao Agents 无法连接远程引擎**
如果 Engine 运行在单独的服务器上，在 Yao Agents 的 **Settings → Engine** 中输入服务器地址。
