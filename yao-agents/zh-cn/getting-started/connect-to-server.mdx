# 连接到服务器

本指南帮助你将 Yao Agents 客户端连接到服务器。

## 第一步：获取服务器地址

访问[服务器](/servers)页面，找到离你最近的服务器，复制服务器地址。

## 第二步：打开 Yao Agents

在你的设备上启动 Yao Agents 桌面应用。

## 第三步：配置服务器

进入 **设置 → 服务器**，粘贴你复制的服务器地址。

## 第四步：登录或注册

如果服务器需要邀请码，请在[服务器](/servers)页面申请。否则直接创建账号。
