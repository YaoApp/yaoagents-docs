# 连接云服务器

Yao Agents 默认连接本地 Yao Engine（Local Server）。如果你不想在自己设备上安装 Engine，也可以直接连接一台云端服务器——登录后即可使用全部 AI 专家，无需任何本地配置。

## 本地 vs 云端

| | 本地 (Local Server) | 云端 (Cloud Server) |
|---|---|---|
| 需要安装 Yao Engine | 是 | 否 |
| 数据存储 | 全部在你的设备上 | 存储在服务器端 |
| AI 模型 | 自带 Key 或接入云服务 | 服务器预配置 |
| Tai Link 节点 | 自行连接 | 服务器提供共享节点 |
| 适合场景 | 追求隐私、长期使用 | 快速体验、团队共享 |

## 连接步骤

### 1. 选择服务器

打开 Yao Agents 客户端，首次启动会看到服务器选择页面。默认已有 **Local Server**。点击 **Add server** 添加一台云端服务器。

![服务器选择](https://assets.yaoagents.com/en/servers/01-servers-select-en-$__THEME.png)

### 2. 填写服务器地址

在弹出的表单中填入服务器的 URL 和名称。可以在 [/servers](/servers) 页面找到可用的服务器列表及地址。

![添加服务器](https://assets.yaoagents.com/en/servers/02-servers-add-en-$__THEME.png)

### 3. 选择并连接

添加成功后，服务器列表中会出现新增的云端服务器。点击它进入连接流程。

![服务器列表](https://assets.yaoagents.com/en/servers/03-servers-added-en-$__THEME.png)

### 4. 登录

输入邮箱，获取验证码，完成登录。部分服务器可能需要邀请码——可在 [/servers](/servers) 页面查看申请方式。

![登录页面](https://assets.yaoagents.com/en/servers/04-servers-login-en-$__THEME.png)

### 5. 开始使用

登录成功后直接进入主界面，所有 AI 专家已就绪。操作方式和使用本地服务器完全一样——选择专家、发起对话、创建任务。

![云端主界面](https://assets.yaoagents.com/en/servers/05-servers-main-en-$__THEME.png)

## 切换服务器

你可以随时在服务器之间切换。点击客户端左上角的服务器名称，即可回到服务器选择页面，在本地和云端之间自由切换。

## 可用服务器

访问 [/servers](/servers) 页面查看当前可用的云端服务器、地域、注册方式和配置详情。
