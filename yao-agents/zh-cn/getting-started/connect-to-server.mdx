# 连接云服务器

Yao Agents 默认连接本地 Yao Engine（Local Server）。如果不打算在自己设备上安装 Engine，可以直接连一台云端服务器——登录后即可使用全部 AI 专家，无需任何本地配置。

## 本地 vs 云端

| | 本地 (Local Server) | 云端 (Cloud Server) |
|---|---|---|
| 需要安装 Yao Engine | 是 | 否 |
| 数据存储 | 全部在你的设备上 | 存储在服务器端 |
| AI 模型 | 自带 Key 或接入云服务 | 服务器预配置 |
| Tai Link 节点 | 自行连接 | 服务器提供共享节点 |
| 适合场景 | 追求隐私、长期使用 | 快速体验、团队共享 |

## 连接步骤

### 1. 选择云服务器

打开客户端，在服务器选择窗口的 **Cloud Servers** 标签里选一台云端服务器（如 Polaris (Trial Server) `https://bj.yaoagents.cn`）。

![选择云服务器](https://assets.yaoagents.com/en/login/login-cloud-servers-en-$__THEME.png)

也可以切到 **Custom Server** 标签，自己填服务器地址。

![自定义服务器](https://assets.yaoagents.com/en/login/login-custom-server-url-en-$__THEME.png)

### 2. 连接

点 **Connect**。部分服务器需要邀请码，可在站点申请。

### 3. 登录 / 注册

先填你自己的邮箱，通过验证码验证，点 **Continue**。

![输入邮箱](https://assets.yaoagents.com/en/servers/04-servers-login-en-$__THEME.png)

- **已注册**：验证后直接登录。
- **未注册**：设置密码，点 **Sign Up** 完成注册。

![设置密码](https://assets.yaoagents.com/en/login/login-reg-en-$__THEME.png)

### 4. 开始使用

进入主界面，所有 AI 专家已就绪，操作和本地服务器完全一样。

![主界面](https://assets.yaoagents.com/en/login/login-inbox-en-$__THEME.png)

## 切换服务器

你可以随时切换服务器。右键点击托盘图标，或点击左上角服务器名称，即可回到服务器选择窗口。

## 可用服务器

访问 [/servers](/servers) 页面查看当前可用的云端服务器、地域、注册方式和配置详情。
