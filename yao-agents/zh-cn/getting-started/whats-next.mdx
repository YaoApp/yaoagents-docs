# 下一步

Yao Agents 已经跑起来，基础也了解了。根据你接下来想做的事，选择对应的方向：

## 连接其他设备 — Tai Link

Tai Link 让任何机器都成为 AI 团队可以工作的节点。在第二台电脑、虚拟机或服务器上安装它，Robot 和 Expert 就能在那台设备上打开应用、移动文件、执行命令——完全不碰你的主机。

[Tai Link 是什么 →](/docs/zh-cn/tai-link/what-is-tai-link)
[连接第一台设备 →](/docs/zh-cn/tai-link/connect-first-device)

## 让 Keeper 管理你的知识

Keeper 是知识管理 Agent。给它一个链接、放进一个 PDF、粘贴一个 YouTube URL——它会读取、摘要、存档所有内容。之后问它问题，它从已学到的内容中给你答案。

[Keeper →](/docs/zh-cn/built-in-agents/keeper)

## 接入消息平台

将 Robot 或 Expert 绑定到 Telegram、Discord、微信、钉钉或飞书。结果直接推送到你的团队已经在用的地方。

[消息平台（IM）→](/docs/zh-cn/integrations/chat-platforms)

## 添加自己的 AI 模型

Yao Agents 支持任何兼容 OpenAI 接口的 API——包括通过 Ollama 运行的本地模型。如果想用安装时未配置的模型，在 Settings 中添加新连接器即可。

[AI 模型 →](/docs/zh-cn/integrations/ai-models)

## 扩展 MCP 工具

MCP（Model Context Protocol）工具让 Expert 和 Robot 能与外部服务交互——你的日历、数据库、内部 API。几次点击就能接入任意 MCP 服务器。

[MCP 工具 →](/docs/zh-cn/integrations/mcp-tools)

## 构建或安装自定义专家

在 Yao Agents Hub 浏览社区构建的专家，或者用内置的 AI 开发助手创建自己的。Yao Agents 同时兼容 OpenClaw Agent 生态。

[Yao Agents Hub →](/docs/zh-cn/agent-hub/hub-overview)
[自定义 AI Expert →](/docs/zh-cn/agent-hub/custom-assistants)
