# Tao：一个网关，接入所有服务

Tao 是 Yao Agents 的能力网关。AI 模型、搜索、抓取、存储……你的 Agent 需要的一切，一个 Key 全部接好，按积分计费。

![Tao 服务](https://assets.yaoagents.com/en/tao/services-en-$__THEME.png)

## 提供的服务

| 服务 | 作用 | 接口 |
|------|------|------|
| AI 模型 | 对话、视觉 | `/v1/chat/completions` |
| 结构化决策 | 分类、路由、打分、抽取（Jev） | `/v1/decisions` |
| 搜索 | 网页搜索 | `/v1/search` |
| 抓取 | 抓取网页 | `/v1/fetch` |
| OCR | 从图片提取文字 | `/v1/ocr/type` |
| 图像 | 生成与编辑图片 | `/v1/images/generations`、`/v1/images/edits` |
| 语音 | 转录与合成 | `/v1/audio/transcriptions`、`/v1/audio/speech` |
| Embedding | 文本向量化 | `/v1/embeddings` |

## 怎么接入

1. 打开[注册页](/register)，注册即送 1,000 积分。
2. 控制台点 **Create New Key**，复制 Key。
3. 打开 Yao Agents，选 **Use Tao Service**，粘上 Key，点 **Verify and Configure**。

接好后，设置里显示 **Connected**，模型配置自动填好。

![模型配置](https://assets.yaoagents.com/en/tao/account-setup-10-en-$__THEME.png)

Tao 兼容 OpenAI 接口，不装 Yao Agents 也能直接调用。

## 计费

按积分计量：模型、结构化决策、Embedding 按 token；搜索、抓取按请求数；图像、OCR 按张数；语音按秒数或字符数。

> Tao 目前为 Beta 版，欢迎试用。
