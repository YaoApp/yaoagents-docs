# 安装桌面客户端

桌面客户端适合日常使用，连接你自己电脑上的 Yao Engine。完整流程如下。

## 1. 下载安装

支持 macOS 和 Windows，前往[客户端下载页](/download/yaoagents)下载，像装普通 App 一样安装。

## 2. 连接本地 Engine

打开客户端，服务器选择窗口切到 **Custom Server** 标签。

![Custom Server](https://assets.yaoagents.com/en/login/login-custom-server-en-$__THEME.png)

填入本机 Engine 地址 `http://127.0.0.1:5099`（与浏览器登录地址一致），点 **Connect**。

> 地址从哪来：Yao Engine 界面的 **Server** 一栏，或欢迎页右上角的 **Server URL**。详见[安装](/docs/zh-cn/getting-started/installation)。

![填入地址](https://assets.yaoagents.com/en/login/login-custom-server-url-en-$__THEME.png)

> 连不上时，先确认 Yao Engine 已启动、地址端口正确。

## 3. 注册账号

填**你自己的邮箱**，点 **Continue**。

![输入邮箱](https://assets.yaoagents.com/en/login/login-web-email-en-$__THEME.png)

- **已注册**：验证后直接登录。
- **未注册**：设置密码，点 **Sign Up** 完成注册。

![注册账号](https://assets.yaoagents.com/en/login/login-web-reg-en-$__THEME.png)

## 4. 绑定 Tao

登录后选择模型来源：

- **Use Tao Service（推荐）**：一个 Key 接入模型、搜索、抓取、存储等全部服务。
- **Bring Your Own Key**：自己接 OpenAI、Anthropic、本地 Ollama 等。

![绑定 Tao](https://assets.yaoagents.com/en/login/login-bind-key-en-$__THEME.png)

选 Tao Service：到控制台 **Create New Key** 复制 Key。

![获取 Key](https://assets.yaoagents.com/en/login/login-get-key-en-$__THEME.png)

粘进应用，点 **Verify and Configure**。

![配置 Tao Service](https://assets.yaoagents.com/en/login/login-bind-key-step-2-en-$__THEME.png)

## 5. 开始使用

进入主界面，选专家、发消息、建任务。

![主界面](https://assets.yaoagents.com/en/login/login-inbox-en-$__THEME.png)

> **提示：** 右键点击托盘图标可切换服务器、进入设置等。
