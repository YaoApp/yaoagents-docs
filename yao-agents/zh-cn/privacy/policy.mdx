# Tao 隐私政策

**生效日期：** 2026-09-20
**版本号：** 1.0.0

本隐私政策说明 **象传智慧（北京）软件科技有限公司**（下称"**Tao**"或"**我们**"）在您访问或使用 Tao 服务、[yaoagents.cn](https://yaoagents.cn) 网站、控制台及相关 API（合称"**本服务**"）时，如何收集、使用、共享与保护个人信息。本政策与《[Tao 服务条款](/docs/zh-cn/terms/service)》（下称"**服务条款**"）共同适用。未在本政策中定义的术语，含义同服务条款。

**您使用本服务，即表示您已阅读并理解本政策。**

## 一、简要说明

- **您的内容归您所有。** 我们不存储您的提示词、文件、图片、音频、URL 或模型输出的内容；客户内容仅为完成请求而临时处理，随后即被丢弃。
- **不用于训练。** 我们不会将客户内容用于训练或改进 AI 模型，也不会用于构建数据集。
- **不出售您的个人信息。**
- **仅保留付费服务运营所必需的信息：** 账号信息、支付与账单记录，以及用量**元数据**（例如使用了哪个模型、消耗了多少 token/积分）。
- **部分能力由上游服务商提供。** 当我们将请求转发给上游服务商时，该处理适用其自身的隐私与留存实践；我们会在合理可行时选择具备适当保障的服务商。
- **区域相互独立。** 中国大陆地区站与境外站是相互独立的部署，账号、密钥与数据互不共享，**中国大陆地区的个人信息不出境**。

本简要说明仅为便利阅读，不构成对正文的限缩或替代。

## 三、我们不存储、不留存的内容

3.1 **我们不存储客户内容。** 您输入与输出的内容——包括提示词与模型回复、上传或生成的图片、音频文件、OCR 图片/PDF、搜索词，以及抓取到的网页内容——仅为完成您的请求而**临时**处理，不会被写入我们的数据库、对象存储、备份、数据仓库或分析系统，也不会用于训练或改进模型、构建数据集，或用于我们自身的产品开发。

3.2 **我们自有基础设施同样不留存。** 对于由我们自身基础设施完成的能力，同样适用不留存规则：内容仅在请求期间留存于内存。

3.3 **日志不含正文。** 运营与安全日志仅记录元数据——例如时间、服务、模型、用量、状态、时延、目标主机、抓取路径与错误码；不记录请求或响应正文。

3.4 **对法律调取的影响。** 由于我们不存储客户内容，多数情况下我们并无客户内容可提供。我们可能保留并依法披露第四部分所述账号与用量元数据。

3.5 **上游服务商。** 当我们将请求转发给上游服务商时，该服务商为完成请求会接收输入，其留存与使用实践适用其自身政策。部分服务商已约定零留存，另一些可能为反滥用监测或法律合规在有限期限内留存。我们会在选择服务商与配置集成时予以考量，但无法对每一个上游服务商作出绝对保证。同一模型或能力可能通过不同渠道提供，具体渠道可能动态变化；无论通过何种渠道，我们均不存储客户内容。详见第六部分。

3.6 **抓取（fetch）能力。** 中国大陆地区部署**不启用**第三方抓取基础设施，抓取在中国大陆地区完成；无法获取的页面将返回错误，而不会经境外第三方通道升级处理。**抓取内容不落盘、不留存**，处理与数据存储均在中国大陆地区，我们不将抓取内容存储或中转至境外。若您请求的目标网站在境外，该请求会直接到达该境外目标站点（这是"取回您指定的公开网页"的固有含义），但不经由境外第三方抓取基础设施中转，我们亦不在境外存储任何数据。

## 四、我们收集并保留的个人信息

下表概述我们处理的个人信息类别。"留存期限"为我们默认的保留期；如法律另有要求或为特定争议所必需，实际期限可能更长。

| 类别 | 示例 | 处理目的 | 留存期限 |
|---|---|---|---|
| **账号与身份信息** | 昵称、邮箱、手机号、头像、简介、性别、账号 ID、语言/地区、账号等级 | 创建与管理账号、身份认证、与您沟通 | 账号存续期间；注销后 90 日（法律另有要求除外） |
| **第三方登录标识** | Google `sub` 及邮箱、微信 openid/unionid、其他 OAuth 标识 | 支持登录或账号绑定 | 绑定关系存续期间；解绑/注销时删除 |
| **认证与安全信息** | 密码哈希（bcrypt）、刷新令牌记录、验证码会话、OAuth state、API 密钥元数据、登录/登出记录 | 身份认证、账号安全、防欺诈与滥用 | 账号存续期间；安全日志 6 个月 |
| **联系与设备信息** | IP 地址、设备/浏览器类型、语言、基于 IP 的粗略位置、时间戳 | 运营与安全保障、限流、防滥用 | 6 个月 |
| **支付与账单信息** | 积分余额、资金流水（充值/消费/赠送/退款）、订单、发票、开票主体、税务信息；支付方式令牌/后四位（由支付机构处理） | 计量、计费与收款、开票、退款与争议处理 | 依税务与会计法律要求的期限 |
| **用量元数据** | 服务、模型、单位（token/张/字符/次）、Credits 费用、预授权/冻结记录、时间戳、API 密钥 ID、用户 ID、上游请求 ID、错误/计费状态 | 计量、计费、对账、客服支持、滥用检测 | 24 个月，之后聚合化或删除 |
| **支持与沟通信息** | 邮件、工单、反馈、问卷 | 回复您的请求、改进支持 | 问题解决后 24 个月 |
| **营销偏好** | 同意/撤回记录、沟通偏好 | 发送（或不发送）营销信息、尊重您的选择 | 撤回后 24 个月 |
| **网站与 Cookie 数据** | 必要 Cookie/本地存储、会话数据、统计分析 | 运营网站与控制台、保持登录、了解总体使用情况 | 见第九部分 |

我们不主动收集敏感个人信息（如生物识别、医疗健康、金融账户、行踪轨迹）或未成年人信息，请您不要向本服务提交此类信息。

## 五、我们如何使用个人信息与合法性基础

我们基于下列目的处理个人信息。依《个人信息保护法》，我们对应说明处理的合法性基础（如取得单独同意、履行合同所必需、法定义务、公共利益等）。

| 目的 | 合法性基础 |
|---|---|
| 提供、运营与维护本服务（路由、计量、计费） | 履行合同所必需 |
| 创建与保护账号、身份认证、执行限流 | 履行合同所必需；为保障服务安全所必需 |
| 预防、检测与调查欺诈、滥用、垃圾信息与攻击 | 为履行网络安全等法定义务，以及为保护服务与用户安全所必需 |
| 处理支付、开具发票、退款、履行税务与会计义务 | 履行合同所必需；法定义务 |
| 回复客服请求、告知服务变更 | 履行合同所必需 |
| 发送营销信息（在法律允许范围内） | 单独同意 |
| 响应法律要求、执行服务条款 | 为履行法定义务所必需 |
| 使用**聚合或去标识化**信息改进服务 | 所涉信息已去标识化/匿名化，不属于个人信息 |
| 主张、行使或抗辩法律请求 | 为履行法定义务或行使、抗辩法律请求所必需 |

我们**不会**将客户内容用于上述任何目的，因为我们不保留客户内容。分析与改进基于聚合元数据，而非内容。

7.1 **存储地点。** 中国大陆地区部署的个人信息**存储于中国大陆地区**。我们不会将中国大陆地区的个人信息传输至境外。

7.2 **不出境保证。** 中国大陆地区站的 provider、验证码、短信/邮件、对象存储、日志、备份、监控均不经过境外；若某 provider 仅有境外节点，则该 provider 不进入中国大陆地区站配置。

7.3 如您对存储地点有疑问，可通过 agent@iqka.com 与我们联系。

10.1 在适用法律允许的范围内，您有权：

（1）**查阅、复制**我们持有的您的个人信息；  
（2）**更正、补充**不准确的个人信息；

（5）**转移**您提供给我们的个人信息（符合法定条件时）；

10.4 行使上述权利，请通过 agent@iqka.com 联系我们。我们将依法在法定期限内响应；必要时我们可能核验您的身份。

## 十一、留存

11.1 我们仅在实现本政策所述目的所必需的期限内，或法律要求的期限内保留个人信息。留存期限见第四部分。

11.2 超过必要期限后，我们将删除或去标识化相关信息；聚合、不可识别信息可为分析与服务改进之目的保留更长时间。

11.3 **删除。** 由于我们不持久化客户内容，无需按计划删除内容；请求完成即被丢弃。
