# Yao 软件隐私政策

**生效日期：** 2026-09-20
**版本号：** 1.0.0

本隐私政策说明 **象传智慧（北京）软件科技有限公司**（下称"**Yao**"或"**我们**"）在您使用 **Yao Engine**、**Yao Agents**、**Tai Link** 等客户端软件（合称"**本软件**"）时如何处理个人信息。本政策与《[Yao 软件服务条款](/docs/zh-cn/terms/yao-software)》（下称"**服务条款**"）共同适用。

**您使用本软件，即表示您已阅读并理解本政策。**

---

## 一、简要说明

- **本软件运行在您自己的设备上。** 工作区、文件、对话、机器人与任务数据默认保存在您的设备上。
- **Yao 体系默认匿名。** 本地实例不要求注册我们的账号，账号与凭据保存在您的设备上；**我们通常不知道您是谁**，也无法识别或联系您。
- **我们不收集、不访问、不存储您的本地内容。** 因此不存在将其用于训练、改进模型、构建数据集或向第三方出售的情形。当您调用云端模型或 Tao 服务时，发送哪些输入由您在本地配置的 Agent 决定（见 5.2）。
- **您自带模型。** 您可以配置自己的模型服务商（含本地 Ollama）；您的输入由本软件直接发送给该服务商，我们不经手。
- **仅当您主动使用 Tao 服务时**（账号、模型服务、云服务器、Hub 等），相关个人信息处理适用《[Tao 隐私政策](/docs/zh-cn/privacy/policy)》。

本简要说明仅为便利阅读，不构成对正文的限缩或替代。

## 二、适用范围与个人信息处理者

2.1 本政策适用于本软件（本地客户端软件）。

2.2 在本地运行模式下，我们通常**不处理您的个人信息**，也不知晓您的身份；本地实例的账号与凭据由您自行持有和管理。

2.3 仅在下列情形下，我们可能作为个人信息处理者处理您的个人信息：您选择使用 Tao 服务，或您访问我们的网站。

2.4 **个人信息处理者：** 象传智慧（北京）软件科技有限公司，注册于中国。联系方式：agent@iqka.com。

2.5 **备案信息。** 京ICP备2025116037号。

## 三、本地运行与匿名性

3.1 **本软件在您的设备上运行。** 工作区、文件、对话、任务、模型输入输出与日志默认保存在您指定的本地目录。

3.2 **我们不收集本地内容。** 我们不会收集、访问、存储或分析您的本地内容；因此不存在将其用于训练、改进模型、构建数据集或任何其他用途的情形。当您调用云端模型或 Tao 服务时，发送哪些输入由您在本地配置的 Agent 决定（见 5.2）；Tao 的处理见《[Tao 隐私政策](/docs/zh-cn/privacy/policy)》。

3.3 **本地账号与凭据由您持有。** 本地实例不要求注册我们的账号；账号、密码哈希与令牌保存在您的设备上，由您自行管理与重置。我们无法访问、恢复或删除您的本地数据。

3.4 **第三方模型由您直连。** 当您配置第三方模型时，本软件**将您的输入直接发送至该服务商**；我们不经手、不存储该等输入与输出，该服务商按其自身条款与隐私政策处理。

3.5 **Tai Link。** 连接在 Tai Link 与您的 Yao Agents 实例之间通过加密的 gRPC 隧道建立（生产环境应启用 TLS）。我们不访问或存储您设备之间的连接内容；文件同步的数据保存在您指定的本地目录。

## 四、若您使用 Tao 服务

4.1 本软件可选择连接 **Tao 服务**（AI 能力网关，包括账号、模型服务、云服务器、Hub 等）。

4.2 当您使用 Tao 服务时，相关个人信息的处理适用《[Tao 隐私政策](/docs/zh-cn/privacy/policy)》；本政策不重复规定，如与本政策不一致，以《Tao 隐私政策》为准。

4.3 您可以选择不使用 Tao 服务，纯粹在本地运行本软件。

## 五、有限的其他信息

5.1 **网站与 Cookie。** 如您访问我们的网站或下载页，我们可能使用必要的 Cookie 与本地存储，以及总体统计分析；您可通过浏览器设置管理 Cookie。如法律要求，我们会在设置非必要 Cookie 前取得您的同意。

5.2 **联网调用。** 当您的 Agent、机器人或模型调用需要访问网络（例如调用云端模型或 Tao 服务）时，**发送哪些输入由您在本地配置的 Agent Harness 决定**，可能包含您选择提供的本地内容、文件或上下文。该等输入由本软件直接发送给您所配置的模型服务商或 Tao 服务：

（1）对 **Tao 服务**：内容仅用于完成您的请求，**不留存、不用于训练或构建数据集**（详见《[Tao 隐私政策](/docs/zh-cn/privacy/policy)》）；  
（2）对**第三方模型服务商**：适用其各自的条款与隐私政策。  

5.3 除上述情形及 Tao 服务外，我们不主动收集您的个人信息。

## 六、安全

6.1 我们采取符合行业标准的技术与组织措施保护我们所处理的个人信息，包括传输加密（TLS）、访问控制与最小权限。

6.2 本软件的安全性在很大程度上取决于您的设备与配置；请妥善保管您的设备、凭据与 Server Key，并在设备丢失或人员变动时及时吊销。

6.3 本地数据由您自行控制与保护。在本地运行中，我们并不持有您的本地数据，也无从知悉其是否发生泄露或丢失，因此不会亦无法就此向您发送泄露通知。

6.4 **漏洞修复与安全更新。** 我们尽最大努力及时修复本软件的安全漏洞。对于第三方安全研究者（白帽）报告的漏洞，我们将及时评估并修复，并在必要时通过网站公告或产品内通知告知用户。请及时安装我们发布的安全更新，以降低风险。
