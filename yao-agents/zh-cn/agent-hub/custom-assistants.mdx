# 自定义 AI 专家

Yao Agents 内置了一批 AI 专家，你也可以按需扩展。以下是添加新专家的几种方式。

## 1. 从 Yao Agents Hub 安装

在 Yao Agents Hub 中浏览社区构建的现成专家，一键安装即可使用。

> **早期体验（Early Access）。** Yao Agents Hub 目前处于早期体验阶段。

## 2. 让 AI 开发专家帮你创建

打开内置的 AI 开发专家，描述你想要的专家角色，它会自动生成配置并完成安装——无需编写代码。

> **早期体验（Early Access）。** 该功能目前处于早期体验阶段。

## 3. 编写代码创建

使用 Yao DSL 编写自定义 AI 专家，完全掌控提示词、工具、沙箱和行为。

→ [创建你的第一个 Agent](https://yaoapps.com/docs/tutorials/zh-cn/agent/getting-started/index) — YaoApps.com 上的分步教程

## 4. 探索第三方生态

Yao Agents 兼容来自开放社区生态的 Agent。你可以在以下平台浏览，将兼容的 Agent 适配到 Yao Agents 中使用。

- [ClawHub](https://clawhub.ai/) — 社区构建的技能和插件
- [Hermes Agent Skills Hub](https://hermes-agent.nousresearch.com/docs/skills) — Nous Research 维护的开放 Agent 技能注册中心

> **早期体验（Early Access）。** 第三方生态集成目前处于早期体验阶段。这些均为独立的第三方社区，部分 Agent 可能需要适配才能使用。
