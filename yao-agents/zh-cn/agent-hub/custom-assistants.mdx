# 自定义 AI 专家

Yao Agents 内置了一批 AI 专家，你也可以按需创建自己的。

## 1. 用 Agent Smith 构建

打开 Agent Smith，描述你想要的专家——它会自动搜索技能库、搭建、测试并部署。全程不用写代码。

Agent Smith 能自动从全球技能库（10 万+）和第三方生态中搜索现成方案，安全审查后按你的需求适配定制。

→ [Agent Smith 详情](/docs/zh-cn/built-in-agents/agent-smith)

## 2. 编写代码创建

使用 Yao DSL 编写自定义 AI 专家，完全掌控提示词、工具、沙箱和行为。

→ [创建你的第一个 Agent](https://yaoapps.com/docs/tutorials/zh-cn/agent/getting-started/index) — YaoApps.com 上的分步教程
