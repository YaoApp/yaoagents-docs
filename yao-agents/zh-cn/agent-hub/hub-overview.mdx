# Yao Agents Hub

Yao Agents Hub 是发现、安装和分享 AI 专家的开放市场——为各类工作流量身打造的专业专家。

> **早期体验（Early Access）。** Yao Agents Hub 目前处于早期体验阶段，正式公测即将启动。

## 内置专家

Yao Agents 随产品预装了一批开箱即用的专家。

| 专家 | 擅长什么 |
|------|---------|
| [General](/docs/zh-cn/built-in-agents/general) | 通用助手——问答、编程、调研、写作 |
| [Keeper](/docs/zh-cn/built-in-agents/keeper) | 知识管家——保存、整理、检索任意内容 |
| [PM](/docs/zh-cn/built-in-agents/pm) | 项目经理——任务拆解、进度跟踪、团队协作 |
| [Postman](/docs/zh-cn/built-in-agents/postman) | 邮件助手——通过 SMTP/IMAP 收发、撰写邮件 |
| [Insights](/docs/zh-cn/built-in-agents/insights) | 数据分析——数据库、表格、ECharts 交互看板 |
| [Market Scout](/docs/zh-cn/built-in-agents/scout) | 市场情报——监控订阅源、分类归档洞察 |
| [Slides](/docs/zh-cn/built-in-agents/slides) | 幻灯片制作——大纲转 HTML 演示稿，导出 PDF |
| [Transformer](/docs/zh-cn/built-in-agents/transformer) | 数据结构化——图片、PDF、JSON、CSV 转换 |
| [Web Builder](/docs/zh-cn/built-in-agents/website) | 网站构建——Next.js + Tailwind，VNC 预览 + SSH 部署 |
| [Applet Workshop](/docs/zh-cn/built-in-agents/applet) | 小工具开发——Node.js 可视化 mini-tool，VNC 实时预览 |
| [Report Writer](/docs/zh-cn/built-in-agents/report-writer) | 报告撰写机器人——在任务控制中心自动生成结构化 Markdown 报告 |
