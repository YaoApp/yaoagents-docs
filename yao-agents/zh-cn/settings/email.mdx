# 邮件

**邮件**面板用于配置 SMTP 设置，让 AI 专家（如 Postman）可以代你发送邮件。未配置时，邮件相关功能将无法使用。

![设置 — 邮件 / SMTP](https://assets.yaoagents.com/en/settings/09-config-email-en-$__THEME.png)

## 配置项

| 字段 | 说明 |
|------|------|
| 服务商 | 选择预设服务商或自定义。 |
| SMTP 地址 | 邮件服务器地址，选择预设后自动填充。 |
| SMTP 端口 | 端口号（TLS 通常为 587，SSL 通常为 465），选择预设后自动填充。 |
| 加密方式 | SSL 或 TLS，选择预设后自动填充。 |
| 用户名 | 邮箱账号用户名（通常是完整邮箱地址）。 |
| 密码 | 邮箱密码或专用密码/授权码。 |
| 发件人 | 收件人看到的"发件人"地址。 |

## 可用预设

| 服务商 | 地址 | 端口 | 加密 | 说明 |
|--------|------|------|------|------|
| 腾讯企邮 | smtp.exmail.qq.com | 465 | SSL | 密码需使用客户端专用密码，在[企业邮设置](https://exmail.qq.com/)中生成。 |
| 飞书邮箱 | smtp.feishu.cn | 465 | SSL | 需在[飞书管理后台](https://www.feishu.cn/)开启邮箱 SMTP 服务。 |
| 阿里邮箱 | smtp.aliyun.com | 465 | SSL | 需在[阿里邮箱设置](https://mail.aliyun.com/)中开启 SMTP 服务。 |
| QQ 邮箱 | smtp.qq.com | 465 | SSL | 需在 [QQ 邮箱设置](https://mail.qq.com/)中开启 SMTP 服务并获取授权码。 |
| 163 邮箱 | smtp.163.com | 465 | SSL | 需在 [163 邮箱设置](https://mail.163.com/)中开启 SMTP 服务并获取授权码。 |
| 自定义 | （自行填写） | 465 | SSL | 手动填写 SMTP 服务器信息。 |

## 腾讯企邮设置

1. 登录[腾讯企业邮箱](https://exmail.qq.com/)管理后台。
2. 在设置中生成**客户端专用密码**。
3. 在 Yao Agents 中选择**腾讯企邮**。
4. 填写邮箱地址作为**用户名**和**发件人**。
5. 粘贴客户端专用密码到**密码**字段。
6. 点击**保存**。

## QQ / 163 邮箱设置

1. 在邮箱网页版的设置中开启 SMTP 服务。
2. 获取**授权码**（不是登录密码）。
3. 在 Yao Agents 中选择对应服务商。
4. 填写邮箱地址作为**用户名**和**发件人**。
5. 粘贴授权码到**密码**字段。
6. 点击**保存**。

## 自定义 SMTP

对于其他邮件服务商，选择**自定义**并手动填写所有字段。请查阅服务商文档获取正确的 SMTP 地址、端口和加密方式。
