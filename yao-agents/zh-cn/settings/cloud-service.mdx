# 云服务

**云服务**面板用于配置 Yao Agents 与 Yao Agents 模型服务之间的连接。这是最快的上手方式 — 注册账号、粘贴 API Key，所有内置 AI 专家即可直接使用。

![设置 — 云服务](https://assets.yaoagents.com/en/settings/02-config-cloud-service-en-$__THEME.png)

## 配置项

| 字段 | 说明 |
|------|------|
| Region | 选择距离你最近的区域以降低延迟：美国、中国、亚洲或欧洲。 |
| API URL | Yao Agents 模型服务的接口地址。会根据你选择的区域自动填充。 |
| API Key | 你的个人 API Key。前往 [yaoagents.com/dashboard](https://yaoagents.com/dashboard/auth/entry?redirect=/console) 获取。 |

## 配置步骤

1. 选择距离你最近的**区域**。
2. **API URL** 会自动更新。
3. 粘贴你的 **API Key**。
4. 点击**保存**。Yao Agents 将自动验证连接。

## 使用自有模型服务

如果你希望使用自己的模型服务（OpenAI、Anthropic、DeepSeek、本地 Ollama 等），请在[模型配置](/docs/zh-cn/settings/ai-models)中进行设置。云服务与自定义模型服务商可以同时使用。
