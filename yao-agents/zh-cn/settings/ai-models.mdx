# 模型配置

**模型配置**面板允许你为不同角色分配 AI 模型，并添加新的模型服务商 — 全程通过图形界面操作，无需手动编辑文件。

![设置 — 模型配置](https://assets.yaoagents.com/en/settings/03-config-models-en-$__THEME.png)

## 模型角色

Yao Agents 采用基于角色的模型体系。每个角色服务于不同用途，你可以为每个角色分配不同的模型或服务商：

| 角色 | 用途 | 使用场景 |
|------|------|----------|
| **Default** | 通用任务 | 大多数对话、日常问答、内容生成。 |
| **Heavy** | 复杂推理 | 深度分析、长期规划、多步骤问题求解。 |
| **Light** | 快速简单任务 | 快速回复、分类、简短摘要。 |
| **Vision** | 图像理解 | 读取截图、分析图表、OCR 任务。 |
| **Audio** | 语音转文字 | 语音输入转录。 |
| **Embedding** | 文本嵌入 | 语义搜索、文档相似度。 |

## 为角色分配模型

1. 打开**设置 → 模型配置**。
2. 为每个角色从下拉菜单中选择一个模型。可选模型来自你已配置的服务商。
3. 点击**保存**。

![设置 — 模型角色分配](https://assets.yaoagents.com/en/settings/04-config-models-add-en-$__THEME.png)

如果你尚未添加任何服务商，可以使用[云服务](/docs/zh-cn/settings/cloud-service) — 无需额外设置即可使用全部角色。

## 添加模型服务商

如需使用来自 OpenAI、Anthropic、DeepSeek、Google 或任何 OpenAI 兼容服务的模型：

1. 在模型配置页面底部点击**添加服务商**。
2. 选择服务商类型（OpenAI、Anthropic、DeepSeek、Google、Ollama 或 Custom）。
3. 填写所需信息：

| 字段 | 说明 |
|------|------|
| Name | 该服务商的显示名称（例如"My OpenAI"）。 |
| API Host | 服务商 API 的基础 URL。已知服务商会自动填充。 |
| API Key | 你从服务商处获取的 API Key。 |
| Models | 要启用的具体模型标识（例如 `gpt-4o`、`claude-sonnet-4-5-20250929`）。 |

4. 点击**保存**。新模型会立即出现在角色下拉菜单中。

![设置 — 添加模型服务商](https://assets.yaoagents.com/en/settings/05-config-models-add-deepseek-en-$__THEME.png)

## 编辑或删除服务商

点击服务商卡片可编辑其设置。使用删除按钮可移除服务商。移除服务商会取消所有使用该服务商模型的角色分配 — 你需要重新为这些角色指定模型。

## 支持的服务商

| 服务商 | 类型 | 备注 |
|--------|------|------|
| OpenAI | `openai` | GPT-4o、GPT-4.1、o3、o4-mini 等。 |
| Anthropic | `anthropic` | Claude Opus 4、Claude Sonnet 4.5 等。 |
| DeepSeek | `openai` | DeepSeek V4、R1 等。OpenAI 兼容接口。 |
| Google | `openai` | 通过 OpenAI 兼容网关使用 Gemini 模型。 |
| Ollama | `openai` | 本地模型。将 host 设置为 `http://127.0.0.1:11434/v1/`。 |
| 任何 OpenAI 兼容服务 | `openai` | vLLM、LiteLLM、Azure OpenAI、Groq、Together 等。 |

## 进阶：手动编辑连接器文件

对于高级用例（自定义能力、思考模式配置、Azure 部署等），你仍然可以手动创建连接器文件。详见[环境变量](/docs/zh-cn/settings/env-vars)中关于 `.conn.yao` 文件格式和目录结构的说明。
