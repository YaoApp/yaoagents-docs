# 系统信息

**系统信息**面板展示当前 Yao Agents 安装的版本号和运行环境信息。你可以在设置页面中打开它。

![设置 — 系统信息](https://assets.yaoagents.com/en/settings/01-config-system-info-en-$__THEME.png)

## 面板内容

| 字段 | 说明 |
|------|------|
| Yao Agents | Yao Agents 桌面应用的版本号。 |
| Yao Engine | 底层 Yao Engine 运行时的版本号。 |
| CUI | CUI（Chat UI）组件的版本号。 |
| Environment | 当前运行模式 — `Development` 或 `Production`。 |

## 何时需要查看

- **提交 Bug 报告前** — 在你的 Issue 中附上版本号信息。
- **更新之后** — 确认所有组件都已成功更新。
- **排查问题时** — 技术支持可能会要求你提供版本详情。
