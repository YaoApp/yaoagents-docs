# 搜索与抓取

**搜索与抓取**面板用于配置 AI 专家使用的网页搜索和页面抓取服务。当专家需要在线查找信息或从 URL 提取内容时，会使用此处配置的服务商。

![设置 — 搜索与抓取](https://assets.yaoagents.com/en/settings/07-config-search-en-$__THEME.png)

## 支持的服务商

| 服务商 | 类型 | 功能说明 |
|--------|------|----------|
| [Tavily](https://tavily.com) | 搜索 | AI 优化的网页搜索 API，返回结构化结果，可直接供大语言模型使用。 |
| [Serper](https://serper.dev) | 搜索 | Google 搜索 API，快速且实惠，返回标准搜索结果。 |
| [Brightdata](https://brightdata.com) | 抓取 | 网页抓取与数据采集，可从屏蔽简单请求的页面中提取内容。 |

## 设置方法

1. 注册你想使用的服务商。
2. 从服务商控制台复制 API Key。
3. 在 Yao Agents 中打开**设置 → 搜索与抓取**。
4. 选择服务商并粘贴你的 API Key。
5. 点击**保存**。

## 专家如何使用

当你向 AI 专家提出需要最新信息的问题时，它会自动执行以下操作：

1. 调用已配置的搜索服务商查找相关网页。
2. 使用抓取服务商（如已配置）从这些网页中提取完整内容。
3. 综合分析结果并生成回答。

你不需要配置所有服务商。仅配置搜索服务商即可满足大多数使用场景。如果你的工作流涉及从特定网站提取详细内容，可以额外添加抓取服务商。
