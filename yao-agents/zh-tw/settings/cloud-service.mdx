# 雲端服務

**雲端服務**面板用於設定 Yao Agents 與 Yao Agents 模型服務之間的連線。這是最快的上手方式 — 只需註冊帳號、貼上 API Key，所有內建 AI 專家即可立即使用。

![設定 — 雲端服務](https://assets.yaoagents.com/en/settings/02-config-cloud-service-en-$__THEME.png)

## 設定項目

| 欄位 | 說明 |
|------|------|
| Region | 選擇最近的區域以降低延遲：US、China、Asia 或 Europe。 |
| API URL | Yao Agents 模型服務的端點位址，會依據所選區域自動填入。 |
| API Key | 你的個人 API Key。請至 [yaoagents.com/dashboard](https://yaoagents.com/dashboard/auth/entry?redirect=/console) 取得。 |

## 設定步驟

1. 選擇離你最近的**區域**。
2. **API URL** 會自動更新。
3. 貼上你的 **API Key**。
4. 點擊**儲存**。Yao Agents 會驗證連線狀態。

## 使用自有模型供應商

如果你想使用自己的模型服務（OpenAI、Anthropic、DeepSeek、本地 Ollama 等），請改在[模型設定](/docs/zh-tw/settings/ai-models)中進行設定。雲端服務與自訂供應商可以同時使用。
