# 搜尋與擷取

**搜尋與擷取**面板用於設定 AI 專家使用的網路搜尋與網頁擷取服務供應商。當專家需要上網查詢資料或從網址擷取內容時，會使用此處設定的供應商。

![設定 — 搜尋與擷取](https://assets.yaoagents.com/en/settings/07-config-search-en-$__THEME.png)

## 支援的供應商

| 供應商 | 類型 | 功能說明 |
|--------|------|----------|
| [Tavily](https://tavily.com) | 搜尋 | 針對 AI 最佳化的網路搜尋 API，回傳結構化結果，可直接供 LLM 使用。 |
| [Serper](https://serper.dev) | 搜尋 | Google Search API，速度快、價格實惠，回傳標準搜尋結果。 |
| [Brightdata](https://brightdata.com) | 擷取 | 網頁爬取與資料蒐集服務，可擷取封鎖簡單請求的網頁內容。 |

## 設定步驟

1. 註冊你想使用的供應商帳號。
2. 從供應商的控制台複製 API Key。
3. 在 Yao Agents 中開啟**設定 → 搜尋與擷取**。
4. 選擇供應商並貼上你的 API Key。
5. 點擊**儲存**。

## 專家如何使用

當你向 AI 專家提出需要最新資訊的問題時，它會自動：

1. 呼叫已設定的搜尋供應商尋找相關網頁。
2. 使用擷取供應商（若已設定）從這些網頁提取完整內容。
3. 將結果彙整後納入回答。

你不需要設定所有供應商。大多數情況下，僅設定搜尋供應商就已足夠。若你的工作流程需要從特定網站擷取詳細內容，再另外新增擷取供應商即可。
