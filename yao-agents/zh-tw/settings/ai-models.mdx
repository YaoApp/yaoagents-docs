# 模型設定

**模型設定**面板讓你為不同角色指派 AI 模型，以及新增模型供應商 — 全部透過圖形介面操作，無需手動編輯檔案。

![設定 — 模型設定](https://assets.yaoagents.com/en/settings/03-config-models-en-$__THEME.png)

## 模型角色

Yao Agents 採用角色式模型系統。每個角色有不同的用途，你可以為每個角色指派不同的模型（或供應商）：

| 角色 | 用途 | 使用時機 |
|------|------|----------|
| **Default** | 通用任務 | 大多數對話、日常問答、內容產生。 |
| **Heavy** | 複雜推理 | 深度分析、長篇規劃、多步驟問題解決。 |
| **Light** | 快速簡單任務 | 快速回覆、分類、簡短摘要。 |
| **Vision** | 圖像理解 | 讀取螢幕截圖、分析圖表、OCR 任務。 |
| **Audio** | 語音轉文字 | 語音輸入轉錄。 |
| **Embedding** | 文字嵌入 | 語意搜尋、文件相似度比對。 |

## 為角色指派模型

1. 開啟**設定 → 模型設定**。
2. 針對每個角色，從下拉選單中選擇模型。可用的模型來自你已設定的供應商。
3. 點擊**儲存**。

![設定 — 模型角色指派](https://assets.yaoagents.com/en/settings/04-config-models-add-en-$__THEME.png)

如果你尚未新增任何供應商，請先使用[雲端服務](/docs/zh-tw/settings/cloud-service) — 無需額外設定即可使用所有角色。

## 新增模型供應商

若要使用來自 OpenAI、Anthropic、DeepSeek、Google 或任何 OpenAI 相容服務的模型：

1. 在模型設定頁面底部點擊**新增供應商**。
2. 選擇供應商類型（OpenAI、Anthropic、DeepSeek、Google、Ollama 或 Custom）。
3. 輸入所需資訊：

| 欄位 | 說明 |
|------|------|
| Name | 此供應商的顯示名稱（例如「My OpenAI」）。 |
| API Host | 供應商 API 的基礎 URL。已知供應商會自動填入。 |
| API Key | 從供應商取得的 API Key。 |
| Models | 要啟用的特定模型識別碼（例如 `gpt-4o`、`claude-sonnet-4-5-20250929`）。 |

4. 點擊**儲存**。新模型會立即出現在角色下拉選單中。

![設定 — 新增模型供應商](https://assets.yaoagents.com/en/settings/05-config-models-add-deepseek-en-$__THEME.png)

## 編輯或移除供應商

點擊供應商卡片以編輯其設定。使用刪除按鈕移除供應商。移除供應商會取消所有使用該供應商模型的角色指派 — 你需要重新指派這些角色。

## 支援的供應商

| 供應商 | 類型 | 備註 |
|--------|------|------|
| OpenAI | `openai` | GPT-4o、GPT-4.1、o3、o4-mini 等。 |
| Anthropic | `anthropic` | Claude Opus 4、Claude Sonnet 4.5 等。 |
| DeepSeek | `openai` | DeepSeek V4、R1 等。OpenAI 相容端點。 |
| Google | `openai` | 透過 OpenAI 相容閘道使用 Gemini 模型。 |
| Ollama | `openai` | 本地模型。將主機設定為 `http://127.0.0.1:11434/v1/`。 |
| 任何 OpenAI 相容服務 | `openai` | vLLM、LiteLLM、Azure OpenAI、Groq、Together 等。 |

## 進階：手動建立連接器檔案

對於進階使用情境（自訂功能、思考模式設定、Azure 部署），你仍然可以手動建立連接器檔案。請參閱[環境變數](/docs/zh-tw/settings/env-vars)以了解底層 `.conn.yao` 檔案格式與目錄結構。
