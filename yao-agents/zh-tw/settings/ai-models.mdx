# AI 模型

Yao Agents 中的 AI 模型以**連接器檔案**（`.conn.yao`）的形式設定，存放在應用程式目錄下的 `connectors/` 目錄中。每個檔案定義一個模型——包括類型、憑證和功能。

隨 Yao Agents 內建的四個連接器透過 `.env` 中的環境變數讀取設定，常見場景下無需直接編輯連接器檔案。只有在新增服務商或精細調整模型行為時，才需要建立或修改連接器檔案。

---

## 連接器檔案格式

連接器檔案是一個 JSON 檔案，包含三個欄位：

```json
{
  "label": "UI 中顯示的名稱",
  "type": "openai",
  "options": {
    "host": "https://api.example.com",
    "model": "model-name",
    "key": "sk-...",
    "max_tokens": 16384,
    "temperature": 0.6,
    "thinking": { "type": "disabled" },
    "capabilities": {
      "vision": true,
      "tool_calls": true,
      "reasoning": false,
      "streaming": true,
      "json": true,
      "multimodal": true
    }
  }
}
```

### `type`

| 值 | 協定 | 適用場景 |
|----|------|---------|
| `openai` | OpenAI Chat Completions | OpenAI、DeepSeek、Kimi、Qwen、Ollama，以及任何 OpenAI 相容端點 |
| `anthropic` | Anthropic Messages API | 直接透過 Anthropic API 呼叫的 Claude 模型 |

> **提示：** 大多數第三方服務商都提供 OpenAI 相容端點。使用 `type: "openai"`，將 `host` 指向服務商的基礎 URL 即可。

### `options`

| 欄位 | 類型 | 說明 |
|------|------|------|
| `host` | 字串 | API 基礎 URL。以 `/` 結尾時原樣使用；否則自動在請求路徑前加 `/v1`。 |
| `model` | 字串 | 傳給 API 的模型識別碼（如 `gpt-4o`、`claude-sonnet-4-5-20250929`）。 |
| `key` | 字串 | API 金鑰。可用 `$ENV.變數名稱` 從 `.env` 讀取。 |
| `max_tokens` | 整數 | 回應最大 token 數。 |
| `temperature` | 浮點數 | 採樣溫度。不支援此參數的推理模型請省略。 |
| `thinking` | 物件 | Thinking / 推理模式設定（見下文）。 |
| `capabilities` | 物件 | 告知 Yao 該模型支援哪些功能（見下文）。 |
| `azure` | 字串 | 使用 Azure OpenAI 端點時設為 `"true"`。 |
| `version` | 字串 | Anthropic API 版本請求標頭，預設 `"2023-06-01"`（僅 anthropic 類型）。 |

#### `thinking`

控制擴展推理 / thinking 模式。

| 值 | 效果 |
|----|------|
| `{ "type": "disabled" }` | 關閉 thinking。 |
| `{ "type": "enabled" }` | 始終開啟 thinking。 |
| `{ "type": "adaptive" }` | 模型根據問題自行決定是否 thinking。 |
| `{ "type": "enabled", "budget_tokens": 10000 }` | 開啟 thinking 並設定 token 預算（Anthropic 模型）。 |

#### `capabilities`

| 欄位 | 類型 | 說明 |
|------|------|------|
| `vision` | bool 或 `"openai"` / `"claude"` | 圖像輸入支援。`"openai"` 使用 `image_url` 格式；`"claude"` 使用 base64 格式。 |
| `tool_calls` | bool | 函式 / 工具呼叫支援。 |
| `reasoning` | bool | 擴展推理 / 思維鏈輸出。 |
| `streaming` | bool | 串流回應支援（Server-Sent Events）。 |
| `json` | bool | JSON 模式支援。 |
| `multimodal` | bool | 通用多模態輸入（圖像、檔案）。 |
| `audio` | bool | 音訊理解。 |
| `stt` | bool | 語音轉文字（Whisper 風格轉錄）。 |

Yao 會根據常見模型名稱自動推斷合理的預設值，對於主流模型可以省略 `capabilities`。使用自訂或私有模型時建議明確設定。

## 內建連接器

以下四個檔案隨 Yao Agents 內建，從 `.env` 讀取設定。

### `default` — 均衡

大多數 AI 專家和機器人使用的主要連接器。

```json
{
  "label": "Balanced",
  "type": "openai",
  "options": {
    "host": "$ENV.DEFAULT_CONNECTOR_HOST",
    "model": "$ENV.DEFAULT_CONNECTOR_MODEL",
    "key": "$ENV.DEFAULT_CONNECTOR_KEY",
    "max_tokens": 16384,
    "temperature": 0.6,
    "thinking": { "type": "disabled" }
  }
}
```

`.env` 變數：`DEFAULT_CONNECTOR_HOST`、`DEFAULT_CONNECTOR_MODEL`、`DEFAULT_CONNECTOR_KEY`

### `thinking` — 深度思考

與 `default` 共用同一端點，但啟用了自適應 thinking——用於機器人或專家需要深度推理的場景。

```json
{
  "label": "Deep Think",
  "type": "openai",
  "options": {
    "host": "$ENV.DEFAULT_CONNECTOR_HOST",
    "model": "$ENV.DEFAULT_CONNECTOR_MODEL",
    "key": "$ENV.DEFAULT_CONNECTOR_KEY",
    "max_tokens": 16384,
    "thinking": { "type": "adaptive" }
  }
}
```

### `vision` — 視覺

處理圖像分析任務，未單獨設定時退回到 `DEFAULT_CONNECTOR_*`。

```json
{
  "label": "Vision",
  "type": "openai",
  "options": {
    "host": "$ENV.VISION_CONNECTOR_HOST",
    "model": "$ENV.VISION_CONNECTOR_MODEL",
    "key": "$ENV.VISION_CONNECTOR_KEY",
    "max_tokens": 16384
  }
}
```

`.env` 變數：`VISION_CONNECTOR_HOST`、`VISION_CONNECTOR_MODEL`、`VISION_CONNECTOR_KEY`

### `whisper-1` — 語音轉文字

轉錄音訊輸入。

```json
{
  "label": "Whisper-1",
  "type": "openai",
  "options": {
    "model": "$ENV.VOICE_CONNECTOR_MODEL",
    "key": "$ENV.VOICE_CONNECTOR_KEY",
    "host": "$ENV.VOICE_CONNECTOR_HOST",
    "capabilities": { "stt": true }
  }
}
```

`.env` 變數：`VOICE_CONNECTOR_HOST`、`VOICE_CONNECTOR_MODEL`、`VOICE_CONNECTOR_KEY`

## 新增連接器

1. 在 `connectors/` 下（或子目錄如 `connectors/openai/`）建立一個 `.conn.yao` 檔案。
2. 填寫 `type`、`options`，以及選填的 `capabilities`。
3. 重新啟動 Yao Engine。新連接器會出現在所有機器人和 AI 專家的連接器選擇器中。

### 範例：OpenAI GPT-4o

```json
{
  "label": "GPT-4o",
  "type": "openai",
  "options": {
    "model": "gpt-4o",
    "key": "$ENV.OPENAI_API_KEY",
    "host": "https://api.openai.com",
    "max_tokens": 16384,
    "capabilities": {
      "vision": "openai",
      "tool_calls": true,
      "streaming": true,
      "json": true,
      "multimodal": true
    }
  }
}
```

### 範例：Anthropic Claude Sonnet（直連 API）

```json
{
  "label": "Claude Sonnet 4.5",
  "type": "anthropic",
  "options": {
    "model": "claude-sonnet-4-5-20250929",
    "key": "$ENV.ANTHROPIC_API_KEY",
    "capabilities": {
      "vision": "claude",
      "tool_calls": true,
      "streaming": true,
      "json": true,
      "multimodal": true
    }
  }
}
```

### 範例：Claude 開啟擴展 thinking

```json
{
  "label": "Claude Sonnet 4.5 Thinking",
  "type": "anthropic",
  "options": {
    "model": "claude-sonnet-4-5-20250929",
    "key": "$ENV.ANTHROPIC_API_KEY",
    "thinking": { "type": "enabled", "budget_tokens": 10000 },
    "capabilities": {
      "vision": "claude",
      "tool_calls": true,
      "reasoning": true,
      "streaming": true,
      "json": true,
      "multimodal": true
    }
  }
}
```

### 範例：DeepSeek R1（推理模型）

```json
{
  "label": "DeepSeek R1",
  "type": "openai",
  "options": {
    "model": "deepseek-r1",
    "key": "$ENV.DEEPSEEK_API_KEY",
    "host": "https://api.deepseek.com",
    "capabilities": {
      "reasoning": true,
      "streaming": true
    }
  }
}
```

### 範例：透過 Ollama 使用本地模型

```json
{
  "label": "Llama 3.3（本地）",
  "type": "openai",
  "options": {
    "model": "llama3.3",
    "key": "ollama",
    "host": "http://127.0.0.1:11434/v1/",
    "capabilities": {
      "tool_calls": true,
      "streaming": true,
      "json": true
    }
  }
}
```

> `host` 以 `/` 結尾，Yao 會原樣使用，不再追加 `/v1`。

### 範例：火山引擎 / 字節跳動方舟

```json
{
  "label": "豆包 Seed 1.6 Flash",
  "type": "openai",
  "options": {
    "model": "$ENV.VOLCENGINE_DOUBAO_SEED_1_6_FLASH",
    "key": "$ENV.VOLCENGINE_API_KEY",
    "host": "https://ark.cn-beijing.volces.com/api/v3/",
    "capabilities": {
      "vision": true,
      "streaming": true,
      "json": true
    }
  }
}
```

## `host` URL 規則

| `host` 值 | `/chat/completions` 的完整 URL |
|---|---|
| `https://api.openai.com` | `https://api.openai.com/v1/chat/completions` |
| `https://api.openai.com/` | `https://api.openai.com/chat/completions` |
| `https://my-proxy.example.com/openai/v1/` | `https://my-proxy.example.com/openai/v1/chat/completions` |

**規則：** `host` 以 `/` 結尾時原樣使用；否則在每個端點路徑前自動加 `/v1`。

## 套用設定變更

新增或修改連接器檔案後，重新啟動 Yao Engine 使變更生效。
