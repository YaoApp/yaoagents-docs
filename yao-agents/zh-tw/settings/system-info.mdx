# 系統資訊

**系統資訊**面板顯示目前 Yao Agents 安裝的版本號碼及執行環境。可從設定頁面開啟。

![設定 — 系統資訊](https://assets.yaoagents.com/en/settings/01-config-system-info-en-$__THEME.png)

## 顯示內容

| 欄位 | 說明 |
|------|------|
| Yao Agents | Yao Agents 桌面應用程式的版本。 |
| Yao Engine | 底層 Yao Engine 執行環境的版本。 |
| CUI | CUI（Chat UI）元件的版本。 |
| Environment | 目前的執行模式 — `Development` 或 `Production`。 |

## 何時需要查看

- **回報問題之前** — 在你的問題回報中附上版本號碼。
- **更新之後** — 確認所有元件都已成功更新。
- **疑難排解時** — 技術支援可能會請你提供版本資訊。
