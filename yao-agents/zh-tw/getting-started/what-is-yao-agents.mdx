# Yao Agents 是什麼

所有 Agent 與工作空間集中管理，跑在你自己的裝置上。看板追蹤任務進度，桌面、手機、瀏覽器、API 隨時掌控。自架部署，資料不外流。

![運作原理](https://assets.yaoagents.com/en/architecture/01-how-it-works-en-$__THEME.png)

Agent 在專用裝置上並行運作，你接了幾台，它們就同時在幾台上做事。一個應用管理全部。多一台電腦，就多一份產能。

[下載](/download) · [安裝指南](/docs/zh-tw/getting-started/installation)

## 為什麼選擇 Yao Agents

從電腦、手機或瀏覽器告訴 Agent 要做什麼，它們在你的裝置上同步作業，你繼續忙自己的。

### 工作空間

每個工作區都是獨立隔離的環境，不同工作各佔一處、互不干擾，多台電腦統一管理。工作成果沉澱為文件，累積成你的知識庫。

Agent 工作時，可跨節點取用需要的資料。

![工作空間](https://assets.yaoagents.com/en/workspace/01-workspace-index-en-$__THEME.png)

### 任務看板

在對話中說出你想做的事，Agent 會把它變成一項任務，放進看板。持續對話、反覆執行，越用越順手，逐漸長成專門處理這類工作的 Agent。

還能把任務 Agent 接入自己的應用，或分享給更多人使用。

![任務看板](https://assets.yaoagents.com/en/kanban/09-kanban-daily-en-$__THEME.png)

### 開放介面

專家 Agent、任務 Agent 都能接入你自己的應用與業務流程。介面相容 API 標準，支援 SSE 與 WebSocket。

讓 Agent 融入你的業務，哪裡需要它，它就在哪裡。

![開放介面](https://assets.yaoagents.com/en/openapi/01-openapi-task-en-$__THEME.png)
