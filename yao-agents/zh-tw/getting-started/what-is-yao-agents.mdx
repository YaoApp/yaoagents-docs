# 什麼是 Yao Agents

Yao Agents 是一個**開源的 AI Agent 託管平台**，完全運行在你自己的裝置上。你可以構建、部署和管理智慧 AI 助手——無需依賴任何第三方雲端服務。

> **核心理念：** 你的資料留在你的裝置上。你的 AI，你做主。

## 為什麼選擇 Yao Agents

傳統 AI 方案需要將資料傳送到外部伺服器。Yao Agents 採用了完全不同的方式：

- **隱私優先** — 所有資料和模型推論都留在你的本機或私有伺服器上
- **無廠商鎖定** — 自由切換 LLM 提供商（OpenAI、Anthropic、本地模型）
- **企業級就緒** — 角色權限控制、稽核日誌、合規友善的架構
- **開發者友善** — 透過 TypeScript Hooks、MCP 工具和強大的外掛 API 擴展一切

### 適合誰使用

Yao Agents 為以下族群設計：

1. **開發者** — 想要構建自訂 AI 工作流程
2. **團隊** — 需要私有化部署的 AI 助手
3. **企業** — 尋找 SaaS AI 平台的自託管替代方案
4. **愛好者** — 喜歡折騰本地 AI 的極客

## 核心概念

### Agent（智慧體）

**Agent** 是具有特定角色、個性和工具集的 AI 助手。每個 Agent 包含：

- 定義其行為的系統提示詞
- 存取一個或多個 LLM 後端
- 可選的 MCP 工具用於外部整合
- Hooks（`Create` / `Next`）用於自訂處理邏輯

### Mission（任務）

**Mission** 是結構化的任務流水線。你可以：

1. 定義目標和子任務
2. 為每個步驟分配 Agent
3. 設定觸發器（手動、排程、事件驅動）
4. 即時監控執行進度

### Hub（中心）

**Hub** 是發現和安裝社群構建的 Agent 的市場。可以把它理解為 AI 助手的「App Store」。

## 架構概覽

| 元件             | 角色                     | 技術棧           |
| ---------------- | ------------------------ | ---------------- |
| Yao Engine       | 核心執行時和 API 伺服器  | Go               |
| SUI Framework    | 伺服端渲染 UI 框架       | HTML + JS + CSS  |
| Agent Runtime    | LLM 編排與工具呼叫       | TypeScript       |
| Tai Link         | P2P 裝置通訊             | Go + WebRTC      |
| CUI              | 對話式 UI 元件           | TypeScript       |
| Mission Control  | 任務流水線引擎           | Go + TypeScript  |

## 快速範例

這是一個最小的 Agent 設定：

```json
{
  "name": "General",
  "description": "通用助手",
  "model": "gpt-4o",
  "system_prompt": "你是一個有用的助手。",
  "tools": ["web_search", "file_reader"],
  "temperature": 0.7
}
```

你也可以用 TypeScript 定義 Hooks：

```typescript
function Create(context: Context): Assistant {
  const assistant = context.newAssistant();
  assistant.setModel("gpt-4o");
  assistant.setSystemPrompt("你是一個有用的助手。");
  return assistant;
}

function Next(context: Context, input: Message): Response {
  const result = context.chat(input);
  if (result.toolCalls.length > 0) {
    return context.executeTool(result.toolCalls[0]);
  }
  return result;
}
```

一個簡單的 YAML 任務定義：

```yaml
name: 每日報告
trigger:
  type: schedule
  cron: "0 9 * * *"
steps:
  - agent: data-collector
    action: fetch_metrics
  - agent: report-writer
    action: generate_report
    input: $prev.output
  - agent: messenger
    action: send_email
    input: $prev.output
```

### 執行 Shell 命令

Agent 在獲得權限後也可以執行 Shell 命令：

```bash
yao agent run general --input "總結今天的日誌"
yao mission start daily-report --env production
```

## 功能對比

| 特性             | Yao Agents       | 雲端 AI SaaS     | 其他開源方案       |
| ---------------- | ---------------- | ---------------- | ------------------ |
| 資料隱私         | 完全自主         | 依賴廠商         | 各有不同           |
| 部署方式         | 自託管           | 僅雲端           | 自託管             |
| 多 Agent 流水線  | 內建支援         | 有限             | 需手動搭建         |
| UI 框架          | SUI（內建）      | 僅儀表板         | 無 / 自行構建      |
| 模型靈活性       | 任意 LLM         | 廠商鎖定         | 任意 LLM           |
| 企業級功能       | RBAC、稽核、SSO  | 支援             | 社群外掛           |
| 社群市場         | Hub              | 廠商商店         | 無                 |

## 安裝速覽

安裝 Yao Agents 就像下載一個普通 App 一樣簡單：

1. 從[官網](https://yaoagents.com/download)下載安裝檔
2. 執行安裝程式 — 支援 **macOS**、**Windows** 和 **Linux**
3. 開啟瀏覽器存取 `http://localhost:5096`

> 詳細步驟請參閱[安裝指南](/docs/zh-tw/getting-started/installation)。
