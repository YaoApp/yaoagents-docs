# 下一步

Yao Agents 已經運行起來，基礎也了解了。根據你接下來想做的事，選擇對應的方向：

## 任務看板 — 讓 AI 幫你執行任務

把要做的事放到看板上，用自然語言描述需求，AI 自動執行。支援分組管理、定時排程、狀態追蹤。

[什麼是任務看板 →](/docs/zh-tw/getting-started/what-is-kanban)

## 收件匣 — 不錯過 AI 的任何進展

任務完成、失敗或 AI 需要你決定時，收件匣統一通知。直接回覆就能讓任務繼續。

[什麼是收件匣 →](/docs/zh-tw/getting-started/what-is-inbox)

## 連接其他裝置 — Tai Link

Tai Link 讓任何機器都成為 AI 團隊可以工作的節點。在第二台電腦、虛擬機器或伺服器上安裝它，Robot 和 Expert 就能在那台裝置上開啟應用程式、移動檔案、執行命令——完全不碰你的主機。

[Tai Link 是什麼 →](/docs/zh-tw/tai-link/what-is-tai-link)

[連接第一台裝置 →](/docs/zh-tw/tai-link/connect-first-device)

## 接入訊息平台

將 Robot 或 Expert 綁定到你團隊使用的聊天應用程式，結果直接推送到大家已經在用的地方。

| 平台 | 連結 |
|------|------|
| 微信 | [接入 →](/docs/zh-tw/integrations/chat-platforms/wechat) |
| 飛書 | [接入 →](/docs/zh-tw/integrations/chat-platforms/lark) |
| 釘釘 | [接入 →](/docs/zh-tw/integrations/chat-platforms/dingtalk) |
| Telegram | [接入 →](/docs/zh-tw/integrations/chat-platforms/telegram) |
| Discord | [接入 →](/docs/zh-tw/integrations/chat-platforms/discord) |

## 新增自己的 AI 模型

Yao Agents 支援任何相容 OpenAI 介面的 API——包括透過 Ollama 執行的本機模型。如果想用安裝時未設定的模型，在 Settings 中新增連接器即可。

[AI 模型 →](/docs/zh-tw/settings/ai-models)

## 擴充 MCP 工具

MCP（Model Context Protocol）工具讓 Expert 和 Robot 能與外部服務互動——你的行事曆、資料庫、內部 API。幾次點擊就能接入任意 MCP 伺服器。

[MCP 工具 →](/docs/zh-tw/settings/mcp-tools)

## 構建或安裝自訂專家

在 Yao Agents Hub 瀏覽社群構建的專家，或者用內建的 AI 開發助手建立自己的。Yao Agents 同時相容 OpenClaw Agent 生態。

[Yao Agents Hub →](/docs/zh-tw/agent-hub/hub-overview)

[自訂 AI Expert →](/docs/zh-tw/agent-hub/custom-assistants)
