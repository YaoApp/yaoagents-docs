# 下一步

Yao Agents 已經運行起來，基礎也了解了。根據你接下來想做的事，選擇對應的方向：

## 連接其他裝置 — Tai Link

Tai Link 讓任何機器都成為 AI 團隊可以工作的節點。在第二台電腦、虛擬機器或伺服器上安裝它，Robot 和 Expert 就能在那台裝置上開啟應用程式、移動檔案、執行命令——完全不碰你的主機。

[Tai Link 是什麼 →](/docs/zh-tw/tai-link/what-is-tai-link)
[連接第一台裝置 →](/docs/zh-tw/tai-link/connect-first-device)

## 讓 Keeper 管理你的知識

Keeper 是知識管理 Agent。給它一個連結、放進一個 PDF、貼上一個 YouTube URL——它會讀取、摘要、存檔所有內容。之後問它問題，它從已學到的內容中給你答案。

[Keeper →](/docs/zh-tw/built-in-agents/keeper)

## 接入訊息平台

將 Robot 或 Expert 綁定到 Telegram、Discord、微信、釘釘或飛書。結果直接推送到你的團隊已經在用的地方。

[訊息平台（IM）→](/docs/zh-tw/integrations/chat-platforms)

## 新增自己的 AI 模型

Yao Agents 支援任何相容 OpenAI 介面的 API——包括透過 Ollama 執行的本機模型。如果想用安裝時未設定的模型，在 Settings 中新增連接器即可。

[AI 模型 →](/docs/zh-tw/integrations/ai-models)

## 擴充 MCP 工具

MCP（Model Context Protocol）工具讓 Expert 和 Robot 能與外部服務互動——你的行事曆、資料庫、內部 API。幾次點擊就能接入任意 MCP 伺服器。

[MCP 工具 →](/docs/zh-tw/integrations/mcp-tools)

## 構建或安裝自訂專家

在 Agent Hub 瀏覽社群構建的專家，或者用內建的 AI 開發助手建立自己的。Yao Agents 同時相容 OpenClaw Agent 生態。

[Agent Hub →](/docs/zh-tw/agent-hub/hub-overview)
[自訂 AI Expert →](/docs/zh-tw/agent-hub/custom-assistants)
