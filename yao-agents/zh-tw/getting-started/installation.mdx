# 安裝

前往[下載頁面](/download)取得 Yao Engine，選擇對應平台與架構。

## 步驟一：啟動 Yao Engine

安裝完成後開啟 Yao Engine，主視窗會列出 Yao 和 Tai 兩個服務。

![Yao Engine](https://assets.yaoagents.com/en/engine/01-engine-app-en-$__THEME.png)

> **注意：** 首次啟動時，App Root 須指向空目錄。版本需求 Yao Agents v1.6.1+。

按下 **Start**，啟動後會顯示各服務的 PID 與存取位址。

![Yao Engine 執行中](https://assets.yaoagents.com/en/engine/02-engine-start-en-$__THEME.png)

## 步驟二：開啟歡迎頁

點擊 **Visit**，瀏覽器會開啟歡迎頁面，接著點 **Get Started**。

![歡迎頁](https://assets.yaoagents.com/en/engine/03-engine-visit-en-$__THEME.png)

## 步驟三：登入

**首次登入**請使用內建管理員帳號：

- **信箱：** `root@yaoagents.com`
- **密碼：** `Yao123++`

![登入](https://assets.yaoagents.com/en/engine/05-engine-login-code-en-$__THEME.png)

> **注意：** 帳號儲存在本機裝置上。如需註冊其他使用者，請先設定 SMTP 郵件服務，否則無法收到註冊驗證碼。

## 步驟四：設定模型

點選側邊欄左下角頭像，進入 **設定 → 模型組態**。

![模型組態](https://assets.yaoagents.com/en/engine/06-engine-models-en-$__THEME.png)

| 欄位 | 用途 |
|------|------|
| Default | 一般日常任務 |
| Heavy | 複雜推理、長上下文 |
| Light | 快速簡易查詢 |
| Vision | 圖片辨識 |
| Audio | 語音轉文字 |
| Embedding | 向量搜尋、知識庫 |

> **注意：** DeepSeek 系列模型不支援圖片與語音。使用 DeepSeek 時，請為 Vision 欄位指定其他模型（如 Claude、GPT-4o），Audio 欄位指定 Whisper 語音轉錄模型。

點擊 **Add Provider** 新增模型供應商，填入憑證。

![新增供應商](https://assets.yaoagents.com/en/engine/07-engine-provider-add-en-$__THEME.png)

> **提示：** 新增 image2（OpenAI 相容介面）的文生圖/圖生圖模型後，Agent 工作時如需產生或編輯圖片會自動調度。

選擇預設模型。

![設定完成](https://assets.yaoagents.com/en/engine/08-engine-provider-default-en-$__THEME.png)

## 步驟五：安裝桌面用戶端

桌面用戶端適合日常使用，與瀏覽器互不衝突。

前往[用戶端下載頁](/download/yaoagents)下載安裝。開啟後填入伺服器位址（與瀏覽器登入的位址相同），點擊 **Connect**。登入方式與瀏覽器相同。

![新增伺服器](https://assets.yaoagents.com/en/servers/02-servers-add-en-$__THEME.png)

> **提示：** 對系統匣圖示按右鍵，可切換伺服器或進入設定。
