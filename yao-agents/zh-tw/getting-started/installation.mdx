# 安裝

前往[下載頁面](/download)取得 Yao Engine，選擇對應平台與架構。

Yao Engine 是本機伺服器：在一台電腦上裝好，就能直接用瀏覽器開始使用。

日常使用建議再裝一個 **Yao Agents 桌面用戶端**，連到這台 Engine。Engine 只要裝一台，**同一個網路內的其他電腦都能連上它**，多台裝置共用一台伺服器。

- 只想先跑起來：裝完用瀏覽器打開即可。
- 日常使用：裝[桌面用戶端](/docs/zh-tw/getting-started/install-client)，體驗更好。

## 步驟一：啟動 Yao Engine

安裝完成後開啟 Yao Engine，主視窗會列出 Yao 和 Tai 兩個服務。

![Yao Engine](https://assets.yaoagents.com/en/engine/01-engine-app-en-$__THEME.png)

> **注意：** 首次啟動時，App Root 須指向空目錄。版本需求 Yao Agents v1.6.1+。

按下 **Start**，啟動後會顯示各服務的 PID 與存取位址。

![Yao Engine 執行中](https://assets.yaoagents.com/en/engine/02-engine-start-en-$__THEME.png)

> **提示：** 這裡的 **Server** 欄位就是存取位址（本機 `http://127.0.0.1:5099`，下面幾行是同網路其他裝置可用的位址）。用戶端要填的伺服器位址就取自這裡。

> **提示：** 在網內其他電腦登入時，用能存取到 Yao Engine 的區域網路位址（如 `http://192.168.x.x:5099`）——瀏覽器打開它，Yao Agents 用戶端也填這個位址。

## 步驟二：開啟歡迎頁

點擊 **Visit**，瀏覽器會開啟歡迎頁面，接著點 **Get Started**。

![歡迎頁](https://assets.yaoagents.com/en/engine/03-engine-visit-en-$__THEME.png)

> **提示：** 歡迎頁右上角的 **Server URL** 也能看到伺服器位址，用戶端填這個位址即可。

## 步驟三：註冊帳號

從歡迎頁進入登入頁，填**你自己的信箱**，點 **Continue**，通過驗證碼驗證。

![輸入信箱](https://assets.yaoagents.com/en/login/login-web-email-en-$__THEME.png)

設定密碼，點 **Sign Up** 完成註冊。帳號會保存在安裝了 Yao Engine 的電腦上，注意不是 Yao Agents 官網的帳號。

![註冊帳號](https://assets.yaoagents.com/en/login/login-web-reg-en-$__THEME.png)

## 步驟四：綁定 Tao

登入後選擇模型來源，建議 **Use Tao Service**：一組 Key 接上模型、搜尋、抓取、儲存等全部服務。

![綁定 Tao](https://assets.yaoagents.com/en/login/login-bind-key-en-$__THEME.png)

到控制台 **Create New Key** 複製 Key。

![取得 Key](https://assets.yaoagents.com/en/login/login-get-key-en-$__THEME.png)

貼進應用，點 **Verify and Configure**。接好後設定裡顯示 **Connected**，模型設定會自動填好。

![設定 Tao Service](https://assets.yaoagents.com/en/login/login-bind-key-step-2-en-$__THEME.png)

綁定成功，直接進入主介面開始使用。

![登入成功](https://assets.yaoagents.com/en/login/login-web-success-en-$__THEME.png)

> 也可以選 **Bring Your Own Key**，自己逐項設定 OpenAI、Anthropic、本機 Ollama 等供應商。

## 步驟五：連接桌面用戶端

桌面用戶端適合日常使用。前往[用戶端下載頁](/download/yaoagents)下載安裝，開啟後填入伺服器位址（本機 Engine 預設 `http://127.0.0.1:5099`），點 **Connect**。

![連接伺服器](https://assets.yaoagents.com/en/login/login-custom-server-url-en-$__THEME.png)

> **提示：** 對系統匣圖示按右鍵，可切換伺服器或進入設定。

完整步驟見[安裝桌面用戶端](/docs/zh-tw/getting-started/install-client)。
