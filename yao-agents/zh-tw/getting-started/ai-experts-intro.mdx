# AI 專家

Yao Agents 內建多位 AI 專家，各自專精一類工作。選對專家，說出需求，剩下的交給它。

![AI 專家列表](https://assets.yaoagents.com/en/experts/03-experts-full-en-$__THEME.png)

### DeepSeek Harness

基於 DeepSeek Harness 的通用 Agent。程式開發、研究、資料分析、寫作、自動化——在持久化沙箱中完成，終端機、瀏覽器、VNC 桌面一應俱全。

![DeepSeek Harness](https://assets.yaoagents.com/en/experts/04-expert-deepseek-harness-en-$__THEME.png)

[查看詳情 →](/docs/zh-tw/built-in-agents/deepseek-harness)

### Claude Code

基於 Claude Code 的通用 Agent。程式開發、研究、資料分析、寫作、自動化——同樣配備持久化沙箱和即時預覽。

![Claude Code](https://assets.yaoagents.com/en/experts/05-expert-claude-code-en-$__THEME.png)

[查看詳情 →](/docs/zh-tw/built-in-agents/claude-code)

### Agent Smith

打造你的專屬 AI 專家。描述需求，Agent Smith 會自動搜尋技能、組裝專家、在沙箱中測試，然後上線到你的專家列表。

![Agent Smith](https://assets.yaoagents.com/en/experts/06-expert-agent-smith-en-$__THEME.png)

[查看詳情 →](/docs/zh-tw/built-in-agents/agent-smith)

### Web Builder

用對話建構並部署網站。Next.js + Tailwind，VNC 即時預覽，一鍵 SSH 部署並自動設定 HTTPS。

![Web Builder](https://assets.yaoagents.com/en/experts/07-expert-web-builder-en-$__THEME.png)

[查看詳情 →](/docs/zh-tw/built-in-agents/website)

### Applet Workshop

描述一個工具，直接得到可執行的應用。計算機、看板、轉換器、AI 工具——在桌面上即時建構和預覽。

![Applet Workshop](https://assets.yaoagents.com/en/experts/08-expert-applet-workshop-en-$__THEME.png)

[查看詳情 →](/docs/zh-tw/built-in-agents/applet)

### Slides

輸入主題、大綱或文件，生成精美簡報。9 套內建主題，1920×1080 PDF 匯出。

![Slides](https://assets.yaoagents.com/en/experts/09-expert-slides-en-$__THEME.png)

[查看詳情 →](/docs/zh-tw/built-in-agents/slides)

### Insights

連接資料庫或拖入表格，Insights 設計指標、建構互動式 ECharts 看板，並即時預覽。

![Insights](https://assets.yaoagents.com/en/experts/10-expert-insights-en-$__THEME.png)

[查看詳情 →](/docs/zh-tw/built-in-agents/insights)

## 如何選擇專家

在首頁開啟 **AI 專家** 面板，透過分類標籤篩選或搜尋名稱。

## 切換模型

預設使用你設定的主模型。對話過程中可透過底部的模型選擇器隨時切換。

![模型選擇器](https://assets.yaoagents.com/en/chat/08-chat-model-picker-en-$__THEME.png)
