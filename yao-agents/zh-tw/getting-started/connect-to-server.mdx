# 連接到伺服器

本指南幫助你將 Yao Agents 用戶端連接到伺服器。

## 第一步：取得伺服器地址

造訪[伺服器](/servers)頁面，找到離你最近的伺服器，複製伺服器地址。

## 第二步：開啟 Yao Agents

在你的裝置上啟動 Yao Agents 桌面應用。

## 第三步：設定伺服器

進入 **設定 → 伺服器**，貼上你複製的伺服器地址。

## 第四步：登入或註冊

如果伺服器需要邀請碼，請在[伺服器](/servers)頁面申請。否則直接建立帳號。
