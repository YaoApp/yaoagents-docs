# 連接雲端伺服器

Yao Agents 預設連接本機 Yao Engine（Local Server）。如果不打算在自己的裝置上安裝 Engine，也可以直接連接一台雲端伺服器——登入後即可使用全部 AI 專家，無需任何本機設定。

## 本機 vs 雲端

| | 本機 (Local Server) | 雲端 (Cloud Server) |
|---|---|---|
| 需要安裝 Yao Engine | 是 | 否 |
| 資料儲存 | 全部在你的裝置上 | 儲存在伺服器端 |
| AI 模型 | 自備 Key 或接入雲端服務 | 伺服器預先設定 |
| Tai Link 節點 | 自行連接 | 伺服器提供共享節點 |
| 適合場景 | 注重隱私、長期使用 | 快速體驗、團隊共享 |

## 連接步驟

### 1. 選擇雲端伺服器

開啟用戶端，在伺服器選擇視窗的 **Cloud Servers** 頁籤選一台雲端伺服器（例如 Polaris (Trial Server) `https://bj.yaoagents.cn`）。

![選擇雲端伺服器](https://assets.yaoagents.com/en/login/login-cloud-servers-en-$__THEME.png)

也可以切到 **Custom Server** 頁籤，自己填伺服器位址。

![自訂伺服器](https://assets.yaoagents.com/en/login/login-custom-server-url-en-$__THEME.png)

### 2. 連接

點 **Connect**。部分伺服器需要邀請碼，可在網站申請。

### 3. 登入 / 註冊

先填你自己的電子郵件，通過驗證碼驗證，點 **Continue**。

![輸入電子郵件](https://assets.yaoagents.com/en/servers/04-servers-login-en-$__THEME.png)

- **已註冊**：驗證後直接登入。
- **還沒註冊**：設定密碼，點 **Sign Up** 完成註冊。

![設定密碼](https://assets.yaoagents.com/en/login/login-reg-en-$__THEME.png)

### 4. 開始使用

登入後進入主介面，所有 AI 專家已就緒，操作方式與本機伺服器相同。

![主介面](https://assets.yaoagents.com/en/login/login-inbox-en-$__THEME.png)

## 切換伺服器

你可以隨時切換伺服器。對系統匣圖示按右鍵，或點左上角的伺服器名稱，即可回到伺服器選擇視窗。

## 可用伺服器

造訪 [/servers](/servers) 頁面查看目前可用的雲端伺服器、地區與註冊方式。
