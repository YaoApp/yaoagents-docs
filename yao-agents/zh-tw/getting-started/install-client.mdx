# 安裝桌面用戶端

桌面用戶端適合日常使用，連接你自己電腦上的 Yao Engine。完整流程如下。

## 1. 下載與安裝

macOS、Windows、Linux 都有，到[用戶端下載頁](/download/yaoagents)下載，像裝一般 App 一樣安裝。

## 2. 連接本機 Engine

打開用戶端，在伺服器選擇視窗切到 **Custom Server** 頁籤。

![Custom Server](https://assets.yaoagents.com/en/login/login-custom-server-en-$__THEME.png)

填入本機 Engine 位址 `http://127.0.0.1:5099`（與瀏覽器登入位址相同），點 **Connect**。

![填入位址](https://assets.yaoagents.com/en/login/login-custom-server-url-en-$__THEME.png)

> 連不上時，先確認 Yao Engine 已啟動、位址與連接埠正確。

## 3. 登入 / 註冊

先填電子郵件，通過驗證碼驗證，點 **Continue**。

![輸入電子郵件](https://assets.yaoagents.com/en/servers/04-servers-login-en-$__THEME.png)

- **已註冊**：驗證後直接登入。
- **還沒註冊**：設定密碼，點 **Sign Up** 完成註冊。

![設定密碼](https://assets.yaoagents.com/en/login/login-reg-en-$__THEME.png)

## 4. 設定模型服務

登入後選擇模型來源：

- **Use Tao Service（推薦）**：一組 Key 接上模型、搜尋、抓取、儲存等全部服務。
- **Bring Your Own Key**：自己接 OpenAI、Anthropic、本機 Ollama 等。

![選擇模型服務](https://assets.yaoagents.com/en/login/login-bind-key-en-$__THEME.png)

選 Tao Service：到控制台 **Create New Key** 複製 Key。

![取得 Key](https://assets.yaoagents.com/en/login/login-get-key-en-$__THEME.png)

貼進應用，點 **Verify and Configure**。

![設定 Tao Service](https://assets.yaoagents.com/en/login/login-bind-key-step-2-en-$__THEME.png)

## 5. 開始使用

進入主介面，選專家、傳訊息、建立任務。

![主介面](https://assets.yaoagents.com/en/login/login-inbox-en-$__THEME.png)

> **提示：** 對系統匣圖示按右鍵，可切換伺服器或進入設定。
