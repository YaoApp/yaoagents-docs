# 安裝 Tai Link

在你想讓 Agent 工作的那台機器上安裝 Tai Link 服務端，整個流程大約五分鐘。

## 開始之前

- 已有一個執行中的 Yao Agents 實例（本地或雲端），遠端機器能透過網路存取到它。
- 遠端機器執行 **macOS、Linux 或 Windows**（x86-64 或 ARM64）。

## 下載

前往 [yaoagents.com/download](/download) 下載適合你平台的 Tai Link 安裝包。

| 平台 | 檔案名稱 |
|------|---------|
| macOS（Apple Silicon）| `tai-darwin-arm64` |
| macOS（Intel）| `tai-darwin-amd64` |
| Linux（x86-64）| `tai-linux-amd64` |
| Linux（ARM64）| `tai-linux-arm64` |
| Windows（x86-64）| `tai-windows-amd64.exe` |

下載後將二進位檔放到 PATH 中。

**macOS / Linux：**

```bash
chmod +x tai-*
sudo mv tai-* /usr/local/bin/tai
```

**Windows：**

將 `.exe` 移動到系統 PATH 下的目錄，或直接從下載位置執行。

## 啟動服務端

指定 Yao Agents 實例位址啟動 Tai Link：

```bash
tai server http://<你的_YAO_伺服器>:5099
```

將 `<你的_YAO_伺服器>` 替換為執行 Yao Agents 的機器 IP 或主機名稱。

## 設定檔（可選）

在正式環境中，建議建立 `config.yml` 代替命令列參數：

```yaml
yao:
  server: "http://<你的_YAO_伺服器>:5099"
  display_name: "辦公室伺服器"

data: /data/volumes

log:
  level: info
  file: logs/tai.log
```

然後以設定檔啟動：

```bash
tai server --config config.yml
```

Tai Link 預設在目前目錄和 `/etc/tai/config.yml` 尋找設定檔。

## 驗證安裝

啟動後，終端機應顯示：

```
tai server ready
```

若 Yao 伺服器可達，Tai Link 會自動完成認證和註冊。切換到 Yao Agents 介面——裝置應在幾秒內出現在 Tai Link 面板中。
