# 連接第一台裝置

設定 Tai Link，透過 Server Key 將遠端機器接入 Yao Agents。

## 準備

- 目標機器已[安裝 Tai Link](/docs/zh-tw/tai-link/installation)。
- 一台正在執行的 Yao Engine 伺服器（Yao v1.0.0-rc10+），目標機器能透過網路存取。

## 第 1 步 — 建立 Server Key

如果已有 Server Key 可直接沿用——同一個 Key 支援多台裝置同時使用。否則建立新的：

在 Yao Engine 介面底部點選 **Open Terminal**。

![Yao Engine — 點選 Open Terminal](https://assets.yaoagents.com/en/engine/02-engine-start-en-$__THEME.png)

執行：

```bash
yao server-key create --name "my-node"
```

輸出：

```
  Server key created successfully

  Key ID:  sk-a1b2c3d4e5f6
  Name:    my-node
  Key:     yao-sk:64-char-hex-string...

  ⚠ Save this key now. It will not be shown again.
```

複製完整 Key（`yao-sk:...`），第 2 步會用到。

## 第 2 步 — 編寫設定檔

在目標機器上建立 `config.yml`：

**macOS / Linux:**

```yaml
yao:
  server: "<YOUR_YAO_SERVER>"
  node_id: "my-node"
  display_name: "Office Server"
  server_key: "yao-sk:your-key-here"

data: /path/to/your/data

host_exec:
  only: true
  full_access: true

log:
  level: info
```

**Windows:**

```yaml
yao:
  server: "<YOUR_YAO_SERVER>"
  node_id: "my-node"
  display_name: "Office Server"
  server_key: "yao-sk:your-key-here"

data: "C:\\TaiData"

host_exec:
  only: true
  full_access: true

log:
  level: info
  file: logs/tai.log
```

| 欄位 | 說明 |
|------|------|
| `yao.server` | Yao Agents 伺服器位址。在 Yao Engine 歡迎頁可以看到，與用戶端登入位址相同。 |
| `yao.node_id` | 節點唯一識別碼。多台裝置之間不能重複。 |
| `yao.display_name` | 在 Yao Agents 介面中顯示的名稱。 |
| `yao.server_key` | 第 1 步建立的 Server Key。 |
| `data` | 工作空間資料目錄，Agent 在此讀寫檔案。Windows 路徑需使用雙反斜線（`\\`）。 |
| `host_exec.only` | 宿主機執行模式——Agent 直接在本機執行命令，不使用 Docker 容器。 |
| `host_exec.full_access` | 不限制命令與路徑，允許完全存取。 |

## 第 3 步 — 啟動 Tai Link

```bash
tai server --config config.yml
```

正常啟動後會看到類似輸出：

```
level=INFO msg="logger initialized" level=info format=text file=logs/tai.log
level=INFO msg="tai server" module=server version=1.8.6 ...
level=INFO msg="tai server starting" module=server grpc=[127.0.0.1:0] ...
```

Tai Link 透過 Server Key 自動認證，無需瀏覽器登入。裝置會在幾秒內出現在 Yao Agents 介面中。

## 第 4 步 — 確認連線

點選頂部導覽列的 **電腦**，開啟電腦面板。新裝置應顯示為 **Running**。

![Tai Link — 裝置面板](https://assets.yaoagents.com/en/tai/01-tai-devices-en-$__THEME.png)

建立工作區時，即可選擇該節點作為執行環境。

## 管理 Server Key

列出所有 Key：

```bash
yao server-key list
```

撤銷 Key：

```bash
yao server-key revoke sk-a1b2c3d4e5f6
```

## 常見問題

**裝置沒有出現在 Tai Link 面板。**
檢查目標機器能否存取 Yao 伺服器，確認防火牆未攔截出站連線。查看 Tai Link 終端機的錯誤訊息。

**裝置顯示「Offline」但 Tai Link 正在執行。**
隧道可能斷開了。Tai Link 會自動重連（指數退避）。檢查網路並稍等片刻。
