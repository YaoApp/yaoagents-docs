# 自訂 AI 專家

Yao Agents 內建了一批 AI 專家，你也可以依需求建立自己的。

## 1. 用 Agent Smith 構建

開啟 Agent Smith，描述你想要的專家——它會自動搜尋技能庫、搭建、測試並部署。全程不用寫程式碼。

Agent Smith 能自動從全球技能庫（10 萬+）和第三方生態中搜尋現成方案，安全審查後按你的需求適配定制。

→ [Agent Smith 詳情](/docs/zh-tw/built-in-agents/agent-smith)

## 2. 撰寫程式碼建立

使用 Yao DSL 撰寫自訂 AI 專家，完全掌控提示詞、工具、沙箱和行為。

→ [建立你的第一個 Agent](https://yaoapps.com/docs/tutorials/en-us/agent/getting-started/index) — YaoApps.com 上的逐步教學
