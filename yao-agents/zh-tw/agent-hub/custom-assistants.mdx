# 自訂 AI 專家

Yao Agents 內建了一批 AI 專家，你也可以依需求擴充。以下是新增專家的幾種方式。

## 1. 從 Yao Agents Hub 安裝

在 Yao Agents Hub 中瀏覽社群建立的現成專家，一鍵安裝即可使用。

> **早期體驗（Early Access）。** Yao Agents Hub 目前處於早期體驗階段。

## 2. 讓 AI 開發專家幫你建立

開啟內建的 AI 開發專家，描述你想要的專家角色，它會自動生成設定並完成安裝——無需撰寫程式碼。

> **早期體驗（Early Access）。** 該功能目前處於早期體驗階段。

## 3. 撰寫程式碼建立

使用 Yao DSL 撰寫自訂 AI 專家，完全掌控提示詞、工具、沙箱和行為。

→ [建立你的第一個 Agent](https://yaoapps.com/docs/tutorials/en-us/agent/getting-started/index) — YaoApps.com 上的逐步教學

## 4. 探索第三方生態

Yao Agents 相容來自開放社群生態的 Agent。你可以在以下平台瀏覽，將相容的 Agent 適配到 Yao Agents 中使用。

- [ClawHub](https://clawhub.ai/) — 社群建立的技能和外掛
- [Hermes Agent Skills Hub](https://hermes-agent.nousresearch.com/docs/skills) — Nous Research 維護的開放 Agent 技能登錄中心

> **早期體驗（Early Access）。** 第三方生態整合目前處於早期體驗階段。這些均為獨立的第三方社群，部分 Agent 可能需要適配才能使用。
