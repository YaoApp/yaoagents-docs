# Yao Agents Hub

Yao Agents Hub 是發現、安裝和分享 AI 專家的開放市場——為各類工作流量身打造的專業專家。

> **早期體驗（Early Access）。** Yao Agents Hub 目前處於早期體驗階段，正式公測即將啟動。

## 內建專家

Yao Agents 隨產品預裝了一批開箱即用的專家。

| 專家 | 擅長什麼 |
|------|---------|
| [General](/docs/zh-tw/built-in-agents/general) | 通用助手——問答、編程、調研、寫作 |
| [PM](/docs/zh-tw/built-in-agents/pm) | 專案經理——任務拆解、進度追蹤、團隊協作 |
| [Postman](/docs/zh-tw/built-in-agents/postman) | 郵件助手——透過 SMTP/IMAP 收發、撰寫郵件 |
| [Insights](/docs/zh-tw/built-in-agents/insights) | 資料分析——資料庫、表格、ECharts 互動看板 |
| [Market Scout](/docs/zh-tw/built-in-agents/scout) | 市場情報——監控訂閱源、分類歸檔洞察 |
| [Slides](/docs/zh-tw/built-in-agents/slides) | 簡報製作——大綱轉 HTML 簡報，匯出 PDF |
| [Transformer](/docs/zh-tw/built-in-agents/transformer) | 資料結構化——圖片、PDF、JSON、CSV 轉換 |
| [Web Builder](/docs/zh-tw/built-in-agents/website) | 網站建構——Next.js + Tailwind，VNC 預覽 + SSH 部署 |
| [Applet Workshop](/docs/zh-tw/built-in-agents/applet) | 小工具開發——Node.js 可視化 mini-tool，VNC 即時預覽 |
| [Report Writer](/docs/zh-tw/built-in-agents/report-writer) | 報告撰寫機器人——在任務控制中心自動生成結構化 Markdown 報告 |
