# 連接微信

將機器人接入微信，用戶直接在微信裡發訊息即可對話——對方無需安裝任何額外軟體。

微信透過 **ClawBot 插件**接入，這是微信官方插件體系中的一個渠道插件，由騰訊提供支援。連接後，機器人以一個微信號的身份在線，用戶加好友後即可開始聊天。

## 開始之前

- 機器人已在 Mission Control 中建立。
- 準備一個專用微信號（個人帳號即可，不需要公眾號或小程式）。
- 微信客戶端：請升級至最新版本（iOS / Android 均支援）。
- 執行 Yao Agents 的伺服器在掃碼期間及機器人執行時需保持聯網。

## 第一步 — 開啟整合面板

1. 在 Mission Control 中點擊要連接的機器人。
2. 進入 **設定 → 整合** 標籤頁。
3. 找到 **微信** 卡片，將開關打開。

![Mission Control — 整合面板，微信卡片](https://placehold.co/1200x750/1a1a2e/ffffff?text=Screenshot+needed%3A+Robot+Integration+panel+%E2%80%94+WeChat+card)

## 第二步 — 掃碼連接

點擊 **掃碼連接**，Mission Control 頁面彈出含連接碼的對話框。

在手機微信中，按以下路徑開啟 ClawBot 插件：

**我 → 設定 → 插件 → 微信 ClawBot → 詳情**

在 ClawBot 插件詳情頁，點擊 **開始掃一掃**，掃描 Mission Control 頁面上顯示的二維碼。

> 💡 二維碼有效期為 3 分鐘。超時後關閉對話框重新開啟即可刷新。

**首次連接時**，微信會提示你授權 ClawBot 插件存取該帳號，確認授權後連接即建立。

掃碼成功後，對話框自動關閉，卡片顯示 **已連接** 及微信帳號名稱。

## 第三步 — 儲存

點擊 **儲存**（設定面板頂部儲存按鈕）。機器人現在已在微信上線。

用任意手機向該微信號發訊息，機器人即會回覆。

## 重新連接

若連接中斷（例如伺服器重啟後），開啟整合面板，點擊微信卡片上的 **重新連接** 重新掃碼即可。

## 常見問題

**彈出「ClawBot 插件未安裝」或「不支援此功能」。**
當前微信版本過舊，請將微信升級至最新版本後重試。

**掃碼後「已連接」狀態一直不出現。**
確認使用 iOS 8.0.70+ 的微信，且已授權 ClawBot 插件。確認該帳號未在其他裝置上同時登入。

**機器人過一段時間後停止回覆。**
微信工作階段可能逾時，重新掃碼連接即可。建議保持 Yao Agents 伺服器持續執行以避免中斷。

**提示「已在其他裝置登入」。**
先在其他裝置退出該微信帳號，再重新掃碼。
