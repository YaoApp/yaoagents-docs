# API 金鑰

> **僅限企業版。** API 金鑰管理需要企業版訂閱。[了解企業版](/enterprise)

產生 API 金鑰，用於從外部程式碼、腳本或整合系統呼叫機器人時進行身份驗證。

## 開始之前

管理 API 金鑰需要先在帳戶上啟用 **兩步驗證（2FA）**。若尚未設定 2FA，存取此頁面時會提示你先完成設定。

前往 **設定 → 安全性** 啟用 2FA。

## 建立 API 金鑰

1. 進入 **設定 → API 金鑰**。
2. 輸入一個選填名稱（如「正式環境」、「CI/CD 流程」）。
3. 點擊 **建立新金鑰**。
4. 立即複製金鑰——離開此頁面後金鑰值將被部分遮蔽。

![設定 — API 金鑰頁面](https://placehold.co/1200x750/1a1a2e/ffffff?text=Screenshot+needed%3A+Settings+%E2%86%92+API+Keys)

> ⚠️ 完整金鑰只顯示一次。請妥善保存，視同密碼處理。

## 使用金鑰

在每個 API 請求的 `Authorization` 請求標頭中帶入金鑰：

```
Authorization: Bearer <你的 API Key>
```

完整端點說明與程式碼範例請見 [API 直連](/docs/zh-tw/integrations/api-direct-connect)。

## 管理金鑰

每個金鑰顯示以下資訊：

| 欄位 | 說明 |
|------|------|
| 名稱 | 建立時填寫的標籤 |
| 金鑰 | 遮蔽值（`sk-xxx...xxxx`），附複製與顯示按鈕 |
| 狀態 | `活躍` 或 `停用` |
| 建立時間 | 建立日期 |
| 最後使用 | 最近一次請求日期，或「從未」 |

**刪除**金鑰：點擊金鑰卡片上的刪除圖示並確認。刪除立即生效且不可復原——使用該金鑰的所有程式碼將立即失效。
