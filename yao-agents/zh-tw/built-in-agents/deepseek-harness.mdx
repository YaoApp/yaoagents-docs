# DeepSeek Harness

![DeepSeek Harness](https://assets.yaoagents.com/en/experts/04-expert-deepseek-harness-en-$__THEME.png)

基於 DeepSeek Harness 的通用 Agent。程式開發、研究、資料分析、寫作、自動化——在持久化沙箱中完成一切，終端機、檔案系統、瀏覽器和 VNC 桌面全部就緒。

## 擅長什麼

- **程式開發** — 撰寫、執行、除錯和重構任何語言的程式；搭建和維護複雜專案
- **研究** — 抓取網頁、綜合多源資訊、生成結構化報告
- **資料分析** — 處理 CSV、JSON、Excel 檔案；執行分析；生成圖表和看板
- **寫作** — 撰寫報告、方案、郵件、Markdown 或 HTML 文件
- **自動化** — 建構腳本、CLI 工具和流水線，將重複工作自動化
- **即時預覽** — 在沙箱中執行應用和工具，透過 VNC 即時查看結果

## 工作原理

DeepSeek Harness 運行在持久化的 Docker 沙箱中，配備完整桌面環境。擁有終端機、瀏覽器、檔案系統和網路存取——相當於一台完整的工作機器。

它使用 DeepSeek V4 Pro 或 V4 Flash 作為推理引擎。你描述需求，它規劃方案、執行工作、觀察結果並反覆迭代，直到滿意為止。

沙箱生命週期為 `longrunning`——閒置時暫停，返回時自動恢復。程式碼、檔案和專案狀態跨對話永久保存。

如果未啟用 Docker 沙箱，任務將直接在安裝 Yao Engine 的機器上執行。

## 使用技巧

**描述期望的結果和約束。** 告訴它完成後應該是什麼樣，加上邊界條件。不要指揮怎麼做——讓它自己規劃路徑。「找出哪些產品在拉動營收增長，按地區拆分給我看」就夠了。

**提前給足上下文。** 附上檔案、貼上截圖、引用工作區內已有的文件，或詳細描述當前狀況。上下文越充分，來回溝通的輪次越少。

**複雜任務分階段推進。** 先讓它調研，再制定方案，最後執行。避免一上來就做錯方向。例如：「先看看這個表格有什麼資料，然後建議可以做哪些分析。」

**給出可驗證的完成標準。** 如果你能描述「做對了是什麼樣」——特定格式的檔案、展示某個趨勢的圖表、包含特定章節的報告——就直接說。它會在交付前自行檢查。

**持續對話，不斷推進。** 每條訊息都基於之前的完整上下文。直接說「加一個同比對比」或「再精簡一些」——它保留完整語境，從上一步接著做。

**範例：**

> 調研 [產業] 排名前 5 的競爭對手，整理他們的定價模式，生成對比表格。

> 分析附件的 sales-report.xlsx。哪些產品增速最快？做一個包含關鍵指標的資料看板。

> 為 [主題] 撰寫一份專案方案。受眾：管理層。控制在 3 頁以內，附時間表和預算估算。

> 每日監控這個 RSS 來源，彙總與 [話題] 相關的內容，並儲存到日誌檔案中。
