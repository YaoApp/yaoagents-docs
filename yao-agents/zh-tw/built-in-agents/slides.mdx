# Slides

將想法、大綱或文件轉化為精美的簡報並匯出為 PDF。給 Slides 一個主題或貼上你的內容——它負責結構、設計和輸出。

## 擅長做什麼

- **製作投影片** — 接受任意輸入（主題、條列清單、文件、會議記錄）並構建結構完整、設計精良的簡報
- **專業主題** — 9 個內建主題：Tech、Business、Science、Nature、Education、Art、Culture、Lifestyle、Health
- **PDF 匯出** — 1920×1080 高畫質 16:9 PDF（2× 視網膜螢幕），可直接分享或簡報
- **內容生成** — 使用內建 LLM 撰寫和潤飾投影片內容，包括摘要和翻譯
- **資料搜集** — 可擷取網路內容，用最新資料補充你的投影片
- **自訂視覺** — 依需求為投影片生成圖片

## 工作原理

Slides 遵循四階段工作流程：**大綱 → 內容 → 設計 → 匯出**。

首先根據你的輸入提出投影片結構。經你確認（或調整）後，為每張投影片撰寫內容，套用所選主題，渲染 HTML，並截圖驗證版面。最後匯出為 PDF 並將檔案交付到 Workspace。

沙箱使用 desktop-lite 映像，沒有完整的 VNC 顯示——渲染為無頭模式。生命週期為 `oneshot`，每次對話重新開始。檔案儲存到 Workspace 並跨工作階段持久保留。

## 怎麼寫好 Prompt

**從主題開始或貼上你的內容。** Slides 需要猜測的越少，結構越好。一行主題就夠；貼上會議記錄效果更好。

**說明長度和受眾。** 「10 張投影片用於產品發布，受眾是銷售團隊」給了 Slides 足夠的脈絡來校準深度和語氣。

**如果有偏好，指定主題。** 否則 Slides 根據主題自動選擇——大多數專業場合預設是 Tech 或 Business。

**在生成內容前迭代大綱。** 在 Slides 寫好所有文案之前調整結構更快捷。

**範例：**

> 製作一個 10 張投影片的簡報，介紹我們的新產品：一個 AI 驅動的分析平台。受眾：企業銷售。使用 Business 主題。

> 製作一個關於 2026 年 AI 趨勢的簡報——8 張投影片，Tech 主題，面向一般受眾。

> 將這些會議記錄轉化為 6 張投影片的摘要：[貼上記錄]

> 將這個現有簡報翻譯成英文並重新設計為 Business 主題。

## 能力速覽

| 能力 | 說明 |
|------|------|
| 輸入 | 主題、大綱、文件文字、會議記錄 |
| 主題 | Tech、Business、Science、Nature、Education、Art、Culture、Lifestyle、Health |
| 輸出 | HTML 投影片 + PDF（16:9，1920×1080，2× 視網膜螢幕） |
| AI 功能 | 內容撰寫、摘要、翻譯、網路搜尋、圖片生成 |
| 沙箱 | `claude-desktop-lite` 映像，4 GB 記憶體，`oneshot` 生命週期 |
| Workspace | 永久儲存——投影片檔案無限期保留 |
