# Market Scout

你的市場情報資訊流。訂閱資訊來源——新聞網站、產業部落格、競品頁面——Market Scout 自動監控、取得最新內容、分類整理，匯入你的市場研究集合。

## 擅長做什麼

- **資訊來源監控** — 定期檢查訂閱的資訊來源，取得新內容
- **內容分類** — 按產業、主題和相關性自動打標籤，無需手動整理
- **趨勢分析** — 識別多個資訊來源中的模式，發現新興主題
- **簡報** — 產生跨所有監控資訊來源的日報或週報摘要
- **按需查詢** — 按主題提問，從已收集的資料中取得相關條目

## 工作原理

Market Scout 按排程或按需從你設定的訂閱資訊來源讀取內容。取得新內容後，按主題和相關性分類每篇文章，然後存入你的**市場研究**集合（也可透過 Keeper 存取）。

Market Scout 沒有沙箱容器，作為輕量級 Agent 執行。所有收集的情報跨對話持久保存在知識庫中。

大量監控場景下，將 Market Scout 與 Mission Control 中的定時 Robot 搭配使用——設定為每天執行，它會自動更新你的集合，無需手動觸發。

## 怎麼寫好 Prompt

**從資訊來源開始。** 第一次使用時，告訴 Scout 要監控哪些網站或資訊來源：「把這三個 URL 新增到我的監控清單。」之後「檢查更新」就夠了。

**檢索時縮小範圍。** 「本週 AI Agent 框架有什麼新動態？」或「尋找過去一個月關於供應鏈的文章」能讓搜尋結果更精準。

**請求簡報。** 「給我今天的市場摘要」是快速取得所有資訊來源摘要的方法。

**範例：**

> 把這些資訊來源新增到我的監控清單：https://techcrunch.com，https://www.theinformation.com，https://news.ycombinator.com

> 從所有訂閱資訊來源取得今天的更新。

> AI 基礎設施領域的最新趨勢是什麼？

> 給我本週收集的所有內容的週報摘要。

> 尋找過去兩週關於競品定價或募資的文章。

## 能力速覽

| 能力 | 說明 |
|------|------|
| 輸入 | 訂閱 URL、按需主題查詢 |
| 分類 | 按產業、主題和相關性自動打標籤 |
| 輸出 | 市場研究集合（與 Keeper 共享） |
| 簡報格式 | 日報摘要、週報 |
| 沙箱 | 無容器——輕量級 Agent，知識庫持久儲存 |
| Workspace | 知識庫永久保存，跨對話持續可用 |
