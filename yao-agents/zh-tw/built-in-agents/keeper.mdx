# Keeper

你的知識中心。儲存任何內容——網頁、筆記、研究資料、檔案——隨時找回。Keeper 自動閱讀、打標籤、分類整理，你不需要手動操作。

## 擅長做什麼

- **儲存網頁** — 貼上 URL，Keeper 自動擷取全文內容並存檔，支援搜尋
- **儲存筆記和研究資料** — 貼上文字片段、會議記錄或研究發現，Keeper 自動分類打標籤
- **檔案攝取** — 上傳 PDF、文件等檔案，Keeper 讀取並建立索引
- **整理到集合** — 依主題和類型分組，不是簡單堆成一個清單
- **檢索** — 用關鍵字、標籤或自然語言搜尋所有存檔內容

## 工作原理

Keeper 是對話式知識庫。你把內容交給它——URL、一段文字、一個檔案——它自動儲存、分類、打標籤。每筆記錄都帶有後設資料（來源、日期、主題、類型），方便日後查找。

搜尋支援自然語言。你可以問「上個月我儲存的競品定價內容」，Keeper 會在索引裡查找並返回相關條目。

沒有沙箱容器——Keeper 是輕量級 Agent，背後是綁定到你 Workspace 的結構化知識庫。資料跨對話持久保存。

## 怎麼寫好 Prompt

**給來源，不要給摘要。** 直接貼上 URL 或上傳檔案，讓 Keeper 自己讀。不需要你先總結內容。

**主動指定標籤。** 如果你想依專案或主題整理，說出來：「儲存這個，打上 Q2 研究的標籤。」Keeper 也會自動打標籤，但你指定的優先。

**用自然語言檢索。** 描述你要找什麼就好：「我儲存過的關於 MUJI 的內容」或「所有打了 pricing 標籤的條目」。

**範例：**

> 把 https://www.bcg.com/publications/2025/ai-agent-trends 儲存到我的研究集合，打上 AI strategy 標籤。

> 存這條會議記錄，打上 product 和 Q2 標籤：[貼上內容]

> 搜尋我最近兩週儲存的競品定價相關內容。

> 我儲存過哪些關於供應鏈中斷的內容？

## 能力速覽

| 能力 | 說明 |
|------|------|
| 輸入方式 | URL 貼上、文字輸入、檔案上傳 |
| 檔案類型 | PDF、文件、純文字 |
| 整理方式 | 自動打標籤、主題分類、集合管理 |
| 檢索 | 關鍵字搜尋、標籤篩選、自然語言查詢 |
| 沙箱 | 無容器——輕量級 Agent，知識庫持久儲存 |
| Workspace | 知識庫永久保存，跨對話持續可用 |
