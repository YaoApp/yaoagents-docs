# Claude Code

![Claude Code](https://assets.yaoagents.com/en/experts/05-expert-claude-code-en-$__THEME.png)

基於 Claude Code 的通用 Agent。程式開發、研究、資料分析、寫作、自動化——在複雜推理、長上下文理解和精細執行方面表現尤為出色。

## 擅長什麼

- **程式開發** — 建構完整應用、重構程式碼庫、除錯、維護複雜多檔案專案
- **研究** — 抓取網頁、綜合多源資訊、生成結構化報告
- **資料分析** — 處理 CSV、JSON、Excel 檔案；執行分析；生成圖表和看板
- **寫作** — 撰寫報告、方案、文件和 API 規範，表達精準細膩
- **自動化** — 建構腳本、CLI 工具和流水線，將重複工作自動化
- **即時預覽** — 在沙箱中執行和測試一切，配備完整 VNC 桌面

## 工作原理

Claude Code 運行在與 DeepSeek Harness 相同的持久化 Docker 沙箱中——完整桌面、終端機、檔案系統、瀏覽器和 VNC。不同之處在於模型：它使用 Claude 進行推理，在複雜決策、長上下文理解和精細執行方面表現出色。

你描述任務，Claude Code 規劃方案、執行工作並驗證結果。對於大型任務，它會將工作拆分為步驟，逐步檢驗後再繼續。

沙箱生命週期為 `longrunning`——閒置時暫停，返回時自動恢復。你建構的一切跨對話永久保存。

如果未啟用 Docker 沙箱，任務將直接在安裝 Yao Engine 的機器上執行。

## 使用技巧

**說清結果和約束。** 不要一步步指揮，描述你希望完成後是什麼樣，加上邊界條件。「把這份 50 頁 PDF 總結為 2 頁管理層摘要，聚焦財務風險」比「先讀第 1 頁，再讀第 2 頁」好得多。

**複雜任務讓它先問你。** 對於非簡單任務，先給個簡要描述，讓它向你提問。它會幫你發現你沒想到的邊界情況和取捨。

**先調研，再方案，再執行。** 大任務時把研究和行動分開。讓它先理解情況、提出計畫，你確認後再動手。避免白做功。

**給出可驗證的成功標準。** 如果你能描述「正確」是什麼樣——具體數字、格式要求、跟參照物對比——就寫進去。它會在交付前自行校驗。

**持續對話，不斷推進。** 每條訊息都基於之前的完整上下文。引用工作區內的文件、追問、調整結果。「把剛才的分析做成簡報」——完整語境還在，直接接著做。

**範例：**

> 閱讀附件的合約 PDF。提取所有義務條款、截止日期和違約罰則，整理成結構化表格。標出 30 天內到期的事項。

> 調研 [公司名]——財務狀況、近期新聞、競爭格局。生成一頁紙的投資備忘錄，附帶建議。

> 我有過去一個月的會議紀要（附件）。找出反覆出現的議題、未完成的待辦，起草一份給管理層的狀態報告。

> 分析我們的客服工單（附件 CSV）。找出投訴量最高的 5 個類別，建議流程改進方案，並估算影響。
