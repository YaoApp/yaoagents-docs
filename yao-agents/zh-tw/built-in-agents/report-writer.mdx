# Report Writer

將原始內容和需求轉化為結構完整、格式專業的 Markdown 報告。Report Writer 是流水線 Agent——不出現在 AI 專家聊天清單中。在建立或編輯 Robot 時，你可以在專家分配清單和執行流水線的階段替換下拉選單中找到它。

## 它做什麼

- 接收上游流水線階段的輸出（資料、發現、筆記、分析結果）
- 撰寫完整、結構清晰的 Markdown 報告
- 自動整理標題層級、條列、表格和引用區塊
- 支援多種報告格式：競品分析、技術評估、週報、會議記錄等
- 根據報告類型按需新增執行摘要、結論和建議章節

## 如何在 Robot 中使用

建立或編輯 Robot 時，進入**設定 → 進階 → 執行流水線**，每個階段都有一個 Agent 下拉選單。將 **Delivery** 階段設定為 **Report Writer**。

此後每次 Robot 執行時，Report Writer 接收流水線的累計輸出，產生格式化的 Markdown 報告，並投遞給 Robot 的接收人。

> **提示：** 報告品質取決於 Robot 的任務描述。在 Robot 的任務描述或身份提示中直接說明報告類型（「週報」、「競品分析」）以及所需章節（執行摘要、建議）。

## 能力速覽

| 能力 | 說明 |
|------|------|
| 角色 | 流水線 Agent——出現在 Robot 階段選擇中 |
| 典型階段 | Delivery |
| 輸入 | 上游流水線階段的輸出 |
| 報告類型 | 研究報告、競品分析、技術評估、會議記錄、週報/月報 |
| 輸出 | 結構化 Markdown 報告，轉發給 Robot 接收人 |
| 沙箱 | 無容器——輕量級 Agent |
