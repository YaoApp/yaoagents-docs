# Agent Smith（打造專屬專家）

![Agent Smith](https://assets.yaoagents.com/en/experts/02-agent-smith-en-$__THEME.png)

說出你的需求，它來建立、調優並上線你的專屬 AI 專家。不用寫程式碼，不用懂技術——你描述，它實現。

## 擅長做什麼

- **從零建立專家** — 告訴它你要什麼樣的專家（比如「股票分析專家」），它自動完成搭建
- **搜尋現成能力** — 自動從全球技能庫（10 萬+）中找到合適的方案，直接複用
- **安全審查** — 外部技能安裝前自動檢查安全性和相容性
- **測試驗證** — 自動測試功能是否正常，不通過就改到通過
- **沙箱實測** — 在沙箱桌面裡直接跑起來，拿真實輸入測試
- **一鍵上線** — 測好後直接部署，你和團隊馬上就能用

## 能做哪些類型的專家

- **資料分析專家** — 看股票行情、解讀財報、生成資料報告
- **內容創作專家** — 行業報告、演示文稿、行銷文案
- **資訊處理專家** — 轉換檔案格式、識別圖片文字、整理批量資料
- **研究調研專家** — 競品分析、市場調研、技術方案評估
- **辦公效率專家** — 整理郵件、追蹤進度、生成工作匯報

不限於以上類型，只要你說得清楚，它都可以做。

## 工作原理

Agent Smith 運行在一個帶完整桌面的沙箱環境中，有終端、檔案系統、瀏覽器。它的工作流程：

1. 分析你的需求
2. 搜尋全球技能庫中有沒有現成方案可以複用
3. 搭建專家的核心能力
4. 自動執行測試，確保功能正常
5. 在沙箱裡實際跑一遍，供你確認效果
6. 部署上線

整個過程你只需要說一句話啟動，然後等結果。中間有問題它會問你。

## 怎麼寫好 Prompt

**新建專家：**

> 幫我做一個股票分析專家，能看 K 線和基本面

> 做一個會議紀要專家，輸入錄音文字就能輸出結構化紀要

**改進現有專家：**

> 我的股票分析專家回答太囉嗦了，幫我調一下

> 給競品分析專家加上生成 PPT 的能力

**找現成技能：**

> 有沒有現成的 PDF 解析技能？幫我搜一下裝上

> 搜一下有沒有爬網頁的技能，裝到我的調研專家裡

**測試和預覽：**

> 幫我測一下這個專家能不能正常工作

> 我想在瀏覽器裡看看效果，打開預覽

**上線發布：**

> 測好了，幫我上線

> 把這個專家部署上去，我和團隊要用

## 能力速覽

| 能力 | 說明 |
|------|------|
| 建立專家 | 根據描述自動搭建完整的 AI 專家 |

| 安全審查 | 安裝外部技能前自動進行安全檢查 |

| 一鍵部署 | 測試通過後直接上線，立即可用 |
