# 雲端伺服器上線 — 免裝 Engine，開啟即用

![雲端伺服器](https://assets.yaoagents.com/en/servers/05-servers-main-en-$__THEME.png)

不想在自己電腦上裝 Yao Engine？現在可以直接連雲端伺服器——模型、Tai Link 節點、沙箱，全幫你設定好了，登入就能用。

## 怎麼連

用戶端伺服器選擇頁，點 **Add server**，填地址。

![新增伺服器](https://assets.yaoagents.com/en/servers/02-servers-add-en-$__THEME.png)

選中伺服器，電子郵件 + 驗證碼登入。搞定。

![登入](https://assets.yaoagents.com/en/servers/04-servers-login-en-$__THEME.png)

登入之後和本機一樣——選專家、聊天、建任務，所有功能都在。

## 本機 vs 雲端

| | 本機 | 雲端 |
|---|---|---|
| 安裝 Engine | 要 | 不要 |
| 資料在哪 | 你的裝置 | 伺服器 |
| 模型 | 自己設定 | 設定好了 |
| 適合 | 隱私優先、長期使用 | 快速體驗、團隊共享 |

點左上角伺服器名稱隨時切換。
