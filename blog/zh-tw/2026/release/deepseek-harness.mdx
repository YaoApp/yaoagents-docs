# DeepSeek Harness 打開就用，跨裝置運行

![DeepSeek Harness](https://assets.yaoagents.com/en/dsh/01-dsh-kanban-en-$__THEME.png)

Yao Agents 集成了 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)。桌面客戶端或瀏覽器打開就能用，跨裝置運行。

## 怎麼用

專家列表裡選 **DeepSeek Harness**，開始對話。

模型在設定裡配好 API Key 就行，支援 DeepSeek V4 Pro、V4 Flash，也相容其他 OpenAI 相容端點。
