# 設定面板上線 — 接自己的模型，三步搞定

![模型設定](https://assets.yaoagents.com/en/settings/03-config-models-en-$__THEME.png)

新版 Yao Agents 上線了設定面板。想用自己的模型？打開設定點幾下就行。

支援 OpenAI、Anthropic、DeepSeek、Ollama 本地模型，只要是 OpenAI 相容介面的都能接。

## 三步接入你的模型

**第一步**：打開設定 → 模型設定 → 新增提供商

**第二步**：選類型，填 API Key

**第三步**：給角色指派模型 — Default（日常）、Heavy（重活）、Light（快活）、Vision（看圖），儲存搞定

設定完之後所有專家和 Robot 都會用你指定的模型。

## 還能設定什麼

- **搜尋引擎** — 配上 Tavily 或 Serper，專家就能上網查資料
- **郵件** — 填好 SMTP，Postman 就能幫你發信了
- **沙箱映像檔** — 介面上直接下載，不用敲指令
