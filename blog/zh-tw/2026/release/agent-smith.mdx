# Agent Smith — 一句話構建你自己的 AI 專家

![Agent Smith 構建過程](https://assets.yaoagents.com/en/tutorials/06-agent-smith-dev-en-$__THEME.png)

把你的工作流程變成一個專屬 AI 專家。講清楚要做什麼，Agent Smith 幫你構建出來，以後重複的事交給專家跑。

## 舉個例子：構建一個股票分析專家

在對話框裡跟 Yao Agents 說：

> 幫我做一個股票分析專家，能看 K 線和基本面，輸入股票代碼就能出分析報告。

接下來 Agent Smith 會自動完成這幾步：

**1. 搜尋現成技能**

先從全球技能庫（10 萬+）裡找有沒有能用的。找到後做安全審查，通過了再根據你的需求適配定制後裝進來。沒有合適的就從頭寫。

**2. 搭建專家**

根據你的描述，把處理邏輯、資料取得、輸出格式這些拼成一個完整的 AI 專家。

![構建完成](https://assets.yaoagents.com/en/tutorials/07-agent-smith-dev2-en-$__THEME.png)

**3. 自動測試**

跑一遍測試看功能對不對。沒過就自己改，改到過為止。

**4. 沙箱裡實測**

在沙箱桌面裡直接跑起來，拿真實輸入試一把。哪裡不滿意直接告訴 Agent Smith，它當場調。

![沙箱測試](https://assets.yaoagents.com/en/tutorials/08-agent-smith-preview-en-$__THEME.png)

**5. 部署上線**

測完覺得沒問題，跟它說「上線吧」，它就把專家部署好，更新到你的 AI 專家列表。下次直接在列表裡選就能用。

## 成品長啥樣

做好的股票分析專家，輸入 TSLA 就能出完整報告——K 線走勢、基本面數據、風險提示。

![分析報告](https://assets.yaoagents.com/en/tutorials/09-agent-smith-preview3-en-$__THEME.png)

## 不只是股票分析

幾個場景供參考：

> 做一個競品分析專家，輸入公司名就能輸出競品對比報告

> 做一個會議紀要專家，把錄音文字整理成結構化紀要

> 做一個週報生成專家，彙總本週的工作記錄，輸出一份週報

把你的日常工作變成 AI 專家，讓 Agent Smith 幫你搞定。
