# Yao Agents 公測開跑 — 叫你的舊電腦出來上班

![Yao Agents — AI Expert 面板](https://assets.yaoagents.com/en/experts/01-experts-grid-en-$__THEME.png)

內建 30+ AI 專家開箱即用，不夠？描述一下你要的角色，AI 幫你當場打造一個。

## Yao Agents 是什麼

裝好就有一支 AI 專家團隊在你電腦上待命，資料不上雲端，模型隨你挑，打開就能用。

能做什麼？舉幾個例子：

- **臨時需要一個小工具** — 跟 Applet Workshop 講一聲，它幫你現場做一個，右邊畫面即時看效果。
- **要架一個網站或 Landing Page** — 丟給 Web Builder，Next.js + Tailwind 幫你搞定，滿意了一鍵部署到你的伺服器。
- **數據分析、做儀表板** — Insights 接上你的資料庫或試算表，跑完直接產出 ECharts 互動式儀表板。
- **做簡報** — Slides 把你的大綱變成投影片，匯出 PDF 直接拿去用。
- **盯市場動態** — Market Scout 幫你自動追蹤產業資訊，抓回來分好類歸好檔。
- **管專案、處理 Email** — Project Manager 搭配 Postman，組成 Robot 之後自動收信、分類歸檔、追蹤專案進度，幫你把專案管理這件事自動化。
- **存知識** — 看到好文章？丟個連結給 Keeper，它自己讀、自己摘要、自己打標籤存好，之後一搜就出來。

不想每天重複一樣的操作？建一個 Robot，告訴它負責什麼，它會像真人一樣自己看狀況、自己做判斷、自己把事情搞定，做完跟你回報。

家裡有幾台放著長灰的舊電腦？透過 Tai Link 把它們串進來，AI 團隊跨裝置協同作業，你這邊照常做你的事。

## 為什麼做 Yao Agents

2022 年我們做了 Yao Engine，一個開源應用引擎，用 DSL 描述商業邏輯，程式自動產生程式碼。後來 AI 能力跟上了，程式碼全部由 AI 產生、人來審查；再後來 AI 自己審查，人做最後驗證。

這幾年我們一直在想：AI 都能寫程式了，軟體會變成什麼樣子？

兩個判斷：

**重點不是 Coding，是專業能力。** 你是做行銷的，你需要的不是「一套數據看板軟體」，而是看到數據、得出結論、快速行動；你是做營運的，你要的不是「一套監控工具」，而是產業動態到手、報告寫好、下一步清清楚楚。AI 不取代你的專業判斷，但它能幫你把中間那些繁瑣的執行環節處理掉。

**最好的軟體是沒有軟體。** 過去得學 UI、記操作，現在跟 AI 說你要什麼結果，它去做，做完交給你。

所以我們把 Yao Engine 的全端能力跟 AI Agent 結合，做成了 Yao Agents。跑在你自己的電腦上，資料在你手裡，模型你選。你專注你的專業領域，剩下的交給 Yao Agents 去辦。
