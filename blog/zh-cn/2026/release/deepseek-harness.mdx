# DeepSeek Harness 打开就用，跨设备运行

![DeepSeek Harness](https://assets.yaoagents.com/en/dsh/01-dsh-kanban-en-$__THEME.png)

Yao Agents 集成了 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)。桌面客户端或浏览器打开就能用，跨设备运行。

## 怎么用

专家列表里选 **DeepSeek Harness**，开始对话。

模型在设置里配好 API Key 就行，支持 DeepSeek V4 Pro、V4 Flash，也兼容其他 OpenAI 兼容端点。
