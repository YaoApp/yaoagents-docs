# 云服务器上线 — 不装 Engine，打开就用

![云服务器](https://assets.yaoagents.com/en/servers/05-servers-main-en-$__THEME.png)

不想在自己电脑上装 Yao Engine？现在可以直接连云端服务器——模型、Tai Link 节点、沙箱，全帮你配好了，登录就能用。

## 怎么连

客户端服务器选择页，点 **Add server**，填地址。

![添加服务器](https://assets.yaoagents.com/en/servers/02-servers-add-en-$__THEME.png)

选中服务器，邮箱 + 验证码登录。搞定。

![登录](https://assets.yaoagents.com/en/servers/04-servers-login-en-$__THEME.png)

登录之后和本地一样——选专家、聊天、建任务，所有功能都在。

## 本地 vs 云端

| | 本地 | 云端 |
|---|---|---|
| 安装 Engine | 要 | 不要 |
| 数据在哪 | 你的设备 | 服务器 |
| 模型 | 自己配 | 配好了 |
| 适合 | 隐私优先、长期使用 | 快速体验、团队共享 |

点左上角服务器名随时切换。
