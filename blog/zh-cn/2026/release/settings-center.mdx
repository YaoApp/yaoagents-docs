# 设置面板上线 — 接自己的模型，三步搞定

![模型配置](https://assets.yaoagents.com/en/settings/03-config-models-en-$__THEME.png)

新版 Yao Agents 上线了设置面板。想用自己的模型？打开设置点几下就行。

支持 OpenAI、Anthropic、DeepSeek、Ollama 本地模型，只要是 OpenAI 兼容接口的都能接。

## 三步接入你的模型

**第一步**：打开设置 → 模型配置 → 添加提供商

**第二步**：选类型，填 API Key

**第三步**：给角色分配模型 — Default（日常）、Heavy（重活）、Light（快活）、Vision（看图），保存搞定

配完之后所有专家和 Robot 都会用你指定的模型。

## 还能配什么

- **搜索引擎** — 配上 Tavily 或 Serper，专家就能联网查资料
- **邮件** — 填好 SMTP，Postman 就能帮你发邮件了
- **沙箱镜像** — 界面上直接下载，不用敲命令行
