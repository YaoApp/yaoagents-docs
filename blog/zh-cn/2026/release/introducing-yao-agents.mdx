# Yao Agents 公测开启 — 喊你旧电脑出来干活

![Yao Agents — AI Expert 面板](https://assets.yaoagents.com/en/experts/01-experts-grid-en-$__THEME.png)

内置 30+ AI 专家开箱即用，不够？描述一下你要的角色，AI 帮你现造一个。

## Yao Agents 是什么

装完就有一支 AI 专家团队在你电脑上待命，数据不上云，模型随你挑，打开就能用。

能干啥？比如：

- **临时需要个小工具** — 跟 Applet Workshop 说一句，它给你现场撸一个，右边屏幕实时看效果。
- **要搭个网站或落地页** — 丢给 Web Builder，Next.js + Tailwind 搭好，满意了一键部署到你服务器上。
- **数据分析、出看板** — Insights 接上你的数据库或表格，跑完直接出 ECharts 交互式仪表盘。
- **做个 PPT** — Slides 把你的大纲变成演示文稿，导出 PDF 直接拿去用。
- **盯市场动态** — Market Scout 帮你自动追踪行业资讯，抓回来分好类归好档。
- **管项目、处理邮件** — Project Manager 搭配 Postman，组成 Robot 之后自动收邮件、分拣归档、跟进项目进度，帮你把项目管理这事儿自动化。
- **存知识** — 看到好文章？丢个链接给 Keeper，它自己读、自己摘要、自己打标签存好，以后一搜就出来。

不想每天重复同样的操作？创建个 Robot，告诉它负责什么，它会像真人一样自己看情况、自己做判断、自己把活干了，完事给你汇报。

家里有几台吃灰的旧电脑？通过 Tai Link 把它们连进来，AI 团队跨设备协同干活，你这边该干嘛干嘛。

## 为什么做 Yao Agents

2022 年我们做了 Yao Engine，一个开源应用引擎，用 DSL 描述业务逻辑，程序生成代码。后来 AI 能力跟上了，代码全部 AI 生成、人来审查；再后来 AI 自己审查，人做最后验证。

这几年我们一直在想：AI 能写代码了，软件会变成什么样？

两个判断：

**重点不是 Coding，是专业能力。** 你是做市场的，你需要的不是"一个数据看板软件"，而是看到数据、得出结论、快速行动；你是做运营的，你要的不是"一个监控工具"，而是行业动态到手、报告写好、下一步清清楚楚。AI 不替代你的专业判断，但它能把中间那些繁琐的执行环节干掉。

**最好的软件是没有软件。** 过去得学 UI、记操作，现在跟 AI 说你要什么结果，它去做，做完交给你。

所以我们把 Yao Engine 的全栈能力跟 AI Agent 结合，做成了 Yao Agents。跑在你自己电脑上，数据在你手里，模型你选。你专注你的专业领域，剩下的交给 Yao Agents 去办。
