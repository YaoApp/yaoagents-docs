# Settings Panel Is Live — Connect Your Own Models in 3 Steps

![Model Configuration](https://assets.yaoagents.com/en/settings/03-config-models-en-$__THEME.png)

The new version of Yao Agents ships with a settings panel. Want to use your own models? Open settings, click a few times, done.

Supports OpenAI, Anthropic, DeepSeek, Ollama local models — anything with an OpenAI-compatible API works.

## Connect your model in 3 steps

**Step 1**: Open Settings → Model Configuration → Add Provider

**Step 2**: Pick the type, enter your API Key

**Step 3**: Assign models to roles — Default (everyday), Heavy (complex tasks), Light (fast tasks), Vision (image understanding). Save.

All experts and robots will use the models you assign.

## What else can you configure

- **Search engine** — Add Tavily or Serper so experts can look things up online
- **Email** — Fill in SMTP and Postman can send emails for you
- **Sandbox images** — Download directly from the UI, no terminal needed
