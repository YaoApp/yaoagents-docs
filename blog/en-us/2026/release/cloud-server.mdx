# Cloud Servers Are Live — No Engine, No Setup, Just Go

![Cloud server](https://assets.yaoagents.com/en/kanban/07-kanban-board2-en-$__THEME.png)

Don't want to run Yao Engine on your own machine? Connect to a cloud server instead — models, Tai Link nodes, sandbox, all pre-configured. Sign in and go.

## Connect in two steps

Open the server selection screen, hit **Add server**, enter the address.

![Add server](https://assets.yaoagents.com/en/servers/02-servers-add-en-$__THEME.png)

Pick the server, sign in with email + verification code. Done.

![Sign in](https://assets.yaoagents.com/en/servers/04-servers-login-en-$__THEME.png)

From there it's the same experience — pick an expert, chat, create tasks. Everything works.

## Local vs Cloud

|                | Local              | Cloud              |
| -------------- | ------------------ | ------------------ |
| Engine install | Yes                | No                 |
| Data           | Your device        | The server         |
| Models         | Set up yourself    | Ready to go        |
| Best for       | Privacy, long-term | Quick trial, teams |

Click the server name top-left to switch anytime.
