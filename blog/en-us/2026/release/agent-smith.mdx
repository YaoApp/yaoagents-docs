![Agent Smith building process](https://assets.yaoagents.com/en/tutorials/06-agent-smith-dev-en-$__THEME.png)

Turn any repeatable workflow into a dedicated AI expert. You describe what it should do; Agent Smith handles the rest — from scaffolding to deployment.

## Example: Building a Stock Analyst

Tell Yao Agents in the chat:

> I need a stock analyst that reads K-line charts and fundamentals. Give it a ticker, get a full analysis report.

Agent Smith takes it from there:

**1. Skill search**

Scans a global library of 100,000+ skills for anything reusable. Matches go through a security audit, get adapted to your spec, then installed. No match? It writes everything from scratch.

**2. Assembly**

Wires up the processing logic, data sources, and output format into a complete AI expert.

![Build complete](https://assets.yaoagents.com/en/tutorials/07-agent-smith-dev2-en-$__THEME.png)

**3. Automated tests**

Runs the test suite. Failures get fixed and re-run until everything passes.

**4. Sandbox trial**

Spins it up in a sandbox desktop with real inputs. Something off? Just tell Agent Smith — it adjusts on the spot.

![Sandbox testing](https://assets.yaoagents.com/en/tutorials/08-agent-smith-preview-en-$__THEME.png)

**5. Ship it**

Say "deploy" and it goes live — added straight to your AI Experts list, ready to use.
