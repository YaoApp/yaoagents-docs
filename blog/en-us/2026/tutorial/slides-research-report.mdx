# Create a Brand Research Deck with Yao Agents

![Final result](https://assets.yaoagents.com/en/tutorials/04-ppt-result-en-$__THEME.png)

In this example, we ask Yao Agents to research Labubu and produce a brand research slide deck.

> **Sample output** [Download PDF →](https://assets.yaoagents.com/en/demos/labubu-growth-path.pdf)

## Setup

Check three settings first.

| Setting | Recommended | Notes |
|---------|------------|-------|
| [Models](/docs/en-us/settings/ai-models) | DeepSeek (Anthropic) / DeepSeek V4 Pro | Set as Default model |
| [Search](/docs/en-us/settings/search-scrape) | Brightdata | Required for web research |
| [Sandbox](/docs/en-us/settings/docker-setting) | `Transformer, Slides` downloaded | Click to download if not ready |

> **Note**: Set DeepSeek's interface type to **Anthropic-compatible**. DeepSeek does not support vision — you need to set a separate **Vision model** (e.g. GPT-4o Mini) or image-related features won't work.

![Sandbox settings](https://assets.yaoagents.com/en/settings/08-config-sandbox-en-$__THEME.png)

## Create a Workspace

Create a new workspace from the sidebar. All output files will be saved here.

![New workspace](https://assets.yaoagents.com/en/tutorials/01-create-workspace-en-$__THEME.png)

## Send a Message

![Chat](https://assets.yaoagents.com/en/tutorials/02-chat-request-en-$__THEME.png)

Select the workspace, then tell Yao Agents in the chat box:

> Research Labubu's growth path and why it went viral globally. Make a slide deck, 6–7 pages, style should match Labubu's brand identity. I need to share it with the marketing team.

That's it. Yao Agents hands the task to the Slides expert, which will search the web, organize content, generate slides, and export a PDF.

![Working](https://assets.yaoagents.com/en/tutorials/03-slides-working-en-$__THEME.png)

## See the Result

The finished deck is in your workspace, ready to download.

![Work log](https://assets.yaoagents.com/en/tutorials/05-work-log-en-$__THEME.png)

Click the file to preview it:

![Deck preview](https://assets.yaoagents.com/en/tutorials/04-ppt-result-en-$__THEME.png)

The work log shows the full process — what was searched, what was written, how many revisions.
