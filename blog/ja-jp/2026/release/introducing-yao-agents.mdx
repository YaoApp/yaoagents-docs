# Yao Agents オープンベータ開始 — 眠ってるPCを叩き起こせ

![Yao Agents — AI Expert パネル](https://assets.yaoagents.com/en/experts/01-experts-grid-en-$__THEME.png)

30以上のAIエキスパートがすぐ使えます。足りなければ、欲しい役割を説明するだけでAIがその場で作ってくれます。

## Yao Agents とは

インストールするだけで、AIエキスパートチームがあなたのPC上にスタンバイ。データはクラウドに上がらず、モデルは好きなものを選べて、すぐに使い始められます。

何ができるかって？たとえば：

- **ちょっとしたツールが欲しい** — Applet Workshop にひとこと伝えれば、その場でサクッと作ってくれます。右側の画面でリアルタイムにプレビュー確認。
- **Webサイトやランディングページを作りたい** — Web Builder に任せれば、Next.js + Tailwind で構築。気に入ったらワンクリックであなたのサーバーにデプロイ。
- **データ分析やダッシュボード** — Insights にデータベースやスプレッドシートをつなげば、ECharts のインタラクティブなダッシュボードを一発で生成。
- **プレゼン資料を作りたい** — Slides にアウトラインを渡すだけで、スライドに仕上げてくれます。PDF書き出しでそのまま使えます。
- **市場の動向をウォッチしたい** — Market Scout が業界ニュースを自動でトラッキング、カテゴリ分けしてきれいに整理。
- **プロジェクト管理やメール対応** — Project Manager と Postman を組み合わせて Robot を作れば、メールの受信・振り分け・進捗フォローまで自動化できます。
- **ナレッジを貯めたい** — いい記事を見つけたら、リンクを Keeper に投げるだけ。自動で読んで、要約して、タグ付けして保存。後から検索すればすぐ出てきます。

毎日同じ作業を繰り返すのはもう終わりにしませんか？ Robot を作って担当範囲を教えておけば、状況を見て、判断して、タスクをこなして、終わったら報告してくれます。

家に使ってない旧PCが眠ってませんか？ Tai Link でつなげば、AIチームが複数デバイスで協力して動きます。あなたは自分のやるべきことに集中するだけです。

## なぜ Yao Agents を作ったのか

2022年に Yao Engine というオープンソースのアプリケーションエンジンを作りました。DSLでビジネスロジックを記述して、プログラムがコードを生成する仕組みです。その後AIの能力が追いついてきて、コードは全部AIが生成して人間がレビューするようになり、さらにその先ではAI自身がレビューして、人間は最終確認だけ。

ここ数年ずっと考えてきたことがあります。AIがコードを書けるようになったら、ソフトウェアはどう変わるんだろう？

2つの確信があります。

**大事なのはコーディングじゃなくて、専門知識です。** マーケティング担当なら、欲しいのは「データダッシュボードソフト」じゃなくて、データを見て、結論を出して、すぐ動けること。運用担当なら、「モニタリングツール」が欲しいんじゃなくて、業界動向を把握して、レポートができていて、次に何をすべきかクリアになっていること。AIはあなたの専門的な判断を置き換えるものではありません。でも、間にある面倒な作業を片付けてくれます。

**最高のソフトウェアは、ソフトウェアがないこと。** これまではUIの使い方を覚えて、操作を記憶する必要がありました。今はAIに欲しい結果を伝えるだけ。AIがやって、できたものを渡してくれます。

だから、Yao Engine のフルスタック能力とAI Agentを組み合わせて、Yao Agents を作りました。あなた自身のPCで動いて、データはあなたの手元に、モデルはあなたが選ぶ。あなたは自分の専門分野に集中して、残りは Yao Agents に任せてください。

## オープンベータについて

ベータ段階なので、バグはどうしてもあります。問題を見つけたらぜひフィードバックをお寄せください。できるだけ早く修正します。

Yao Agents Hub とAIによるエキスパート自動生成機能は現在クローズドベータ中で、まもなく公開予定です。公開後はHubからコミュニティのエキスパートをワンクリックでインストールしたり、やりたいことを説明するだけでAIにエキスパートを生成してもらえるようになります。サードパーティのAgentエコシステムとの連携も進めており、今後さらに多くのエキスパートが利用可能になります。

Yao Agents を手軽に体験していただくために、[モデルサービス](https://yaoagents.com/dashboard/auth/entry?redirect=/console)を用意しています。Claude、GPT、DeepSeek など主要モデルを統合しており、登録すればすぐ使えます。もちろん、自前のモデルサービスを接続することもできます。

開発者の方で、自分でエキスパートを作ってみたい方は、[Yao Agent 開発チュートリアル](https://yaoapps.com/docs/tutorials/en-us/agent/getting-started/index)をチェックしてみてください。ゼロから自分だけのAIエキスパートを構築できます。
