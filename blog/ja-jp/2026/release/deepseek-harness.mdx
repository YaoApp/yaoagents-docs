# DeepSeek Harness すぐ使える、デバイスをまたいで動く

![DeepSeek Harness](https://assets.yaoagents.com/en/dsh/01-dsh-kanban-en-$__THEME.png)

Yao Agents に [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) が統合されました。デスクトップアプリまたはブラウザで直接使え、複数デバイスで動作します。

## 使い方

エキスパート一覧から **DeepSeek Harness** を選んで会話を始めるだけです。

設定でモデルの API キーを入れてください。DeepSeek V4 Pro、V4 Flash のほか、OpenAI 互換エンドポイントにも対応しています。
