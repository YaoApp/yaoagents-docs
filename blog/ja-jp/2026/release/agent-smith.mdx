# Agent Smith — 一言で自分だけのAIエキスパートを構築

![Agent Smith 構築プロセス](https://assets.yaoagents.com/en/tutorials/06-agent-smith-dev-en-$__THEME.png)

あなたのワークフローを専用AIエキスパートに変換。やりたいことを伝えれば、Agent Smith が構築します。あとは繰り返し作業をエキスパートに任せるだけ。

## 例：株式アナリストを構築する

チャットボックスで Yao Agents にこう伝えます：

> 株式アナリストを作って。Kラインとファンダメンタルズが見られて、ティッカーを入力すると分析レポートが出るやつ。

あとは Agent Smith が自動で進めます：

**1. 既存スキルを検索**

グローバルスキルライブラリ（10万以上）から使えるものを探します。見つかればセキュリティ審査を行い、あなたの要件に合わせてカスタマイズしてからインストール。適切なものがなければゼロから書きます。

**2. エキスパートを構築**

あなたの説明をもとに、処理ロジック・データ取得・出力フォーマットを組み立て、完全なAIエキスパートに仕上げます。

![構築完了](https://assets.yaoagents.com/en/tutorials/07-agent-smith-dev2-en-$__THEME.png)

**3. 自動テスト**

テストを実行して機能を検証。通らなければ自分で修正し、全て通るまで繰り返します。

**4. サンドボックスで実テスト**

サンドボックスのデスクトップで実際に動かし、リアルな入力で試します。気になる点があれば Agent Smith に伝えれば、その場で調整します。

![サンドボックステスト](https://assets.yaoagents.com/en/tutorials/08-agent-smith-preview-en-$__THEME.png)

**5. デプロイ**

問題なければ「デプロイして」と伝えるだけ。エキスパートがデプロイされ、AIエキスパート一覧に追加されます。次回からはリストから選ぶだけで使えます。

## 完成品はこんな感じ

出来上がった株式アナリストに TSLA を入力すると、Kライン推移・ファンダメンタルズ・リスク指標を含む完全なレポートが出力されます。

![分析レポート](https://assets.yaoagents.com/en/tutorials/09-agent-smith-preview3-en-$__THEME.png)

## 株式分析だけじゃない

他にもこんな使い方：

> 競合分析エキスパートを作って。会社名を入れたら比較レポートが出るやつ

> 議事録エキスパートを作って。文字起こしを入れたら構造化された議事録にまとめるやつ

> 週報エキスパートを作って。今週の作業ログをまとめてレポートにするやつ

日常業務をAIエキスパートに。Agent Smith にお任せください。
