# クラウドサーバー提供開始 — Engine不要、接続するだけ

![クラウドサーバー](https://assets.yaoagents.com/en/kanban/07-kanban-board2-en-$__THEME.png)

Yao Engine をローカルにインストールしたくない？クラウドサーバーに接続すれば、モデル・Tai Link ノード・サンドボックスがすべて設定済み。サインインするだけです。

## 接続方法

サーバー選択画面で **Add server** をクリックし、アドレスを入力。

![サーバー追加](https://assets.yaoagents.com/en/servers/02-servers-add-en-$__THEME.png)

サーバーを選択し、**ご自身のメールアドレスを入力**してください。確認コードが届くので、認証後にパスワードを設定します。デフォルトアカウントは使用しないでください。

![サインイン](https://assets.yaoagents.com/en/servers/04-servers-login-en-$__THEME.png)

あとはローカルと同じ。エキスパートを選び、会話を始め、タスクを作成できます。

## ローカル vs クラウド

| | ローカル | クラウド |
|---|---|---|
| Engine インストール | 必要 | 不要 |
| データ | 自分のデバイス | サーバー |
| モデル | 自分で設定 | 設定済み |
| 向いている用途 | プライバシー重視・長期利用 | 手軽に体験・チーム共有 |

左上のサーバー名をクリックすればいつでも切り替え可能。

## 利用可能なノード

**Polaris（北京）** が稼働中。招待コードが必要です。

| ノード | アドレス | 登録 |
|--------|---------|------|
| Polaris | bj.yaoagents.cn | 招待コード |

招待コードの申請と今後のノード情報は [/servers](/servers) をご確認ください。
